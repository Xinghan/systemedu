# 阶段简报角色恢复：动态片头生成中

五条项目线各有一位固定的虚构中国科研角色，共 40 段独立对白。已解决 Python TLS 传输问题，全部任务均已获得服务端任务 ID，正在分批生成和合成。实时状态见 `progress.json`，逐项状态在各站 `task.json`；此批次仍不代表全部完成或已部署。

已完成首段视频的本地页面验收：旧观看标记升级、跳过、重播、结束后返回、下一站触发和手机布局；类型检查没有新增错误，lint 和生产构建通过。完整 40 段媒体、字幕、浏览器解码和逐段画面审查将在生成结束后统一验收。

任务中心和地图的 125 张无人背景不变，原课堂节点与记录不变。新角色图片仅被视频播放器引用。v1 资源保留，v2 片头接在原有阶段说明前；少量生成镜头意外出现前景旁听者，用明确记录的镜头裁切保持直接面对研究员的视角。

`generate.py` 先持久化提交状态，不对状态不明的付费请求重发。只有收到明确 429 限流且无任务 ID 的请求，才允许通过 `--retry-rejected` 归档拒绝记录后补交。`watch.py` 只查询已有任务并合成，不能创建付费任务。

`curl_transport.py` 只用于本批媒体生成：保持 TLS 校验，限制服务域名，不把凭据或签名 URL 放进进程参数、日志或仓库。五位人物均为 AI 生成的虚构任务搭档。
