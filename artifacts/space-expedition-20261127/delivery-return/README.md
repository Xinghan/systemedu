# 本章作品返回课文修复

用户报告：进入「星光调查卡」作品表单后，无法返回之前的课文。

## 原因与修改

- 原来进入作品页时把整个导航路径替换为 `.work`，丢失了课文目的地。返回到任务中心后，「继续」又根据已读状态打开作品页，形成循环。
- 从课文进入作品页时保留课文路径；重启后从任务中心直接进入作品页时，补上本章最后一节作为返回目的地。
- 作品页提供带文字的「返回上一节」按钮，无需完成作品或勾选自检即可返回。退出前保存草稿，不创建提交回执。
- 回到课文时创建新的 WebView 会话，恢复持久化的阅读页及学习记录。保留旧会话的单次前进保护，既能再次完成并进入作品页，也不会因重复消息跳过节点。
- 未修改课程节点、稳定 ID、内容版本、媒体、学习记录格式或作品回执格式。

## 验证

设备：iPad Air 11-inch (M4)，iOS 27.0，横屏与竖屏。测试使用隔离存储与合成角色 Navigation QA，未更改用户真实作品。

1. 修复前新增回归用例并运行，点击原有返回按钮后无法找到课文标题，用例按预期失败（44.696 秒）。结果：`/tmp/systemedu-delivery-back-before-20261127.xcresult`。
2. 修复后 ExpeditionTests：13 项通过，1 项需要显式启用的在线头像服务测试跳过，0 失败。单次前进保护、旧记录可读、节点覆盖、作品提交条件与章节推进均通过。
3. UI 回归通过：作品页返回课文、恢复最后阅读页、再次从正文完成进入作品页、草稿保留、不提交不完整作品、重启后直接进入作品页再返回、竖屏回看更早节点（43.578 秒）。
4. 完成视频自动弹出、关闭、重播与章节只推进一次的 UI 回归通过（51.657 秒）。以上结果：`/tmp/systemedu-delivery-back-after-20261127.xcresult`。
5. 最终使用自定义图文布局避免系统工具栏把 Label 折叠成图标；断言「返回上一节」文字实际可见，并等待前一节正文加载。再次运行返回用例通过（60.049 秒）。结果：`/tmp/systemedu-delivery-back-label-20261127.xcresult`。本目录三张截图来自此次最终运行。
