# 课文完成后自动播放章节总结

用户确认触发入口为正文最后一页的「完成本节，整理本章作品」。旧实现只在作品署名入档后播放，因而该入口没有总结视频。

## 最终行为

- 本章最后一个节点完成后进入作品整理页，并自动弹出该章总结；关闭或跳过回到作品草稿。
- 作品页提供「重看本章总结」。未提交的材料仍按原有要求收集，自检与归档条件不变。
- 署名入档后展示回执和下一章入口，不再次强制播放。回执与作品档案保留完整版视频重播。
- 普通小节完成仍进入下一小节，不把整章总结插入每个子节点。
- 14 段总结增加 `summaryStart` 元数据。阅读结束时跳过第一句「已归档」，播放回顾、鼓励与后续提示；进度拖动、播放结束后的重播、字幕列表使用同一起点。归档重播从零开始。

没有生成或替换视频。课程、120 个稳定节点引用、媒体路径、音乐署名及学习记录结构保持原样；对比 HEAD 的资源清单，唯一差异为 14 个 `summaryStart` 数值。

## 验证记录

测试设备：iPad Air 11-inch (M4)，iOS 27.0。所有 UI 用例使用 UUID 隔离数据库与合成角色，未修改真实用户的进度或作品。

- 修复前：点击真实正文完成按钮，用例在「提交前出现总结」断言处按预期失败（48.445 秒）。`/tmp/systemedu-summary-trigger-before-20261127.xcresult`。
- 原生 ExpeditionTests：13 通过，1 个需显式启用的在线头像测试跳过。覆盖 14 章视频资源与字幕起点、120 个节点覆盖、旧记录解码、作品提交和只推进一次。
- 普通小节推进及重启恢复通过（31.402 秒）；作品返回课文、保留阅读页与草稿、重新完成、重启后返回通过（53.490 秒）。`/tmp/systemedu-summary-trigger-verified-20261127.xcresult`。
- 最终 UI 回归全部通过：首章实际拍照、自动总结、提交与解锁下一章（101.682 秒）；播放器自动播放、关闭、跳过、回放、字幕范围、提交不重复播放及档案重播（60.288 秒）；其余 13 章连续完成、各章总结在提交前播放、提交后只进入下一章，并重启验证最终归档状态（257.373 秒）。`/tmp/systemedu-summary-all-chapters-20261127.xcresult`，3 项用例、0 失败。
