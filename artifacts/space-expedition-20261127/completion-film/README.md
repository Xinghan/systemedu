# 林岚的阶段回信：单章样片

此目录保留初版（Cherry 配音）及其验收记录。用户反馈后，App 资源已由相邻 `completion-film-commander-voice` 目录记录的指挥官音色与 Firmament_Active 配乐版本替换；初版审阅影片保留供对比。

范围：只制作「星光为什么变暗了」（`research-P1`）完成后的样片。其余 13 章保留现有行为，不套用这段对白。原有 15 段开场/阶段介绍视频保持不变。

## 影片

- `linlan-completion-preview.mp4`：带烧录中文字幕的审阅版，约 15.67 秒。
- App 资源：`packages/student-web/public/mission/space/expedition-v2/video/research-P1-complete.{mp4,vtt}` 与 `research-P1-complete-poster.jpg`。原视频不烧字幕，沿用原生播放器的字幕开关、字幕全文、暂停和拖动进度。
- 固定角色：原项目动画指挥官林岚，同一面容、制服与科研指挥室。前约 12.64 秒是实际生成的动态人物讲话镜头；末尾 3 秒单独切到无人观测实验室及成果提示。没有用静态人物图的平移缩放代替讲话动画。
- 对白：「队员，你的星光调查卡已经归档。让观察可以复查，是很好的开始。保持这份认真，下一站，我们一起检查数据的可靠性。」
- 这是按本阶段任务编写的鼓励与方法建议，不是对学生答案正确性的自动评分。播放器显示已提交作品的真实姓名、作品标题和材料数量；作品仍保留「内容待评阅」状态。

## 触发与退出

1. 本章全部学习节点完成后进入作品页；此时不播放完成影片。
2. 原有材料、自检和学习进度检查通过，点击「署名入档，完成本章任务」。不可变作品副本写入成功后，成果页自动弹出影片。
3. 「退出视频」始终可见，退出回到这次成果，不会撤销完成记录；成果页有「重看林岚的阶段回信」。
4. 「跳过视频，继续远航」或播完后的「继续远航」关闭播放器后才切到下一章。影片结束本身不强制跳转，避免丢失成果查看机会。
5. 重启直接按已归档记录恢复到下一章。作品档案里的回放为手动播放，不自动弹出；从档案播放时按钮为「返回作品」。

## 生成与复现

`generate.py` 使用项目已有的 DashScope 配置（不在文件中保存密钥）：`qwen3-tts-flash` / Cherry 生成对白，`wan2.6-i2v` 结合现有 `art/commander.png` 和 15 秒音轨生成动态人物，FFmpeg 合成两个独立镜头及审阅字幕。`audio.json`、`prompt.txt`、`task.json` 保留非敏感生成参数和任务状态；已有任务不自动重复提交。

官方接口说明：[Wan 2.6 图生视频](https://help.aliyun.com/en/model-studio/wan2-6-i2v)。依次执行 `generate.py voice`、`submit`、`fetch`、`compose`。中间原片位于 `/tmp/systemedu-completion-film-20261127`，正式 App 影片与审阅版均已保存在仓库。审阅字幕用 Pillow 排版后通过 FFmpeg 叠加，适用于本机没有 libass 的 FFmpeg。

安装仅更新完成视频配置与三个新增媒体文件，不重新导出工作区其他任务的课程改动。120 个原节点、正文、ID、记录版本和章节归属保持不变。验证结果见 `verification.json`。
