# 分子寻药：八站人物任务短片

本次补齐先前只实现无声图片简报的遗漏。已完成制作并通过本地验收；未部署。

## 交付范围

每站独立剧本、陈澄口播镜头、中文语音、阶段场景讲述、可开关 VTT 字幕与完整文字简报。第一站兼作开场，不额外弹第二段。八站对应 observation / filter / prediction / systems / protocol / data / evaluation / delivery；这些是任务站编号，不是新增八级学习难度。

沿用星际远航制作方式：每站一次 Wan2.6 I2V 10 秒人物镜头生成，保留自然说话段；其后使用已有研究室静态图搭配完整配音。没有再次生成场景图片，也没有把图片平移冒充人物视频。人物沿用已有虚构中国研究员陈澄，研究画面为 AI 场景示意，不作为分子结构或实验数据证据。

- 配音：沿用本项目 TTS 配置；不复刻真人声音。每站 dialogue 与 brief 分开合成，时间过长会拒绝生成而非截断句子。
- 视频：1080p、30 fps、H.264 / AAC，faststart；只在当前站的弹窗加载，不预取后续八段。
- 字幕：按中文短句与音频总时长估算，非逐字强制对齐。完整文字稿始终可展开，视频失败时直接展开。
- 自动触发：任务首页/地图选站、直接微项目/课堂、任务中心首次到站。中心先结束或跳过 5.6 秒入场再弹视频。同身份同站跳过或结束后不反复播放；可随时重播。
- 可达性：Esc/跳过/结束返回任务，焦点回到重播入口；后台暂停，后台首次到达不消耗；减弱动态设置下初始暂停。浏览器拦截自动播放时出现明确按钮。
- 数据：独立新版视频偏好 key，不复用无声图片简报 seen 标志；播放不会写课程完成记录。作业、任务自检、时间表、真实学习内容与记录 ID 不变。

## 可复现生产步骤

在仓库根目录依次执行 `.venv/bin/python artifacts/biomed-stage-films-20261010/generate.py voice`、`... generate.py submit`、`... generate.py fetch`、`... compose.py`。`--level 1` 等用于单站操作。视频提交先保存意图，再保存 task_id；已提交站只查询或下载，不会自动重复付费生成。配置、密钥与临时签名 URL 不进入产物。

`source.mp4` 为模型原片，`input-10s.mp3` 为指定中文人物台词；`brief.mp3` 为后续说明。`scripts.json` 是作者稿，发布台词见前端 biomed-stage-films.json，二者由校验核对。`task.json` 保留不含凭证的服务执行状态。

参考现有已验收脚本 artifacts/space-stage-films-20261009；服务输入约束核对 [阿里云图生视频文档](https://help.aliyun.com/zh/model-studio/legacy-image-to-video-api-reference/)。没有升级模型或更换服务商。
