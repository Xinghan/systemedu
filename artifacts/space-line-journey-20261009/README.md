# 星际远航整线任务中心 · 本地验收

本批次将任务体验从 `assemble-a-rover` 单门制造课提升到航空航天整条项目线。

入口：`http://localhost:4000/mission/space`。项目库航空航天项目线的主入口也已接入。12 个项目覆盖现有 taxonomy 中所有主分类或关联分类为 aerospace 的项目；5 段成长、8 个地点。HiRISE 与 Lightkurve 为两个可独立选择的高阶方向。

## 本轮实现

- 项目线序章、可选 29 秒影片、完整地图、分站简报、交付物、下一站关系、家长准备、作品档案。
- 复用现有图片和影片，没有额外生成 12 套视频。Lightkurve 原 manifest 没有封面，使用研究标识卡，不冒用另一项目封面。
- 三分钟项目、多节点课程、完整课程详情与正式课堂均有返回全线地图的入口。制造课内部地图继续呈现其 8 个学习节点，与整线地图明确区分。
- 保留课程内容、编号、版本、权限、课堂组件和学习记录存储方式；未新增学生媒体 tabs。
- 全线进展只读已有数据：访客短体验本机相册、引导课正式交付、大项目实际节点完成标记。浏览/视频不推进进展；提交和节点勾选不表示能力已评定。
- 完整工程课程的完成节点全部勾选后，仍显示需要复核作品。账号不自动接管设备上的匿名游戏相册。

## 验证

从仓库根目录运行：

```sh
node artifacts/space-line-journey-20261009/verify-browser.mjs
node artifacts/space-line-journey-20261009/campus-regression/verify-browser.mjs
```

`verification.json` / `campus-regression/verification.json` 保存结果。关键检查：

- 分类覆盖、项目库入口、5 阶段、8 站、12 个实际项目链接；短游戏/统一课堂/地图返回循环。
- 1440、390、320 像素布局；截图人工检查；桌面拖拽、触摸拖拽、键盘地点选择、缩放与居中。
- 影片按需加载、关闭卸载；地图浏览不写学习记录。
- 原课堂正文、资料、视频、实验和打印文件仍存在；课堂记录及数字原型恢复，不能冒充实物交付。
- 访客作品、账号交付、版本 1.0/2.0、账号切换隔离、失败重试、重复/无关课程节点过滤、图片失败时完整目录回退。
- 登录态记录用 Playwright API fixture 验证，未向真实账号写入测试记录。
