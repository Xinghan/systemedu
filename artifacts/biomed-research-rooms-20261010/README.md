# 分子寻药任务中心：无人科研实验室背景 v2

用户纠正：任务中心背景不应出现人物；原场景像家居办公空间，科研实验室特征不足。

本次使用内置 image_gen 为八个任务站分别生成新图：成像观察、自动筛选、测量验证、系统接入、靶点研究、数据溯源、模型评估、候选交接。环境采用实验台、仪器、服务管线、设备柜与分子研究屏幕；全部原图目视检查，无人物、人影或人物屏幕。图像是科研场景示意，不作为课程实验结果或采购清单。

## 文件与引用

- 原图：本目录 originals/{station}.png，共 8 张。
- 完整提示词与生成来源：tools/mission-authoring/biomed-research-room-prompts-v2.json。
- 网站图片：packages/student-web/public/mission/biomedicine/stations/{station}-v2-{640,960,1536}.webp，24 个版本合计 2,055,886 bytes。
- 处理过程：prepare-assets.cjs 只进行等比尺寸适配与 WebP 压缩，不修改图片内容；资产尺寸、大小、哈希在 assets.json。
- 任务中心常驻背景、全屏入场、入场底图和失败备用图统一使用 v2；备用图也为无人观察实验室。旧的人物迎宾图与口播短片独立保留，不再作为任务中心背景引用。
- 共用 MissionRoomSkin 新增可选 version，其他项目线默认仍使用 v1。

## 验收

verify-browser.mjs 已验证八站正常加载、背景请求不包含旧 v1 图片、5.6 秒入场与跳过、320/390 px 画面、失效图片切换到无人备用图、原星际远航背景兼容。截图经目视检查，设备主体与任务文字可辨。改动文件 ESLint 无错误；类型基线比较结果见 typecheck-baseline.json。
