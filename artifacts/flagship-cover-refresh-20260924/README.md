## 资源与接入

原始 PNG、网页 WebP 和逐图生成记录保存于 `systemeduidea/projects_data/<slug>/cover-editorial-v3.*`。原图均为 1536 × 1024；WebP 仅做质量 90 编码，不重绘、不裁切。`prompts.json` 保存精确提示词；`assets.json` 保存尺寸、字节数和 SHA-256。

网站资源在 `packages/student-web/public/project-covers/<slug>/cover-editorial-v3.webp`；项目库快照和公共封面解析入口使用版本化路径，使首页、项目库、详情及我的项目共用同一版封面。其他项目继续使用原有内容服务。
