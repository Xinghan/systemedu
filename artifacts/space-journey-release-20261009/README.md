# 航天任务项目线发布验收

本目录只记录 2026-10-09 此次部署。来源 `fa2c82af8b47a9b8caba7e3d92a049ca8107830b`，发布构建 `NxJ-KRI8fPxxmEY3y8NzF`。

- `request.json`：从已提交 Git 内容导出的 71 文件白名单及哈希。
- `candidate/`：隔离候选版本，五段真实视频播放、字幕、Range、首次触发与去重、地图与课程入口、390 / 320px 布局。
- `production/`：使用同一验收脚本访问正式 HTTPS。以 `verification.json` 的 `passed` 为结果，脚本结束前不视为通过。
- `server/`：实际构建、类型基线对比、上线文件指纹、服务器完整性结果。

验收只用匿名公开 GET，不修改学生账号或作品。首次触发和去重仅在测试浏览器中产生播放偏好。浏览器启用允许自动播放的 Chromium 参数，以验证应用请求播放的路径；实际浏览器的系统自动播放策略仍然适用，限制时提供手动播放按钮。未进行真实 iOS Safari 设备测试。

候选预览 SSH 隧道曾导致播放等待超时。诊断显示视频正在加载，无媒体错误；同一版本增加等待后通过全部检查。服务器本机首段完整视频响应约 0.02 秒；这不代表用户端加载耗时。`production/first-pass-diagnostic.json` 保留正式站第一次验收的快进等待超时；额外末尾 Range 检查正确返回 206 / 65,536 字节，耗时约 4.70 秒。正式站验收不构成性能基准。

发布步骤、范围和回滚方式见 `docs/deployments/2026-10-09-space-journey.md`。
