# 任务中心：阶段场景与动态入场

在既有五模块任务中心上增加独立环境层：先展示全屏背景，站名进入，再淡出场景层并让控制台标题、导航、左右面板和任务单分层滑入。约 1.7 秒完成；图片解码最多等待 450ms，不阻塞工作台。页面提供重播按钮；跳过按钮、Escape、Tab 均立即结束动画。尊重系统减少动态效果偏好。

同站内切换子任务或填写记录不重播。入场层单独更新，任务单、计时器及记录钩子不因重播重新挂载。时间表、地图、日志和档案沿用已有组件。主页面上方也显示当前阶段的背景和站名。

## 加载与回退

- 桌面/全屏背景使用 1536px（约 117–206KB）；手机页面横幅使用 640px（31–49KB）或 960px（59–100KB）。手机全屏竖向裁切使用高清源，避免放大低分辨率图。
- 不预载八个阶段；仅当前阶段和原指挥室回退图被引用。同一图片复用浏览器缓存。
- 处理了图片在 React 接管前已失败的情况；恢复为原指挥室背景。图片失败或慢加载不会无限遮挡任务模块。
- 侧面板滑动限制在页面边界内，避免手机动画临时撑宽视口。入场画面使用稳定视口高度，跳过按钮保持可见。
- 动画为一次性 CSS 与 Web Animations，不新增视频、音频或 3D 运行时。
