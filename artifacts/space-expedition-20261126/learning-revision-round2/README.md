# 行星观测课程：第二轮整条学习路线修订

面向没有天文、统计和编程基础的初中生。用户明确的断点是 **M08「检查缺失数值和观测间断」**；本轮审查、修改及操作验收覆盖 M01–M32，未将范围限制在该节。当前课程内容版本为 `guided-20261126-r2`，原课程 edition `0.2.0`、32 个活动 ID、整个项目线 120 个节点均保留。

第一轮补充过概念，但课文需要的变量、输出和原 17 格汇总 Notebook 并不一致。学生照顺序阅读仍可能找不到下一步材料。本轮新增 `junior-guide.ipynb`（145 格，其中 43 格代码），与 32 节同名对应；原 Notebook、原始观测、媒体和历史记录保留。旧数字章节、直接运行 `develop()` 等冲突说明逐项纠正，原文与原作业均有版本快照。

| 课节 | 具体补充 | 后续实际使用的产物 |
|---|---|---|
| M01–M05 | 明确观察与推测，原始记录查找、区间边界、可填写的观察卡模板 | 文件清单、候选区间、带来源的观察卡 |
| M06–M11 | JupyterLab 安装启动；逐列读取和筛选；原编号对齐；输出后再读回 | 逐行检查表、共同筛选条件、4 个缺口、处理后的数据 |
| M12–M17 | 手算与真实输入分开；趋势、深度、周期、折叠和模型评分逐步执行 | 处理曲线、实际候选参数、可追溯图表 |
| M18–M22 | 保留缺测编号的逐事件表；区分逐事件相对深度与合并通量差；像素图增加数值色条 | 事件比较、质量窗口、像素来源、待本人判断的证据表 |

M08 的正文现有七行构造表、三条真实 FITS 记录与逐项反馈；新增 `kepler10-q3-validity-input.csv` 含误差列。旧 CSV 与原始 FITS 未替换。本人运行后才生成 `validity-ledger.csv` 等结果，不把下载的参考表当作学生成果。
