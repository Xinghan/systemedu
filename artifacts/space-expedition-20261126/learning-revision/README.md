# 初中零基础版恒星观测课：首轮教学修订

2026-11-26。范围为 `lightkurve-transit-detective` 全部 32 节正文。课程仍属于星际远航原路线，没有删除、合并或重新编号节点，也没有新增课堂 tabs。

## 改了什么

在第一次用到相关概念之前补上背景、明确对象、逐步例子及可核对的练习反馈。M01 先讲恒星/行星、光源与接收者，区分 Kepler 望远镜、Kepler-10 恒星和 Kepler-10 b 行星，再比较太阳与遥远恒星的观测；解释变暗的多种原因、凌星几何和光变曲线，最后才进入真实观测。M02–M32 对文件、表格、坐标、程序执行、筛选、比例、中位数、周期/相位、模型与预测、证据判断、误差和复现逐节补写。

新增三张精确教学示意图：太阳与遥远恒星的观测差异、凌星前中后的几何与模拟读数、记录表的一行如何对应散点图的一个点。构造数值与真实 Kepler 数据明确区分。补充内容同时写回 authoring 源，后续生成可保留。

原 32 节正文共 **33,165 个汉字**，本轮后 **67,267 个汉字**，增加 **34,102 个汉字**；不含代码字符、概念拓展、作业、讲课音频等。这是内容规模统计，不是掌握程度或可用性评分。原课并非整体字数少，主要缺少从常识到专业操作之间的解释。
