# 阶段完成与续学修复

修复报告：2026-11-27。代码已通过编译、类型检查和针对性回归；完整连续模拟器验收尚未完成。

## 问题与修复

- 原来恢复课节直接读取旧的 `lessonIndex`，即使这节已完成也会重开。现在按当前内容版本的完成记录，恢复到第一节未完成内容。
- 原来的“读完”按钮会反复切换完成/未完成，而且不会带用户前进。现在保存完成记录后进入下一步，末节进入本章作品整理；重复点击不会撤销或连续跳两节。
- 自动保存与主动完成共用一个写入队列，所有等待者必须等最新写入结束，才允许前进。保存失败停在当前页，可重试。
- 课节、作品整理、章节首页以明确的章节/路由标识重建状态，作品提交防止重复入档。
- 第一章仍要求真实的望远镜拍摄操作记录，单独读完课文不会绕过作品要求。
