# 项目库学习路径图

实物图通过内置 `image_gen` 生成及修改，未使用 CLI 或 API fallback。配套流程图使用原生 SVG 绘制。

- 最终无文字、带细箭头的源图：`space-journey-arrows-source.png`。
- 手机局部画面的原始场景：`space-journey-source.png`。
- 网页衍生图：`../../packages/student-web/public/library/learning-path/`。
- 尺寸与体积：`image-variants.json`。
- 提示词：`prompts.md`。
- 本地中英文、1440 / 1024 / 390 / 320px 检查与截图：`review/`。

照片只展示实物和连接箭头，阶段标题在网页中排版。手机复用无箭头原图的四个局部画面，网页提供纵向箭头，避免裁切横向箭头后产生错误方向。图片是生成的教学示意，不作为已完成实物测试的证据。

## 配套矢量流程图

`learning-process-v1.svg` 在实物图下方展示同样的四步过程：取景观察、建立判断规则、连接模块、执行完整探索任务。四列与实物和网页标题对齐，画面内没有文字。SVG 沿用网站的鼠尾草绿和陶土色。

`learning-process-stages-v1.svg` 是删除横向连接箭头后的手机衍生版，其余图形一致。手机按阶段配对实物与矢量图，由网页中的向下箭头连接各行，避免局部裁切产生错误的横向箭头。修改图形时需同步两个文件。

新增矢量图的本地中英文及 1440 / 1024 / 390 / 320px 验收记录在 `vector-review/`。

当前接入本地项目库，未部署生产环境。验证使用本地浏览器与项目目录接口 fixture，不写入用户或学生数据。
