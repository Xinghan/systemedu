# 飞船终端启动效果

根据用户反馈，把八站背景的入场从 1.72 秒延长至 5.6 秒。

## 显示节奏

- 0–0.8 秒：完整科研环境、细边框与扫描光带。
- 0.8–2.3 秒：终端编号显影，站名逐字点亮；字符启动时短暂变暗和轻微模糊，随后稳定。
- 2.15–3.75 秒：引导线展开，模块名分段显现，光标短暂闪两次。
- 前 4.25 秒：背景保持全显；4.3 秒起，标题、导航、任务单和左右面板陆续进入。
- 5.6 秒：结束入场层；正文不加入持续闪烁。动效均为有限次数，没有全屏闪白或新增视频。

复用已有背景，无新增图片下载或依赖。跳过按钮、Escape、Tab 以及减少动态效果偏好继续生效；同站子任务切换不重播。

- 字符在启动后恢复到稳定的完全不透明状态；所有特效均无无限循环。
- 重播不会替换任务单或计时器实例；计时连续，表单内容保留。
