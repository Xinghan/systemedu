# 晨光号：第一人称任务开场（Web 原型）

入口：http://localhost:4000/mission/rover

## 当前交付

- 独立、适配手机的 Web 体验。中国虚构工程师林岚面对学生讲话，第二个分镜指向任务画面；10 段中文配音，静音字幕、学生回应、镜头推进、通讯波形。
- 检查岩面、沙地和目标岩层；比较两条路线；发送计划后自主执行。直接穿越软沙触发保护停车，沿岩面绕行成功；支持暂停、后台暂停、改线重试。
- 抵达后取景、缩放、拍照。预览与下载采用同一个裁切计算，保存路线尝试与观察记录，刷新可继续。
- 完成后链接到原有地形、规则和探测车制作课程，没有改造原有课堂或增加课堂 tabs。
- 图片分镜与镜头动画，并非完整三维角色/口型动画。地形和行驶结果都是明确标识的教学模拟，不是真实火星影像、通信直播或物理仿真。

## 资源

最终图像位于 `packages/student-web/public/mission/rover/`，每幅有 960 宽与原尺寸 WebP。源生成尺寸 1672 × 941，较大档文件名中的 1920 为上限，未上采样。人物竖屏裁切使用原尺寸以免放大低清图。三幅原尺寸约 110 / 110 / 408 KB。

`image-prompts.md` 保存全部内置 image_gen 提示词；人物第二张采用保留身份的编辑。原始 PNG 留在 Codex generated_images，本项目消费的最终资产均已复制为 WebP 入库。

配音使用现有配置的 DashScope qwen3-tts-flash / Cherry（合成音色，不是真人录音或声音克隆）。`dialogue.json` 保存台词，`generate-voice.py` 使用现有配置，不含凭据。音频仅由点击“戴上耳机”或声音按钮开启。

## 保存边界

复用 LearningRecordSession，独立 scope：mars-analog-rover / OPENING / first-person-mission / classroom / 1.0。游客保存在浏览器；登录后使用现有草稿 API。不会提交正式课程成绩，不会自动导入其他身份的草稿。

账号接口验证使用浏览器模拟响应，没有写入真实学生账号。网络失败、版本冲突沿用现有会话处理，提供重试及备份入口；本机存储禁用时明确显示只保留在页面中。未进行生产部署。
