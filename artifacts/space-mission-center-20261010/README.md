## 保存与计时

复用现有 LearningRecordSession 和后端 LearningDraft；新增独立 scope：

`space-exploration / JOURNEY / mission-operations / classroom / 1.0`

`artifact.schema = space-mission-operations/1`。保存 `tasks`、`plan`、`time`、`events`；不向原课堂或任务档案 scope 写入数据，不代替作业提交/评阅。

登录账号通过既有数据库 API 自动保存；访客仅保存本机。账号隔离、版本冲突及备份恢复沿用既有机制。对无法读取的格式保留原记录，不用初始数据覆盖。

主动开始的前台工作才计时，10 秒检查点，离开页面/切到后台时暂停，每段最多 20 分钟；长于 2.5 秒的心跳间隔不计入，避免设备睡眠被累计。浏览器 Web Lock 限制同账号同时只有一个本机标签页计时。换设备发生版本冲突时停止计时并保留本机记录；不宣称跨设备分布式锁。最多可能损失一次未写入的短检查点间隔，例如页面异常终止或冲突发生时。

保存每任务累计、最近 730 个有记录日期的日统计、最近 80 段工作。日志裁剪不会扣减累计值。计时不代表学习质量，不自动记录过去、线下制作或打印等待的时间。

“自检完成”需要全部检查项、非空证据摘要且无阻碍；撤掉条件会退回自检。原课堂的提交/完成标记单独呈现，不自动宣称学生掌握。
