## 制作与来源

- 五个新人物镜头，由 Wan2.6 i2v 根据已认可的虚构中国工程师林岚首帧与新配音生成。使用项目既有 TTS 配置；每段保留原音频、提示词、脱敏任务 ID 与源视频。
- 共五个被服务接受的生成任务。第三段首次提交遇到 TLS 错误、未返回 task ID，保留 `attempt-1-tls-failure.json` 后明确重试一次。后续状态查询和下载的临时网络错误只重试查询/下载，没有重新生成已接受的任务。实际费用以提供商账单为准。
- 人物讲话后切静态说明段；没有额外生成环境视频或图片。第一、二、四段复用相应项目的已有概念封面，属于教学情境图。第三段使用课程 M06 实际可打印底盘的三维结构视图，截自本地课堂，未把复杂金属车当作学生制造目标。
- 第五段前半复用火星教学场景，后半复用 `systemeduidea/projects_data/lightkurve-transit-detective/practice/audit/lightcurve-development.png` 的 Kepler-10 Q3 课程分析图。两条高阶方向可独立选择。
- `scripts.json` 为讲稿；`generate.py` 保留生成流程（不会自动重提已有任务）；`capture-build.mjs` 捕获课程三维视图；`compose.py` 生成网页成片与字幕。
- VTT 按短句分段估计时间，未声称逐字强制对齐。音频波形检查确认人物段保留了作者配音，不构成口型质量认证；人物动作与自然度留待用户实际播放验收。

## 触发规则

- 首次进入地图对应成长阶段自动弹出；直接进入该阶段的微体验、引导课程、探测车任务中心或已有完整课程入口，也使用同一阶段视频。
- 一个阶段可以有多个地图站，02 的三个站、05 的两个方向共享各自的首次展示状态。不会把八个站误当作八个能力等级。
- 原通用火星序章保留手动播放；首次到访用新的阶段视频，避免连续弹出两段。
- 浏览器级 `systemedu:mission:space:stage-film:<level>:v1` 表示“已经展示过”，与旧开场键、账号作业和课程进度均独立。存储不可用时，本次客户端会话内避免重复；清除浏览器数据或换设备会再次展示。
- 到访、播放、跳过都不代表完成或掌握。进度未读完时不抢先为推荐阶段播放错误的视频；明确指定站点的入口不必等待进度请求。
- 可跳过、关闭、重播；播放完关闭弹窗。浏览器限制有声自动播放时显示明确播放按钮。隐藏页面暂停，后台首次打开不消费展示状态。视频加载失败仍可读任务文字和进入课程。
- 继续复用原课堂、资料下载、节点标识与作品记录，没有新增课堂 tabs。
