# 星际远航五段任务视频

用户授权：为整条项目线的每个成长阶段生成视频，首次到达自动弹出。

1. 五段各生成一个新的林岚真人风格对话镜头，复用已认可的角色首帧；任务说明段使用现有静态课程图，节省生成量。用当前项目配置的语音及 Wan2.6 服务，不记录密钥和签名 URL。
2. 每段包括问题、第一步与交付物。第三级强调数字原型之后必须完成 3D 打印实物；第五级明确自主工程与行星研究可分流。到访不等于完成前级。
3. H.264/AAC 网页视频、中文字幕、faststart，保留可复现脚本和脱敏任务状态。抽帧检查画面和音轨，实际动作与口型仍需用户播放验收。
4. 地图选择新阶段、带 station 的入口、直接进入该阶段课程，首次自动弹出；同阶段其他站不重复。将原来通用序章的首次自动弹出替换为阶段视频，保留通用序章手动播放。
5. 浏览器记忆已展示状态，与课程进度分开；存储不可用时会话内记忆。隐藏标签页不消耗首次状态。提供跳过、重播、自动播放受限时的播放按钮、加载失败的文字和退出入口。无新课堂 tabs。
6. 检查五段实际媒体、桌面及手机触发、同级去重、直达课程、后台与存储失败、学习记录不变；审查 diff 后仅提交本批文件并 push 当前分支。不部署。
