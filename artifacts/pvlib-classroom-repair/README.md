# pvlib 统一课堂修复验收

2026-09-29。此目录记录本地验证，尚未部署生产环境。

## 变更

- 正式页面和本地预览均使用 `PvlibCourseLesson`，通过 `CourseContentView.preparedLesson` 接入既有课堂正文、讲课模式和富媒体卡片。
- 移除四个媒体分类 tabs；旧 `view=lab/assignment/slides` 地址定位同一课堂内的卡片、作业或讲课播放器。
- 正文动画、游戏、硬件图解使用原有弹窗。可选 `CourseMediaContext` 为 pvlib 提供有来源校验的 iframe 消息接入，普通课程保持默认播放器。
- 保留 classroom、assignment、quiz、exam 的活动 ID、内容版本算法和账号命名空间。实验产物仍需学生明确关联到作业。
- 正文预览下载链接在展示层转换为资料下载区，正式下载继续使用已认证接口。没有改写用于历史记录版本计算的课程源文件。
- `AGENTS.md` 增加课程展示一致性的验收规则。

## 验证

`node scripts/verify-pvlib-classroom.mjs`：58 节全部通过，204 次记录范围检查，浏览器错误 0，未处理的模拟 API 请求 0。包含：

- 同一页面有正文、讲课播放器、课堂记录与作业；每个动画/游戏只保留一个正文锚点。
- 旧课堂记录可恢复；从真实沙箱 iframe 发出的模拟实验产物消息可以保存，并通过 ready/restore 协议读回；主窗口伪造相同消息被拒绝。该测试检查接入协议，不代表重新验收全部游戏的内部计算或所有游戏都支持恢复操作状态。
- 切换模拟账号后不展示原账号课堂记录和实验产物。
- 正文链接可到达正式下载区；下载 ZIP 的 SHA-256 与课程 manifest 一致。
- 390px 手机布局无水平溢出；讲课浮窗、翻页和退出后正文保留正常。
- M10 的硬件 3D 旧地址可打开同一课堂弹窗，不提供游戏成果提交；单独验证见 `hardware.json`。
- 本地 pvlib 预览与正式入口使用同一课堂；Lightkurve 的共享阅读器可以通过键盘打开、关闭默认媒体弹窗，没有使用 pvlib 保存适配器。

`node scripts/tests/pvlib-classroom.cjs`：下载链接修复不修改原始版本输入；正文资产和旧地址目标保持一致。

`node scripts/tests/pvlib-artifact-restore.cjs`：13 项实验身份、类型与数据大小边界检查通过。

`node scripts/verify-learning-record-session.cjs`：已有记录冲突与丢失响应保护检查通过。

本次新增/修改的 pvlib 组件和转换工具 ESLint 通过。全项目 TypeScript 仍有 16 项已有诊断；通过编译器虚拟读取修改前的相关文件进行对照，修改后仍为同样的 16 项，无新增诊断。没有宣称全项目类型检查通过。

## 范围与工作区说明

浏览器使用本机课程源文件、模拟账号及拦截的 API，不接触真实学生数据。生产鉴权和真实账号回归未在本轮重新执行。

原工作区已有共享课堂、讲课播放器等其他批次的修改。本次基于当前课堂验证，仅暂存共享 `course-content-view.tsx` 中本次增加的接入与媒体适配变更块；其他既有修改保持原状。因此截图反映当前完整工作区，不能将本批次提交单独视为已有全部共享课堂变更的发布包。下一次发布应使用包含这些既有课堂组件的完整候选版本并再次验证。
