# 分子寻药任务短片 v2：实验室与操作演示

重做八个任务站的视频。v1 的室内办公室人物镜头和静态房间讲述，改为真实实验室风格的人物镜头、三段与旁白同步的操作示意，以及可明确辨认的交付物。任务中心的无人房间背景继续使用已验收的 v2；人物只出现在独立短片中。本批次没有修改课程节点、任务地图或学习记录标识，没有部署。

## 素材与边界

- 4 张实验室人物首帧由内置 ImageGen 生成，提示词保存在 `image-prompts.json`，原图在 `originals/`。沿用虚构中国研究员陈澄身份，换为白色实验服和真实大学研究实验室。四个实验空间用于八段各自独立口播，避免重复生成不必要的图片。背景摄影风格画面是 AI 场景示意，不能作为实验设备使用、测量或分子结构的证据。
- 每站一次 Wan2.6 I2V 10 秒实际人物视频生成，成片取完整口播段；随后接不同任务站的 Canvas 动态教学序列。付费任务提交前保存意图并独占创建文件；查询、下载失败不能触发重新提交。任务状态文件只包含 ID、状态和本地结果，不保存凭证或签名下载链接。
- `visuals.js` 与 `render-demo.mjs` 直接绘制精确文字、数据和步骤。旋转模型使用现有 `biomed-data.json` 的咖啡因原子/键/坐标，注明计算模型。筛选示意使用 ESOL-0099 与 ESOL-1071 的现有 MW/logP，QC-MISSING 是教学故障卡；明确这里只显示三条卡片，不代表完整课堂验证集。
- 预测与模型比较数值、A12/A13/A14 关联、R01/R02/R03 清洗记录均为明示的教学示例，不是新跑出的科研结果。EGFR 标识 P00533 / CHEMBL203 来自现有 TeachOpenCADD M01 课程。
- 短片后半段展示的是操作原理动画，不声称是学生课堂实录，不增设课堂 tabs。仍沿用原有课堂富媒体、作业和任务状态。
- 每段说明单独生成配音，按实际音频时长切换画面。可开关中文字幕按短句估计段内时间，不宣称逐字强制对齐。画面下方留出字幕和播放器控件空间。
- 发布格式为 1080p H.264/AAC + faststart。首帧压缩为 WebP，访问当前任务才加载对应影片；不预加载八段视频。使用 v2 路径及独立 v2 已看标记，旧课程记录和旧播放记录保留。

## 复现

在仓库根目录使用现有 `.venv` 和 Node 依赖：

1. `generate.py voice` 生成口播与三个步骤的配音。
2. `generate.py submit` 提交八个独立视频任务；`fetch` 只查询/下载已提交任务。
3. `node render-demo.mjs` 渲染三步演示；可传站序号只渲染一站。
4. `compose.py` 合成人物镜头、演示、旁白与 VTT。
5. `verify-media.py` 与 `verify-browser.mjs` 验收媒体和接入。

这些 Python 文件均位于本目录，应带路径调用；生成、合成脚本支持 `--level N`。服务调用沿用当前配置，不将任何密钥写入产物。每次调用有产生内容或费用的可能，历史任务有状态时不会重复提交。
