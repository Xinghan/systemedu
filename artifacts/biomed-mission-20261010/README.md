- `verify-browser.mjs`：本地访客持久化、模拟账号恢复、日期/日志/档案、跨课程引导、320/390 px。

- `verify-scenes.mjs`：八张独立场景、5.6 秒入场、跳过和减弱动态、项目库与微体验入口。
- `verify-types.cjs` / `verify-lint.cjs`：以 ae3ac9ee 为基线。现有 TypeScript 6 项、ESLint 2 项既有错误不属于本次改动；无新增诊断。
- `space-regression.json`：原有星际远航完整回归通过，包括账号切换、CAS 冲突恢复、跨标签页计时锁和旧记录。
- `build-verification.txt`：实际生产构建输出。项目配置跳过内置类型检查，因此单独保留类型对比结果。

所有提示附加统一约束：成熟、写实的第一人称科研场景，真实屏幕内的分子可视化，无文字/水印/悬浮全息；无化学实验或昂贵实验室设备要求。首站导师为中国女性虚构研究员，八站构图各异。
