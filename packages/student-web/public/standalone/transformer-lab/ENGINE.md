# 自主算法可视化引擎

更新：2026-10-23。入口：`/standalone/transformer-lab`。

## 本次自主实现了什么

- TypeScript 前向计算：查表、位置相加、Pre-LN、Q/K/V、多头因果注意力、稳定 Softmax、拼接与投影、tanh 近似 GELU、MLP、残差、词表投影、greedy 生成。
- 算法计算图：完整张量、中间运算、输入依赖、每个输出元素的公式与乘加项。
- Three.js 3D 场景：张量布局、数值着色、格子拾取、窗口移动、上游追踪、播放与时间线、相机控制和资源释放。
- 第二个算法：二维互相关（CNN 中通常称卷积）。4×4 输入、2×2 核、stride=1、padding=0。修改输入、观察不同滑动窗口及其逐项乘加，与 Transformer 使用相同渲染器。

页面不再加载 Bycroft 的场景、动画或 WASM 推理实现。源码位于 `packages/student-web/src/lib/algorithm-viz/`。

## 如何迁移到其他算法

计算适配器输出 `AlgorithmGraph`：节点拥有 `id / data / op / inputs / position`。`explainCell` 根据真实索引构建依赖和公式。渲染器只接收张量、布局及依赖；不编写 Transformer 或卷积的专属分支。算法适配器决定布局和播放顺序。

1. 实现算法计算，保留有教学价值的中间矩阵。
2. 将每一步映射成图节点和依赖；已有运算可复用，新运算增加对应的逐元素解释规则。
3. 配置适合算法的空间布局、单元格比例与播放顺序。
4. 用可手算案例及独立实现验证数值，再连接概念、题目和代码练习。

`convolution.ts` 是已经接入的第二种算法。扩展并非自动读取论文就生成正确动画；新的数学算法仍需要实现与验证。当前抽象针对二维张量运算，图搜索等非张量算法需要扩展可视化对象协议。

## 阅读与操作

- 点模块进入局部图；鼠标左键拖动旋转、右键拖动平移、滚轮缩放。也提供缩放/旋转按钮。
- 点击格子或输入行/列索引：金色标记为输出，绿色标记为当前窗口可见的输入依赖。展开乘加项可读完整数值；“继续向上游追踪”可打开输入张量及其直接来源。
- 一个大矩阵最多显示 8×12 个元素；标签保留完整形状及当前行列范围。精确索引会移动窗口。隐藏的元素仍参加完整计算。
- 实线表示直接依赖；虚线跨过局部视图折叠的中间运算。3D 全貌只展示主要节点，可逐模块展开。
- 颜色与高度按各张量内部的绝对值范围编码，负值使用棕色。不能仅比较不同张量的颜色深浅来比较数值。
- 播放是在已完成的前向计算上逐格讲解，并非训练或展示 GPU 执行时间。JS 使用双精度运算，权重为 float32；输入最长 6，生成后的总前缀最长 11。每次追加都重算，无 KV cache。
