## 三个独立的接口

第一，08:00Z 和同一天 16:00 UTC+08:00 是同一时刻。转换用于对齐；记录中仍要保留原时区。

第二，0.038 mg/m³ × 1000 = 38 µg/m³。这里只改变表达单位，不表示突然增加了污染。直接删掉单位再画图，会让人比较不兼容的数值。

第三，用记录的 P1/P2/P3 找地图上的同名点，不用“第一行配第一行”。行的排列可变，稳定 ID 才是接口约定。

## 每次只修一项

先保留故障，再改一项接口，重新运行，看哪些问题消失、哪些仍在。若一次把所有控件都切换，虽然可能成功，却很难证明每个改动解决了什么。最终至少保存当前来源下失败与成功两版。

空气课程带来的平均窗口也应写进解释。经过多小时平均的 P2 不能被当成该时刻的瞬时读数；接口检查通过只说明这三项约定对齐，并不保证所有比较都有科学意义。

## 不擦掉过去

修复后当前预览会变化，已保留的旧实验不变。这个差异是有意设计的：我们要能回到“当时用了什么”，而不让新配置悄悄改写旧结果。
