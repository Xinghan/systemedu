## 从一句话回到三个层次

第一层是**接口事实**：08:00Z 是否正确变成 16:00，本来的 0.038 是否正确变成 38，P1 是否回到入口。可以用手算和 ID 表验证。

第二层是**当前资料的观察**：这些教学记录在某种处理方式下有怎样的差别。你要保留资料版本与平均窗口，让别人复算。

第三层是**原因解释**：差别是否由树木、车辆或天气导致。当前练习没有完成这个实验，所以第三层仍是假设。不能因为前两层通过，就自动宣布找到了污染原因。

## 写一句有证据的结论

可写：“修复单位后，P1 从误显示的 0.038 回到 38 µg/m³；点位由行号改为 ID 后回到入口。这个过程只证明数据接线一致，不能证明入口数值变化的成因。”

再想一个可能改变判断的反例：如果复测时两处差异消失，或仪器互换后高值跟着仪器走，你会怎样修订解释？你的档案要允许新证据推翻旧结论。

## 选一个下一步

可以追加同步、同方法测量，也可以先核查仪器质量。选择最能区分当前假设的一步，不要用“收集更多数据”代替具体计划。
