## “能运行”不是“接对了”

导出包故意留下几处常见错配：UTC 时间、本地时间的差异；毫克与微克的单位；表格排序改变之后的地点身份。所有数字看起来都能正常显示，所以只检查页面有没有报错是不够的。

先在默认接口下运行，留下第一次失败。然后写一个你自己的故障假设，例如：“三个记录的点位顺序变了，也许程序按行号放到了错误位置。”它是可检验的，因为查看 ID 就可能支持或推翻它。

## 探查要选得有理由

“时间元数据”揭示时钟约定；“原始单位”揭示数值比例；“点位索引”揭示记录如何找地点。至少选择两类，说明它们各能区分哪一种原因。不是把全部按钮点绿就等于完成诊断。

假设被推翻并不丢人；留下原假设、读数与修订，比事后说“我早就知道”更诚实。不要清除第一次错误，它会成为最终档案里说明修复价值的对照。
