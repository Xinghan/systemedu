## ID 比排列位置可靠

观测卡给出了 P1 入口、P2 树荫和 P3 池边。它们的 ID 是资料之间的连接键。把表格排序以后，“第二行”可能不再是 P2；ID 仍然应指向同一个位置。

三张卡都来自教学设定，所谓“预置测量”是练习中给定的测量记录类型，并非学生亲测。P3 明确属于估计。你选择证据类型后，点的颜色和图例随之改变，别人可以看出哪些结论值得回到原始记录核对。

## 一个常见误会

假设 P3 写着估计 26。把它改成“预置测量”不会让数据更可靠，只会抹掉重要的来源信息。也不能因为图上没有画点，就把整片区域涂成低值。**未记录的地方是未知**。

## 放置与核对

分别选择 P1、P2、P3，按卡片的坐标与类型放置。回看下面记录表，从 ID 找到位置，再从位置找回卡片。最终作品保存的是你的点位选择，而不是一张失去来源的装饰图。
