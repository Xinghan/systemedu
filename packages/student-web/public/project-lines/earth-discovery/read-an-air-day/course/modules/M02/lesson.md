## 两种完全不同的空白

零表示收到一个数值为 0 的结果；缺测表示没有收到可用结果。工作台在 12:00、13:00 留了空缺。它可能对应断电、通信失败或被质量检查剔除，但这份合成数据并未提供原因，你不能替它编一个。

如果把空白补成零，折线会突然跌到地面。这个深谷是处理程序造出来的。即使平均数更低，也不能说空气变好了。选择“错误对照：补零”看一次，再恢复“保留空缺”，两个结果都可以留下，失败的版本也有教学价值。

## 一次具体判断

原始表在 07:00 有 38，06:00 是 23，08:00 是 31。这是一个值得检查的高点，但光凭它高不能删除它。先标记，再问是否有校准、另一台仪器或现场活动记录。**保留原值与标注**比悄悄擦掉尖峰更可复查。

## 亲手识别，而不是点击答案

使用图上的读取线或小时选择器，逐点看原始数据。分别选择最高点和一个缺测时刻。系统检查的是这份教学序列中的对应位置，不会替你判断真实环境是否安全。你的最终报告必须让别人还能看见原始峰值与空缺。
