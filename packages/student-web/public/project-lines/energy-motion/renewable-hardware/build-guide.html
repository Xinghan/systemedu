把风和阳光接到自己的小装置

先做单模块实验，再做风光储整合。自制结构一律 3D 打印；电子器件、电机、螺丝和简单轴件可以购买。这里不需要金属加工，也不接家庭电网。

当前验证状态：课程、模型与打印文件提供数字检查。硬件方案尚未做真实样机验证，默认 STL 是基础板件，不是打印后就能直接组装完成的套装。封面为生成的设计示意；实际尺寸、接线、结构强度与输出必须由自己的器件、CAD 与测量确认。保存数字原型后可以暂停等待器材。

1. 先看真正的能量路径

这是轮流利用太阳能与风能的教学拓扑，不是直接并联两种未知电源，不包含并网逆变。浏览器“择较大一路”是理想策略，实物默认由手动开关选源。自动择源或两路独立采集属于进一步设计，需重新核对防反灌与功率预算。

3. 核对采集板，建立第一条回路

  1. 使用 厂商快速入门和对应数据表核对版本与跳线。原装单节超级电容默认配置（VCF=100）上限 2.70 V、准备阈值 2.30 V、欠压阈值 2.20 V，H_OUT 1.8 V、L_OUT 1.2 V。手册或到货版本不一致时先停止接线，按那一版重新设计。
  2. 先只接原装太阳能板与原装电容，不接控制器、风机或舵机。保持默认配置，电压表观察电容充电与输出。室内弱光可能等很久；数据表最大输出电流不等于光伏板此时能够提供的功率。
  3. 将 4.7 kΩ 接在 H_OUT 与 GND 之间，电压表并联测负载端。先核对表笔插孔和直流电压档，不把电流档跨接电源。
  4. 光被遮挡后，每 20 秒记录负载电压和电容电压；注明端口。测电容时不要短接裸露引脚。
  5. 风机先独立接电阻测试。所有计划风速下，输出极性须固定，开路电压必须低于模块输入上限 5 V，且能启动采集。尚未证实就保持独立实验；不能把“模型有输出”当接入许可。未知过压需另行稳压保护设计，本模板没有替你验证。
  6. 关断回路后，把已经核对的两路源接到先断后通开关，再接模块采集输入；地线与极性按实购模块手册。默认系统不装后备电池，不自行尝试裸电芯充电。

4. 打印包怎样使用

默认 STL 模板包 · 可编辑 OpenSCAD 源 · 尺寸与数量清单

  1. 先在 CAD 中选择 part="fit-coupon"，按实测轴径设置 bore。三个孔依次为名义值 −0.1 / 原值 / +0.1 mm。平面向下切片，检查边界、层厚与细壁，没有打印过的参数不要直接当制造公差。
  2. 记录哪一个孔能装、能转、有无晃动。保留第一次结果，再改一个尺寸重打；这个试配记录是作品的一部分。
  3. solar-tray 是 51 mm 背托，默认对应约 45 mm 面板；用可移胶垫固定，不钻穿电池片。upright 平放打印，用自己设计的角码接底座；补上枢轴固定、角度止挡与导线余量。
  4. 风轮的三个 blade 使用相同打印设置。轮毂按实际轴和联轴方式改孔，安装 pitch-wedge 设置角度；楔块需按根部与实际螺栓添加孔与防转定位。默认楔块仅为截面示例，不是一颗螺丝就足够的最终固定方案。
  5. 两个 guard-ring 只是护圈模板。必须自己补上支柱、细网格与固定座，防止手指触及叶片；完整护罩未完成就不做有动力测试。叶尖间隙用自己的尺寸检查。
  6. 所有 STL 单位 mm，平板大面朝下；叶片长轴平放。建议先 0.2 mm 层高、3 圈壁作为切片起点，按材料与实测调整，不保证适用所有打印机。不要为了追求转速取消护罩。

尚缺的角码、止挡、特定电机座、完整护网、电子托盘，是本课需要完成的设计任务。可以选择自己熟悉的 CAD，但最终要保留可编辑源，而不只是截图。

5. 独立供电的控制器

Uno R3 阈值控制起点只支持阈值方案，未进行实物编译上板验证。浏览器 DSL 可验证逻辑；需把最终 pause、resume 和 missing 选择明确抄入程序常量，并在实物验证。04 的历史学习预测仍在浏览器实验，不假装已经迁到板端。
