## 一张图片，也有自己的身份证

开始观察前，先问三个问题：谁拍的、用什么设备、画面覆盖多大范围。轨道器从高处看到大片地表，车上的相机看到近处的石块；两张图即使在屏幕上一样大，也不能直接比较石头有多大。

工作台提供三张真实影像：PIA23386 是 Jezero 的轨道影像；PIA20755 是车载相机看到的沙丘波纹；PIA06323 是轨道器看到的层状露头。点击图片下方来源，可以找编号、设备与处理说明。来源不是装饰，它让别人能找回你观察的同一张图。

### 一个可推演的例子

假设甲图宽度表示 3 km，乙图表示 3 m，两张图在屏幕上都宽 300 像素。甲图中的 30 像素对应 300 m，乙图中的 30 像素只对应 0.3 m。这个例子的数字用于练习比例，不能套到没有比例尺的图片上。

| 信息 | 它帮助回答什么 |
| --- | --- |
| 影像编号 | 能否找回同一张原图？ |
| 仪器与视角 | 从高处看还是从地面看？ |
| 比例尺或覆盖范围 | 能否比较真实尺寸？ |
| 拼接、颜色或亮度处理 | 画面和肉眼所见是否相同？ |

**反例**：“这张更大，所以那里的山更高。”没有相同尺度，这个结论没有依据。先说“屏幕上更大”，再查实际范围。

这一节只做来源卡。你的作品不是拍摄这张 NASA 图片，而是记录它的身份，并选择自己接下来想研究的特征。
