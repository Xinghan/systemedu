## 失败后，先找最值得改变的一项

默认方案的能量不足。你可以增加初始能量，也可以调整路线或目标。选择哪种修改，要回到任务目的：如果问题必须在扇形沉积目标观察，就不应只为过关随便换地点。

假设目标保持扇形沉积，24 点初始能量：捷径需要 34 点，不能完成；缓坡需要 22 点，返航余量 2 点，满足本课要求。这个比较保留目标和电量，展示了路线选择的影响。

若车辆行动链本身没通过，增加电量也不会修复识别错误。这时应返回组装项目定位问题，再交付修正版，回到远征重新读取。新的输入模块需要新的运行证据。

### 最终作品应该让别人能复查

作品包含车辆模块快照、观察目标、装备来源、修订前后参数、逐步日志和预算结果。你的说明要指出一个由证据推动的修改，而不是笼统写“我完成了全部任务”。

交付后可以继续到已有真实火星车课程：候选图像、规则思路和测试方法可作为起点，但实体组装、电机控制、真实视觉输入与场地测试仍需重新验证。模拟成功不会免除这些步骤。

**反例**：“两次通过，因此任何任务都能完成。”只要换了地形、负载或观测要求，就可能需要新证据。把尚未验证的问题写出来，是这一轮远征的一个有价值的终点。
