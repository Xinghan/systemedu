## 先冻结任务，再采集证据

确认当前预算通过后，冻结现场任务。冻结把观察目标、路线、任务长度和车辆提交版本对应起来。改变目标或读取另一辆车会让旧现场记录失效；重新冻结不同方案时清空旧草稿测量与照片，先备份。已经正式交付的作品仍独立保留。

## 整车尺寸来自测量

用尺量包含轮子、轴、保险杠和外伸部件的最大外宽，不能用底板 CAD 宽度替代。量现场最窄通道并留出转向和测量误差的余量。平台只核对通道大于整车宽；这个数值不保证车辆能转弯，你还要做低速实际检查。

在地面标出基地、观察区和返回区，用胶带标方向，用软物体作障碍。先不通电，用手缓慢移动断电车辆检查通道是否挤线、保险杠是否会卡住。不能在桌缘和楼梯附近试车，也不要用松散沙粒模拟火星。

## 写出别人可以重建的布置

路线说明应包含起点、转弯、观察点、返回点和成人站位，不需要长报告。例如纸面迷宫可以用“向前两格，左转，经过宽门”描述；你的现场需要真实厘米、毫米和位置关系。

孩子负责量尺寸和调整布局，成人确认电源开关可达、场地内没有人和宠物，并协助第一次运行。让现场要求适应当前车辆能力；不是给车设置一条必须高速冲过去的赛道。
