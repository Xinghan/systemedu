## 计划地图不能冒充完成轨迹

地图可以在运行前显示目标和拟走路线；这只是计划。真正的证据来自按当前车辆、路线、装备和能量执行后的日志。未通过时保留未完成状态，不能把虚线计划说成已经走过。

每次远征先复核车辆的短途行动链，再核对目标距离、路线耗能、观察相机和返航余量。带入的运载清单决定相机是否可用；如果没有带入清单，则使用标明来源的平台相机。

### 把三个来源写清楚

真实影像：来自 NASA/JPL，是你选择科学问题的材料。虚拟地图：来自本课设置，是运行目标的位置。模型遥测：是规则计算得到的路段数和能量点，不是传感器从火星传回的数据。

这三者可以放在同一份作品中，但不能混成同一种“实测”。工作台的观测示意与目标记录也只是教学场景，不能当作原图位置的现场照片。

**反例**：“看到绿色路线，所以车真的到了 Jezero。”本课没有控制真实车辆。正确说法是“我这版配置通过了指定教学任务的检查”。

打开两次日志，核对配置、目标和结果是否对应。若改变了目标或电量，要重新运行，旧版本的结论不能自动沿用。
