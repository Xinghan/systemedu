## 任务预算会消费车辆参数

系统读取你已提交车辆的轮子、电池和结构来计算每段消耗与可用容量，不能随手给远征一个与车辆无关的无限电池。捷径路段更少，但有凸起与额外消耗；宽缓路线增加两个路段，却降低额外地形消耗。小轮的捷径通过能力与大轮不同。

工作台的路段数包括去程和返程。总消耗等于往返路段数乘每段消耗，再加路线与观察开销，最后检查是否留下任务预留。数字点数只是教学预算，不能把十点换算成真实电池的十分钟，也不能按浏览器结果决定实物电机电压。

## 比较两种可解释的方案

先跑第一版，记录为什么失败或为什么余量紧张。选择路线、任务长度或预留中的一项修改，再跑并比较。即使第一版通过，也应比较另一种方案，说明为什么选择最后一版。

如果任务总是超出车辆能力，可以缩小观察任务；也可以回上一课重新设计、制造和测试车，再正式提交新车后读取。不能只改远征页面中的摘要，假装硬件已经升级。
