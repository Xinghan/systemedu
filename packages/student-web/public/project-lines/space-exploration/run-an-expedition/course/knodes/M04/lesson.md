## 分段执行，同一任务完整记录

先复查触碰输入和架空停止功能，再在围定场地低速出发。现有程序每次动作需要重新确认，定时转动不保证固定角度。按计划逐段前进和转向，到观察点完全停止后由孩子拍照或描述真实目标，再按自己的路线返回。

记录累计路程与总用时，注明测量方法；用时可以包括停下来观察的时间，但两次尝试要用同样口径。没有到达或没有返回就选“否”，说明卡在哪一步。不要用数字预算结果填实测栏，也不要在车还在移动时靠近轮子拍照。

## 任务失败常在接口处

单独转向能通过，接在一段前进后却可能偏出门口；单独停止能通过，保险杠在斜着进入障碍时可能没有触发。先记录现象，按输入、判断、执行的顺序查证。需改电路或结构时断开电源，参考制造手册重新验证，再恢复任务。

选择一项改进，比如根据地面实测缩短转向时间或把观察区移到有足够停止距离的位置。说明是程序调整还是场地调整。若改变核心车辆或任务方案，应返回相应节点建立新版本并重新冻结；不能让旧测量冒充新版结果。

## 再做一次，不抹掉第一次

至少保留两次完整现场尝试和中间的调整。第一遍也可能成功，此时可以改善停靠位置或测量方法，但仍要说明依据。最终至少一次达到观察点、留下具体观察并返回基地，照片和原始记录留给自己复盘及老师评阅。
