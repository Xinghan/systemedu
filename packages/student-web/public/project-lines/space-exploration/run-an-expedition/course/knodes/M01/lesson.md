## 从“车会动”到“带回结果”

上一课验证了前进、转向和触碰停止。这些是独立动作，远征要把它们按目的组合：从基地出发，到观察点停稳，留下观察，再返回基地。一次任务必须同时考虑场地、车辆、操作和证据，不再分别点击几个按钮就算完成。

选择一个地面观察任务，例如比较两块地垫的表面纹理，或记录两块石头的外形。限定任务范围，不把家中地垫说成真实火星土壤。孩子可以在车停稳后拍照；本课的实物起步车没有自主相机，不会自己识别矿物。

## 用已有作品作起点

读取上一课正式交付的 2.0 实物探测车。这里带入已提交版本的轮子、结构、电池等数字设计参数和制作摘要，用它们计算任务预算。原始实物照片和完整测试仍保存在上一课作品里；这次要采集新的现场证据。

没有实物交付时可以先阅读和写任务，但不能把旧版虚拟车或平台默认车记作自己的实物成果。回到制造课补齐真实作品后再继续。

## 定义结束条件

例如图书运送任务可以是“从桌边到书架，交一本书，再空载返回”，而不是“绕房间跑”。你的探测任务也要写清目标位置、要观察什么和带回什么。出发前与成人确认可围定的地面区域、软障碍和停止方式。
