# 探测车视觉制作说明

视觉版本：mars-expedition/2。采用航天工程展品与野外勘察结合的方向：第一屏看清车辆与动作，前往目标时能判断路线，近看能辨认机械连接。

- 主体：六轮胎面、轮毂和辐条、相连的悬挂杆与关节、隔热车体、甲板紧固件、相机桅杆和光学镜片、天线、散热结构、线束、收拢的观测臂。它是程序建模的概念车，不是某一 NASA 火星车的精确复制。
- 地表：近处砂纹和细碎颗粒、中景带层理的岩石和沙丘、连续远山；障碍只从 GRID 创建，装饰碎石不改变碰撞。低矮障碍保留绕行含义，也减少对车身的遮挡。
- 观察：跟随、全景、近看、拖动、环视与缩放独立于驾驶；近看收起导航和取景窗。SVG 导航取实际地图、路径与镜头方向，手机把覆盖物移到画面上部。
- 运动：轮组随位移转动，车体按行进方向转向，桅杆根据相机朝向独立转动；视觉插值不改变碰撞、可拍照条件或记录。
- 拍照：车载相机按逻辑位置和朝向渲染，拍摄前立即对齐，排除动画中间态。主观察视角不改变照片。实时取景 480×300，导出为 960×600；作品保留 drive-and-frame/1，并追加 visual_version。

几何与材质复用，胎纹、紧固件、碎石及车辙使用实例化；第二视口按需更新。软件渲染降低像素比，正常硬件保留更高分辨率。闲置和隐藏页面不重复绘制；退出或图形降级释放 GPU 资源。WebGL 不可用时将精细 SVG 车辆和同一逻辑地图绘入 Canvas，继续驾驶、取景与保存。

全部模型、矢量和纹理由本项目制作，Three.js 来自本地 MIT 包。[NASA 探测车仪器资料](https://science.nasa.gov/mission/mars-2020-perseverance/science-instruments/)用于辨认组件功能类别，未采用其外部视觉资产。比例、地形、地图尺度和悬挂运动均作了教学简化，不能用来证明工程性能。

验收：正常/近看/手机/驾驶/导出/降级截图，连续输入后立即拍照，改变主视角而保持车载照片一致，路线恢复，图形中断后继续拍照，实际帧间隔记录。证据位于 verification/visual-quality/。真实平板、Safari 和儿童试用另行验证。
