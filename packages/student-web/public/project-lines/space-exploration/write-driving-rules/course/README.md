# 驾驶规则多节点课程

这是原单页规则实验的课程升级：四个有独立目标、学习正文、参考资料、视频任务、实践和输出的节点，累计 50 分钟为设计目标，可分次学习。未声称经过儿童时长验证。

采用现有课程的 tree/knowledge_tree.json、knodes/<id>/lesson.md 与 assignment.md 组织方式。guided-course/1 是本地课程内容格式，尚不是完整课程工厂的 5.0 导入包；学生网站已接入账号学习记录保存，但不将提交当作掌握评定。resources.json 保存来源、核对时间、阅读/观看目的、任务及中文备用要点。

NASA 视频与 Code.org 材料保留原始来源链接，不重新托管或冒充自制内容。正文是本课程编写的教学解释；外部材料是补充观察对象。英文资源有中文引导和备用要点，视频播放依赖来源网站和网络条件。

现有 HTML 仅作为 M02–M04 的实验工具。单独通过实验不会使全部节点提交；学习记录只称为个人记录，内容质量不由字数或点击自动判为掌握。

## 课堂回答的交互设计（学生网站）

`tree/knowledge_tree.json` 的每个节点可提供 `response_prompts`，与 `questions` 一一对应。每项包含 title、hint、example、fields，按学习任务选择 choice、short、text；对照任务可使用 comparison 布局。不要将所有题默认生成为大段文本输入。

- 观察/判断：明确选择对象，再用自己的话写一句理由。
- 条件规则：让输入条件与执行动作分别填写。
- 实验：预测和实测分开，修改前后同条件比较；不预填成功结果。
- 交付：贡献、实际测试与平台提供的部分分别说明。
- 每项提供标明用途的例子，优先用相邻生活场景演示表达方法；示例不能进入学生答案或算作完成。
- 提示放在字段旁，不仅依靠输入后会消失的 placeholder。保留自由表达方式；已有文字不能被新结构自动拆分或覆盖。
- 正常学习使用账号自动保存；下载、历史和旧记录导入收进记录选项。存储/网络错误直接显示恢复操作。

结构化填写与可读文字一同存入原学习记录：正文沿用 answers，字段保存在 client_context.guided_response。表单布局升级不改变课程记录 ID，原有回答继续可读。

## 与正式课程保持一致的展示

引导课程沿用主站 globals.css 的字体、纸色、主色与边框变量，不在课程范围内重新定义同名 token。卡片使用 12px 圆角、控件使用 8px 圆角；参考资料采用来源图标、标题、阅读目的的层级。

视频交给 CourseVideoResource 展示，使用实际视频封面和中央播放按钮，点击后进入弹层。resources.json 可提供 poster_url，应来自原始发布页对应视频，不使用项目宣传图替代视频画面。当前四张封面于 2026-09-20 从 NASA 资源页的 og:image 和 Code.org 的 videooptions.thumbnail 核对取得，继续引用官方地址，不重新托管。

每个视频同时提供观看目的、观察问题、来源与中文备用提示。封面或视频不可用时也保留学习路径；打开或观看视频不自动提交课堂记录。

## 最终交付物（spec 055）

非三分钟项目必须在入口说明最后能交付的作品、如何自检和返回查看的位置。当前知识树的 final_deliverable 配置定义作品名、交付节点、组成和验收说明。驾驶规则课程在 M04 生成作品卡：四行规则、同版本双路线证据、未知处理与贡献 / 测试范围 / 平台能力说明。

作品卡复核已关联实验的规则和完整步骤，不接受只有 passed 标记的空证据。结构化说明中选择的 unknown 动作不得与停止规则冲突；其余解释只检查填写完整，不自动评分。学生可展开两条路线记录进行自检。

项目交付复用 learning records，scope 为 write-driving-rules / M04 / final-deliverable / assignment / 1.0；与 reflection / classroom 分开。提交保存作品和说明快照，账号保留历史，后续笔记不会改写已提交作品。游客仅保存本机最新作品并明确提示；导出仍是次要备份入口。后续其他课程应按作品类型实现自己的验收与展示，不能套用驾驶规则验收器。
