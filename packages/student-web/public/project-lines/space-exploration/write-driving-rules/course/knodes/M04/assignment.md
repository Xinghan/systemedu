## 交付任务

1. 为 unknown 指定停止分支，重新测试当前版本。
2. 在工作台保存作品，再到下方「我的探测车驾驶规则作品包」点击「关联实验作品」。
3. 写出“输入/输出、测试范围、平台提供的部分”三项说明。
4. 在最终作品区核对自己的四行规则，展开训练路线和换路测试，确认步骤对应同一版规则。
5. 三项验收都具备后，点击「提交项目作品」。未登录时按钮为「保存项目作品到本机」；登录后作品单独保存到账号，包含规则、测试证据和说明的完整快照。
6. 之后从课程开头「查看我的最终作品」回到这里，展开「查看上次交付的完整作品」。需要离线副本时，再从记录选项导出。

「提交本节学习记录」保存课堂回答；「提交项目作品」才是这门项目的最终交付。之后修改笔记，不会覆盖账号里已交付的作品版本。

**自检**：记录来自当前版本；两条路线的实际结果都保留；遇到未知时停止；能说清模拟边界。课程显示的是“学习记录已提交”，不是自动评定已掌握。
