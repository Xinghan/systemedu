# 我的第一张星球照片

首个可运行的三分钟入口项目。项目 ID：`spot-a-world`；作品 ID：`sky-observation`。

## 孩子怎样开始

打开后直接进入观测台，月球已作为默认目标，也可选择火星。拖动天空或点方向按钮，把目标移进取景框；调整一次放大倍率，按快门。取景不需要精确居中，完整主体留在框内即可。

完成后得到自己取景的照片，可以选择一句观察亮点、下载照片与记录、重新拍摄。相册保留最近 6 张，支持重新查看和恢复镜头。

- 面向首次接触的孩子，不需要编程、安装、注册或材料采购。
- 成人只需打开页面并确认设备能操作；请把镜头操作交给孩子。
- 3 分钟是设计目标，尚无儿童试用数据。年龄暂按 10–12 岁设计，待真实试用校准。
- 支持鼠标拖动、触屏拖动、方向按钮、画布聚焦后的方向键；不需要相机、麦克风或定位权限。
- 进入后的指南由本地状态规则提供；当前没有接入在线 Agent 对话。

## 运行

学生系统入口：`http://localhost:4000/project-lines`。

直接体验：`http://localhost:4000/explore/space-exploration/spot-a-world`。

独立内容包由此目录内的 `index.html`、`styles.css`、`app.js` 和 `vendor/` 组成。需通过 HTTP 提供文件；模块脚本不承诺支持直接双击 `file://`。返回按钮链接学生系统 `/project-lines`，独立预览时该导航需要宿主提供。

使用本地 Three.js 0.184.0 渲染场景，所有依赖随包提供，没有外部素材请求。无 WebGL 时提供 Canvas 2D 简化画面；可用 `index.html?renderer=canvas` 检查降级路径。桌面 / 平板优先，小屏手机有响应式布局。

## 作品契约

记录格式：`schema_version: "spot-a-world/1"`。作品标识 `artifact_id: "sky-observation"`，来源 `origin: "simulated"`。

| 字段 | 内容 |
| --- | --- |
| `image` | 实际画布取景框裁剪所得的 720×720 JPEG data URL |
| `target`, `target_name` | 本次选择的月球或火星 |
| `view` | 镜头 yaw / pitch（弧度）、倍率、当次视口与裁剪范围 |
| `note` | 可选观察亮点，不要求手写报告 |
| `evidence` | 亲手移动 / 缩放、目标完整入镜、页面内经过时间、最近 200 条操作及本次观察选择 |
| `provided_modules` | 平台预置的天空、控制和提示模块 |
| `provenance` | 渲染方式、程序纹理来源、场景版本与固定随机种子 |

提供两种下载：带标题和模拟说明的 PNG 照片；包含图像和元数据的 JSON 观测记录。不能把 `elapsed_ms` 当作已验证的学习时长。

本机存储键：`systemedu:spot-a-world:v1`。同源 iframe 与独立静态页面共享相册；不同浏览器、端口或域名不自动同步。刷新后能找回作品；清理浏览器数据会删除本机副本。存储故障会明确提示下载，不显示“保存成功”。恢复镜头使用原目标、角度和倍率，并适应当前屏幕；原照片保持不变，重新拍摄仍需新的手动操作。

这些记录尚未接入学生账号、成长档案或下游项目导入。作品字段为后续适配准备，不表示已经完成跨项目传递。

## 完成证据和边界

快门只在本次目标经过手动移动、手动调整倍率、完整入框后可用。系统保存当次画布，而非替换成预制照片。程序提示不会移动镜头或自动完成项目。

场景、天体位置、比例、光照与表面纹理均为教学模拟；不代表真实天空、实时天文数据或望远镜摄影。月球明确为地球的天然卫星，火星明确为行星。Three.js 使用 MIT 许可，许可证位于 `vendor/LICENSE`。

自动浏览器验收脚本在学生系统仓库 `scripts/verify-spot-a-world.mjs`，产物在 `artifacts/project-line/spot-a-world/`。自动测试作品应标为测试样例，不能作为儿童学习证据。当前验证 Chromium 桌面与模拟触屏，Safari、真实平板和儿童独立操作仍需试用。

## 首轮试用观察

请先不讲解操作，观察孩子首次动手的位置、多久主动求助、是否明白快门为何未亮起。完成后只问“这张照片里哪一部分是你决定的？”并请孩子再次打开自己的作品。记录卡点后再决定是否收紧或扩展引导。
