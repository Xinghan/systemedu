# 我的实物探测车 · 制造与调试手册 2.0

本课交付一辆自己改过打印件、改过程序，能够前进、转向、触碰停止的双轮差速车。数字原型可以先完成；实物制作和实测是正式交付的必要部分。相机识别与六轮悬挂放在后续完整火星车课程。

**参考设计状态：文件网格和程序逻辑已检查，尚未完成首台实体样机试制。** 通用孔槽不能保证匹配任意商品支架。先测器件、打印小试配片，再修改完整结构。不要把浏览器里的质量和能量点当成器件规格。

## 家庭开工单

孩子负责：选择方案、测量安装尺寸、修改 CAD、比较打印试配、修改程序、记录原始测量。成人负责：采购规格核对、首次供电检查、打印机热端与需要焊接的接头。没有打印机可使用学校或代打服务；采购、排队、打印冷却不计入课程学习时长。

| 器件 | 数量与规格 | 采购前核对 |
|---|---|---|
| 控制板 | Raspberry Pi Pico H 或焊好排针的原版 Pico，1 块 | 本课程序针对 RP2040 Pico，不能原样用于 ESP32；USB 数据线接口适配 |
| 驱动板 | Pololu DRV8833 carrier #2130，1 块 | 按该板端子标签接线。其他 DRV8833 板的引脚排列、SLP 和保护电路可能不同 |
| 电机 | Pololu 100:1 Micro Metal Gearmotor LP 6V #992，2 个，或经成人核对的等效型号 | 参考电机 3 mm D 轴、10 × 12 mm 齿轮箱截面；6V 堵转电流参考值 0.36 A/台，禁止用手卡轮测试 |
| 轮子 | 与上述 3 mm D 轴适配的一对轮子，32 mm 或 42 mm 级 | 轮径、宽度、轮毂和装配后整车外宽要实测。数字模型“宽度”是底板参数，不是整车宽度 |
| 固定件 | 匹配电机的金属支架及原配小螺丝，2 套；后部球形万向支撑 1 个 | 小电机支架孔不一定是 M3，不要强行旋入。调整支撑高度，使底板大致水平 |
| 触碰开关 | 带 COM / NC / NO 标记的轻触力杠杆微动开关，2 个 | 必须使用 COM 与 NC；用万用表核对松开时导通、按下时断开 |
| 电源 | 带独立开关的 4 节 AA 电池盒；Pico 使用独立 USB 供电 | 同类型同状态 AA；Pico USB 电源与电机供电只共地，**不得将电池盒正极接入 Pico GPIO/3V3** |
| 工具与耗材 | 尺/卡尺、螺丝刀、万用表、绝缘支柱、绑带、泡棉、按实测长度配 M3 螺丝螺母、已绝缘连接线 | 轮子旋转不蹭线；电源和电机回路采用牢固接头，不能靠松动的试探接触 |
| 打印 | PLA 起步，FDM 打印机或代打服务 | 按打印机材料配置；成人管理设备。先小件试配，不要求孩子自己操作热端 |

## 1. 从数字设计到自己的尺寸

下载课程工作台的 `my-rover.scad`。使用 [OpenSCAD](https://openscad.org/documentation.html) 打开，修改文件开头的 `width`、`thickness`；单位 mm。`part` 可选 deck / strap / bumper / coupon。预览后执行渲染，再导出 STL。

参考 ZIP 中的 STL 固定为 100 × 150 × 3 mm 底板，不会随网页选择改变。它与 CAD 的孔槽布局一致：两侧十个 3.4 mm 孔、四个 4 × 10 mm 电机绑带槽、两条 4 × 28 mm 电池绑带槽。开孔坐标见 dimension-sheet.svg。绑带槽是试装备用固定方式，不是已经验证的商品支架孔位。

打印顺序：

1. 打印 `fit-coupon.stl`，平面贴床；五孔从左至右设计值 3.0 / 3.2 / 3.4 / 3.6 / 3.8 mm。记录哪一孔能让实际螺丝通过，而不是强行拧进去。
2. 测电机支架孔距、万向支撑高度、开关孔距、USB 插头空间。画在底板尺寸图上。至少改动一处结构：孔位、孔径、绑带位置或开关固定座。
3. 层高 0.2 mm、三道外壁、约 25% 填充可作为起始尝试，按材料/切片器建议核对；不保证强度。底板平放，压条平放，L 形保险杠的 12 mm 宽底面贴床。不需要为底板孔槽生成支撑。
4. 打印小范围安装样片或压条试配，再打印整板。收缩、挤出和方向都会影响配合；保留前后两版测量。

参考 [Prusa 建模与打印配合说明](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)：没有适用于所有机器和材料的通用公差。

## 2. 机械装配与触碰结构

前端为驱动轮一侧；后端为万向支撑。先用支架将两台电机固定于底板前部两侧，轴向外。用槽位绑带试定位，再按实际支架孔位修改 CAD；电机不能靠电线悬吊。装轮后检查与底板和线缆间隙。

电池盒固定在中央偏后，控制板用绝缘支柱架离底板，USB 接口留空。参考压条用于绑带辅助压紧；按实际器件宽度修改长度。确保电源开关从外面能够立即拨到。

保险杠是 L 形可动触碰条，**不能刚性锁死在底板上**。在左右两端用泡棉导向并用松紧适当的绑带限位，让其向后移动约 1–2 mm 时压下两侧开关杠杆之一，松开能复位。开关固定在底板，保险杠面对外部障碍。先用万用表逐侧核对：任何一侧被轻压都让该 NC 回路断开。结构卡住、无回弹或需要大力撞击时，先重新设计固定座，不通电试撞。

这套保险杠/固定座配合尚待首台样机验证。可以依据实际开关尺寸自制打印导向座；拍下自己的固定方法，并说明修改原因。

## 3. 按端子名接线

全程断开 USB 与电池盒再接线。以下是原版 Pico 的 GP 名与物理脚号；先对照官方引脚图，USB 端朝上时从左上开始编号。wiring.svg 展示网络关系，不表示板子焊盘实际位置。

| 网络 | 起点 | 终点 |
|---|---|---|
| 左轮输入 1 / 2 | Pico GP2（脚 4）/ GP3（脚 5） | DRV8833 AIN1 / AIN2 |
| 右轮输入 1 / 2 | Pico GP4（脚 6）/ GP5（脚 7） | DRV8833 BIN1 / BIN2 |
| 左 / 右电机 | DRV8833 AOUT1/2、BOUT1/2 | 对应电机两根线；方向由架空测试确定 |
| 电机正电源 | 4 × AA 电池盒正极，经独立开关 | 驱动板 VIN |
| 公共地 | 电池盒负极、驱动板 GND、Pico GND（如脚 3） | 互相连接；不要连到正电源 |
| 左触碰 | Pico GP10（脚 14） | 左开关 NC；左 COM 接 GND |
| 右触碰 | Pico GP11（脚 15） | 右开关 NC；右 COM 接 GND |
| Pico 供电 | 合适的 USB 电源/电脑数据线 | Pico USB 插口 |

Pololu #2130 的 SLP 已在板上拉高，按其原厂说明使用；本课不连接 FLT。若换用其他板型，先核对 SLP 和引脚，不能照搬。驱动板额定和散热受条件限制，参考板每通道连续 1.2 A；本课电机选型不是允许持续堵转的保证。

## 4. 运行自己的程序

1. 按 [Pico 官方 MicroPython 入门](https://www.raspberrypi.com/documentation/microcontrollers/micropython.html)安装对应固件，用 Thonny 或官方建议工具连接。不要刷错型号。
2. 将 `controller.py` 保存到 Pico，保留此文件名。它不会启动自动巡航。`import controller as car` 后先保持电机电源关闭，读 `car.contact_open()`：松开两开关应为 False，按下任意开关、拔开任一开关线都应为 True。
3. 架空车轮、成人确认供电再开电机电源。在 REPL 逐条执行 `car.arm()`，然后 `car.forward(300)`。检查左右轮方向。若有反向，断电后修改对应 `LEFT_SIGN` 或 `RIGHT_SIGN`，取值只能是 1 或 -1。
4. 每次动作都需重新 `car.arm()`。程序最大占空比 35%，单次运行最多 3000 ms；这不保证实际速度，先用 300 ms 短脉冲。长距离由多段动作组成，不取消停止检查。
5. 运行中轻按左右触碰条，应返回 `contact-stop`，两轮撤销驱动。拔开一个开关回路时不得启动。Ctrl-C 中断也应撤销 PWM；任何异常先拨电机断电开关。
6. `car.turn(200)` 是定时转动，**不是 90° 指令**。用地面角度标记测量，修改时间并重复。程序至少做一处自己的调整，并在记录里写清变量和实测影响。

归零驱动会滑行，不能保证瞬间停止。切勿通过提高速度去追求停止测试效果；地面测试在围定低速区域，避开楼梯、桌缘、人和宠物。

## 5. 测量、修订与交付

在地面放起点、方向线和标尺。用低矮软障碍测试，不模仿数字地图里的陡坎或沙坑。请保留失败尝试。

| 测试 | 操作 | 课程自检目标 |
|---|---|---|
| 前进 | 先设至少 30 cm 的目标，记录实际轮轴中心移动距离 | 距离误差不超过目标的 20% |
| 转向 | 标记起始朝向与 90° 目标，用量角器或方格纸读角度 | 实测 60–120°，记录调参过程 |
| 触碰停止 | 标记触碰条刚触发的位置，再量继续移动距离 | 先设不超过 10 cm 的目标，实测不超过该目标；人手不挡旋转轮 |

这些是课堂自检指标，不是工业安全或机械认证。记录结构版本、程序版本、地面、目标、实测和下一步。上传两张学生实际拍摄的作品照片：一张结构与接线，一张带标尺的测试现场。只需作品入镜。平台保存压缩照片副本，原图与 CAD 源文件自己留存。

数字原型通过只允许开始制造。正式交付还需要结构修改、试配、实际器件、程序修改、三类实测、两张照片与三句解释。提交状态为待评阅，不自动宣布“已掌握”。若重新冻结另一版设计，旧草稿中的实物证据将清空，先备份或正式交付旧版。
