## 两条电流路径，一个参考地

Pico 通过 USB 供电；四节 AA 经独立开关给电机驱动板供电。Pico 发送控制信号，驱动板把电机电源送给左右轮。电机电流不经过 GPIO。两块板和电池负极共地，电池正极不能接进 Pico GPIO 或 3V3。

先在 [制造手册](/project-lines/space-exploration/assemble-a-rover/hardware/build-guide.md) 的端子表逐项核对。不同驱动板外观相似，引脚可能不同。参考程序只适配指定接线；成人断电接线并检查极性、绝缘和开关可达性，首次通电架空车轮。

## 输入先于动作

两个触碰开关接 COM 与 NC：松开时回路闭合到地，按下或断线时回路断开，内部上拉让输入变高。先关闭电机电源，在 REPL 读取 contact_open()，逐侧按压、松开、断线，核对输入。这个检查没通过，先修结构或接线，不让车运动。

## 让每次试验都可停止

下载 controller.py 并按官方步骤装入 Pico。程序启动保持静止，每次动作前需 arm()，最多运行三秒，过程检查开关，结束或异常时撤销 PWM。归零是滑行停止，不保证立即刹住。硬件断电开关随时可达。

先架空执行 300 ms 的 forward，核对左右方向；断电后按实际结果修改 LEFT_SIGN 或 RIGHT_SIGN。turn(200) 只是 200 ms 转动，不能叫“转 90 度”。落地测角度后改时间或占空比，记录一处自己的程序修改及依据。不要取消停止检查来完成任务。
