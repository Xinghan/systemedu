# 着陆器视觉制作说明

视觉版本：mars-expedition/2。面向约三分钟的制动体验，采用可近看的航天工程展品风格。操作范围小，但设备、材质和观察质量不随时长降低。

- 主体：八边形仪器舱、金色隔热层、四套带斜撑和缓冲段的支腿、足垫、太阳翼及边框、双镜头、天线、线束、散热片、喷管内外层和冷却环。程序创建的概念设备，不是特定航天器复刻。
- 材质与环境：分别处理隔热层起伏、金属反射、涂层、光学玻璃和太阳能电池；砂粒、碎石、地表起伏、远山和方向阴影提供空间尺度。
- 观察：跟随、全景、近看、环视、拖动和缩放；默认显示下降仪表，近看隐藏覆盖物。着陆高度在画面中乘 0.18 以同时看见设备与地面，仪表和轨迹始终使用模型米数。
- 状态：制动驱动喷流和低空尘土；SVG 高度、燃料与发动机状态读取同一模型，轨迹 SVG 来自已保存帧。无随机仪表或预设成功动画。
- 作品：继续使用 land-a-probe/1 和原本机键，新增 visual_version；旧记录可打开。回看立即定位到记录帧，不添加新成绩。

主画面像素比最高 1.6，手机最高 1.5；软件渲染在运动时从 0.75 开始，连续慢帧可降至 0.6；停止观察时恢复设备原生像素比（不超过上述上限）。保留主体结构和材质，通过降低像素成本维持操作。测试中的 SwiftShader 是软件渲染，不代表真实平板性能。无 WebGL 时使用精细 SVG 设备绘入 Canvas，保留操作、轨迹和保存；隐藏不可用的三维环视按钮。

本项目制作全部模型、矢量和程序纹理；Three.js 使用相邻 vendor 的 MIT 版本。NASA 的[探测车仪器资料](https://science.nasa.gov/mission/mars-2020-perseverance/science-instruments/)仅用于识别光学、通信与观测组件的功能类别，没有导入 NASA 模型或图片。

验收入口：systemedu 的 scripts/verify-space-visual-quality.mjs、scripts/verify-space-projects.mjs。运行证据见 verification/visual-quality/；查看初始、近看、制动、收尾、手机和降级画面。自动操作不作为儿童试用数据；真实平板和 Safari 尚未验证。
