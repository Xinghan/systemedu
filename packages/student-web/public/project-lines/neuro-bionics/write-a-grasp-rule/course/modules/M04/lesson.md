# 让规则接受两种检验

正式交付需要当前配置分别在干扰与断流工况运行，而不是拿不同版本最好的结果拼成一份报告。规则程序、窗口和结果会一起固定为一个已提交版本。

**验收例子：**双阈值的目的是什么；confirm 的等待如何影响短动作；missing 的选择会造成什么风险。每个理由最好指向一个时间点或一项对照数字，而不是“感觉稳定”。

进入肌电大项目 M20/M25 时，这些状态逻辑仍有用，但输入幅值范围和阈值需要从实际数据重新标定。0.60 并不是人人通用的肌肉用力标准。

## 换一个角度检查

若修改 missing 后只重跑了断流工况，当前规则的干扰证据仍不完整；界面会提示补测。你可以解释某项改动理论上不影响另一工况，但正式作品仍应包含同一配置下的两次记录，便于其他人重现和判断是否有遗漏。

## 留下自己的证据

应用最终规则并运行干扰、断流两工况；填写自己的选择和未覆盖情形，提交控制包。

**表达例子（请填写自己的结果）：**例如：此规则验证了 …，尚未验证 …；换到实测肌电后必须重新测范围。
