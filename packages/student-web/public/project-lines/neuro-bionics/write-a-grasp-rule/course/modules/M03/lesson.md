# 没有读数不是零

零是一个有效数值；null 表示没有读数。工作台遇到 null 会清空平均窗口和连续计数。missing=release 使状态松开，missing=hold 保留断流前状态。

保持可能继续压住物体，松开可能让物体掉落；策略需要结合装置和场景判断。本课程桌面轻物体实验优先考虑能及时解除持续施力，但任何软件策略都不能替代独立电源开关。

**迁移边界：**旋钮连 Arduino 时，松脱的模拟输入可能浮动为某个数值，并不会自动报告 null。网页断流测试验证的是软件分支，不是实物断线检测。真实电路还需要自己的诊断办法和停止操作。

## 换一个角度检查

选一段仍有意图、但读数为空的时段。release 可能增加遗漏时间，却明确解除动作；hold 可能暂时保持目标，也可能继续错误施力。不要只根据单个总分宣布策略安全。完整说明应包含输入失效、机器动作、物体与周围人的实际后果。
