# 给开合留一个缓冲区

闭合和松开是两个状态。close=0.60 表示达到闭合阈值才考虑闭合；open=0.45 表示低至松开阈值才考虑松开。中间区域保持已有状态，称为迟滞。

**算例：**从松开开始，输入 0.61→0.55→0.44：依次闭合、保持闭合、松开。若每次都用 0.60 判断，第二点就会松开。缓冲区不是忽略所有变化，而是为两个方向使用不同条件。

在规则编辑器写完整四行并“应用规则”；只输入文字不会改变实验。一次只改开阈值或合阈值，在相同干扰输入下保存两版。

## 换一个角度检查

试着从“已经闭合”和“仍然松开”两种起点分别输入 0.55。相同输入可以对应不同动作，因为控制器还记住上一状态；这不是矛盾，而是状态机的特点。将 open 写得高于 close 会使两个条件冲突，编辑器因此拒绝应用。
