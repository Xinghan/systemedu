# 把旋钮接到真实夹爪

旋钮是可控输入源，便于学习系统调试，本课不接人体电极。下载当前配置的程序起点，用 Uno A0 读取旋钮，D9 输出舵机信号；外部稳压 5V 为舵机供电，地线共地，正极不与 USB 5V 并接。

成年人协助核对供电与接线。先不装夹指检查开合方向和停止，再安装本人打印结构。独立电源开关负责物理断电；D2 软件停止按钮只是补充功能。

**实现边界：**程序没有自动断线传感器。A0 浮空仍可能给出数字，不会触发浏览器的 null 分支。报告中必须把网页断流策略与实物停止办法分开写清楚。

## 换一个角度检查

比较下载程序和网页规则：前者读取真实 A0，并按固定采样间隔计算；后者使用已知的合成数据。两者共享阈值逻辑，但输入的可靠性不同。把真实串口记录保存在自己的工程文件中，作品栏上传能体现本人修改的 CAD 或控制源文件。
