# 接入自己的三个部件

系统由输入、处理、规则和机构串联。你可以读取本人已经提交的滤波卡、控制规则和夹爪参数；如果还没有前作，就从示例参数开始，并明确来源，不把示例叫作本人作品。

接口不仅是线接上，还包括单位、范围、时序和失效约定。这里控制器需要 0–1，旋钮板提供 0–1023；采样周期 0.2 秒；输出状态再映射到标定过的舵机角度。

**接口例子：**“输入整数 0–1023 → 除以 1023 → 0–1 的平均 → 状态规则 → 本人标定角度”。导入前作会真实改变这些参数，但不会导入旧照片来证明当前系统。

## 换一个角度检查

前作导入只读取本人提交的参数，不会把另一个项目的成功结论自动搬来。系统中多了一段单位转换，也可能多了一段等待，因此需要新的端到端实验。画接口表时可以加一列“谁负责转换”，避免两个模块都转换一次或都认为对方已经处理。
