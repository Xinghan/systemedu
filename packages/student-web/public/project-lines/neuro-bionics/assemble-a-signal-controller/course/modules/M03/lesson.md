# 让接口说同一种语言

把输入解释改为 ADC 0–1023 转 0–1，再运行同一接口故障工况。程序会先转换再平均。修复应使输出恢复随意图变化，而不是只是让一张图变好看。

然后用干扰和断流两种工况测试当前版本。单位修复并不会消除噪声，窗口和确认次数仍可能造成延迟。这就是系统级权衡：局部正确不等于整个任务已经合格。

**证据例子：**修复前低输入 225 大于 0.60，错误维持闭合；修复后 225/1023≈0.22，低于 0.45，能够松开。报告必须用你当前实验的实际数据。

## 换一个角度检查

修复后若波形幅值回到 0–1，却依然漏掉短动作，就应停止反复修改单位，转而研究窗口和确认时间。一次成功排查的意义在于缩小问题范围。保存同工况修复前后结果，使别人看得出你没有同时换一段更容易的输入来制造改善。
