# 先定位，再修理

先选择“接口故障复测”，保留未修复版本。不要先把所有参数改一遍；写出至少一个可被观测推翻的假设，例如“输入与控制器的单位不同”。

探查信号、接口和机构三个位置。若收到 225，却拿它直接与 0.60 比较，就已经找到输入范围不匹配的证据；继续调夹指长度不会解决这个问题。

**诊断顺序：**看到症状→提出原因→选择能区分原因的测点→读数→最小修改→相同工况复测。假设不成立也有价值，把证据和排除过程记下来。

## 换一个角度检查

列出两个竞争解释：A 是单位不一致；B 是机构卡住。若信号表显示状态始终闭合，即使三维夹指没有机械碰撞，A 更值得优先检查。若状态能切换而实物不动，才转向供电、接线和机械问题。选择测点的目的就是让两种解释给出不同预期。
