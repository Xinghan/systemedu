# 用数据检查整个系统

先选轻小目标，测其高度，再用旋钮控制开合，记录实际夹指角、开口和五秒保持结果。固定测量位置和目标，不要一边换物体一边换参数。

若模型预测接触却实际没有，检查零位、接触片厚度和支架松动；若串口状态不对，先查输入与规则。不同现象需要不同证据，不能统一归因“打印不准”。

**迭代例子：**发现承接垫受力后移动，改打印底座连接，再以同一目标重测。真实保持力、摩擦和变形未在浏览器求解，因此三维画面不能代替这组实测。

## 换一个角度检查

设计一次能区分原因的复测：例如固定软件与旋钮位置，只更换已经测过厚度的接触片，再测开口。如果同时调阈值、换物体和改支架，即使成功也很难知道原因。将“改变的因素”和“保持不变的因素”分开记录。

## 留下自己的证据

填入至少三次原始测量，记录一处本人结构改动的前后表现，说明成功与失败的边界。

**表达例子（请填写自己的结果）：**例如：状态正确但 …；我测到 … 后修改了 …，相同目标复测 …。
