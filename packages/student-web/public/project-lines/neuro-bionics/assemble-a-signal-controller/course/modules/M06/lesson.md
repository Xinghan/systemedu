# 交付自己的系统

03 级交付比单个部件多三项要求：接口清楚、故障有定位证据、系统完成真实制作与测量。滤波卡和夹爪各自合格，仍不能自动替代整机验收。

最终记录同时保留未修复工况、修改依据、当前版多工况测试以及本人实物证据。可以先提交数字原型，之后再完成实物；两者在作品档案中分别标记。

进入完整肌电假肢手项目后，还会增加实际信号采集、个体标定、更多机械自由度和反馈测量。这里没有力传感器，因此只能称为状态控制与几何试验，不能声称实现了夹持力闭环。

## 换一个角度检查

请尝试用一段完整因果链解释某次失败：输入端实际收到什么、处理后得到什么、规则给出什么状态、机构出现什么现象。缺一环时就承认证据不足，并提出下一次测量位置。系统作品的价值在于这些环节可以相互核对，而不是部件数量更多。

## 留下自己的证据

检查接口故障、当前多工况与实物证据，提交系统。用三句话说明输入是什么、机器做什么、你凭什么相信它。

**表达例子（请填写自己的结果）：**例如：输入 … → 处理 … → 机构 …；我的依据 …；目前不能证明 …。
