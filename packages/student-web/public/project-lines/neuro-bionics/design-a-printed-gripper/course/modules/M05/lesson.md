# 交付一件可检验的实物

先完成数字原型也可以，但正式作品必须包含本人打印结构、自己的源文件、两张可解释的照片和三次以上原始测量。照片分别说明装配关系及测量位置，不能用课程封面代替自己的制作。

**证据链：**参数版本→本人打印与试配→实际装配→原始测量→解释。修改参数后，旧实测不会自动证明新版本；先提交旧版保留快照，再登记新的证据组。

模板尚未经过我们的实物打样。平台检查记录完整性，不自动认定照片真实或夹持性能达标。若打印失败，也要说明原因并继续迭代；提交完成与老师确认掌握是两件事。

## 换一个角度检查

把“我上传了文件”和“别人能复核制作”分开。源文件应能找到你修改的孔位或尺寸；照片说明测量工具放在哪里；CSV 使用原始读数。文字、文件和照片若对应不同版本，即使每项单独存在也不能构成这一版作品的有效证据。

## 留下自己的证据

提交数字原型或补齐本人制作后交付实物。写清预测开口与实测差异，说明下一次要改哪个因素。

**表达例子（请填写自己的结果）：**例如：预测 …，实测 …；可能原因 …，我下一次只改 … 来区分解释。
