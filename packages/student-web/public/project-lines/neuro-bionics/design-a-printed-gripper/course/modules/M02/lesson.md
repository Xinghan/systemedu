# 先打印一个小试配件

先下载参数化 SCAD 和试配片。试配片有名义孔径减 0.1 mm、原值、加 0.1 mm 三个孔。使用同一卷材料、层高和打印方向比较，记录哪个孔可以装入普通螺丝或轴。

打印尺寸受材料、切片和机器影响。名义尺寸只是设计输入，不能把“导出成功”称为“装配成功”。保留原配舵机摇臂，用实测孔距连接打印夹指；不要打印舵机细花键替代原件。

**改图例子：**原孔需用力压入，增大 0.1 mm 后能够插入但不晃动。这只是示例，记录必须来自本人。模板直角座需要按实购部件补安装孔；未适配的 STL 不是可直接装好的套件。

## 换一个角度检查

记录试配时是否使用同一颗螺丝，孔轴方向是否相同，以及是否修整过毛边。若一个样品修整了、另一个没有，比较就混入第二个因素。修整打印塑料可以作为工艺记录，但不能省略原始失败结果，也不需要购买金属加工设备。

## 留下自己的证据

只先打印试配片；记录材料、层高、实际孔配合。修改自己的源文件，再决定是否打印大件。
