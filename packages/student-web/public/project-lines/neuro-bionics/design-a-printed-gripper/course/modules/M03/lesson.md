# 让固定的真正固定

安装关系分为两条：固定链是底座、打印直角座、侧板和舵机壳体；运动链是输出轴、原配摇臂、打印夹指和接触片。固定承接垫与底座连接，不能跟着夹指一起滑动。

所有自制结构件通过 3D 打印完成；只购买一个小型位置舵机、控制板、旋钮、电线、普通螺丝及供电件。支架孔距必须测实购物品后在 CAD 补齐，不要求加工金属。

**装配检查：**先不通电，核查螺丝确实穿过配合孔、线缆不进入夹持区域、承接面不会翻转。不要强扭舵机输出轴。发现碰撞先改打印零件或停止角度，不能靠电机持续顶住障碍。

## 换一个角度检查

用手轻触已断电的底座和承接垫，观察支撑是否整体滑动；不要扭动舵机轴。若固定链不稳，先解决固定再分析控制。把照片拍到螺丝实际连接的位置，只有外观正面图通常不足以证明摇臂与夹指真的相连。
