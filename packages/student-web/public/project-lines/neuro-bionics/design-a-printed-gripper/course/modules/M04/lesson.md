# 测出你自己的舵机端点

舵机命令角度不等于夹指相对水平线的角度。安装摇臂方向、机构尺寸和实际舵机都影响映射。先取下夹指、保持空载，在成年人协助下核对供电和动作方向，再安装到所需零位。

本课使用位置舵机；连续旋转舵机不能靠同一程序定位。程序中的 OPEN_ANGLE 与 CLOSE_ANGLE 是待替换的起点。小范围逐步寻找无卡滞的端点，再测实际夹指角和剩余开口，不要直接扫到机械极限。

**测量格式：**angle_deg,gap_mm,target_mm,held_5s。角度为实际夹指相对水平线向下的角；gap 是最低接触点到承接面的距离；held_5s 用 0/1 记录本次是否按约定保持五秒。即使失败也保留。

## 换一个角度检查

例如串口命令 110°、实际夹指角 18°，应把 18 填入 angle_deg，而不是 110。若方向相反，修改控制端点或重装零位，不要把负方向掩盖成正数。每一次改变摇臂安装角、接触片厚度或承接垫高度后，都要重新测开口关系。

## 留下自己的证据

记录至少三次本人测量，包含一个未达到目标的情形。出现持续嗡鸣、卡滞或过热立即切断舵机外部电源，先排除机械问题。

**表达例子（请填写自己的结果）：**例如：角度 …、开口 …、目标高 …；保持结果 …；这一行是实测而非公式计算。
