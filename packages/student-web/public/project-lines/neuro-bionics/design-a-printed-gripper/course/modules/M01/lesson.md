# 把抓取变成尺寸问题

本课制作桌面单活动夹指机构：舵机轴水平放置，夹指在竖直平面转动，目标放在固定承接垫上。只要求受控接触和夹持试验，没有机械臂搬运功能。

理想几何中，转轴到承接面的零位间隙为 g，转轴到接触点距离为 L，夹指从水平线向下转 θ，剩余开口约为 g−L·sinθ。**算例：**g=55 mm、L=55 mm、θ=30°，开口为 27.5 mm，接近 28 mm 的目标。

这是点接触近似，没有考虑接触片厚度、轴间隙和物体变形。小于目标高度不表示夹得更好，而可能已经过行程。浏览器的“接触”不证明有足够保持力。

## 换一个角度检查

同样的 30°，长夹指比短夹指下降更多，但这不能推出它更有力。真实力矩与接触力还受作用臂、舵机能力和摩擦影响。本课不以几何公式估算承重；先将目标支撑在承接垫上，观察开口和接触，再决定是否需要进一步的力测量。

## 留下自己的证据

拖动角度，分别保留未碰到与接近目标的两版。画出固定件和运动件，标注自己的三个尺寸。
