# 区分练习与检查

使用平稳、干扰、短促、断流和接口故障五类练习。完成一次有依据的接口修复，检查当前规则的干扰与断流结果，再确定要带入挑战的配置。

只挑最好的一次会低估失败。练习用来决定方案，首次检查用来评价事前选择，二者角色不同。此阶段允许修改参数，但还没有打开新的挑战结果。

**对照设计：**比较窗口时固定阈值，比较机构时固定输入；如果必须同时修改多个部件，应承认无法单独归因。写明为什么当前证据足以支持你的第一次尝试。

## 换一个角度检查

用一张小表区分：练习工况帮助选择参数，第一次新工况检查当前选择，后续修订帮助理解失败。三个阶段都能产生学习，但不能混称独立测试。模型的挑战输入是固定的，重复见过后不再属于真正陌生数据，报告里应如实说明。

## 留下自己的证据

完成当前版练习证据，记录至少一个被排除的解释，然后检查研究问题是否可测。

**表达例子（请填写自己的结果）：**例如：我先怀疑 …，测量 … 后排除；接下来保持 … 不变。
