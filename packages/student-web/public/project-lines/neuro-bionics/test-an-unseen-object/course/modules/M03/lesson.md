# 固定真正的第一次

点击冻结后，问题、指标和参数会固定；打开新工况只生成一次首轮结果。后续改动属于事后修订，不能覆盖首轮，也不能把修订后的好成绩叫作第一次。

观察是否达到原定误闭合上限，以及新目标的几何接触状态。两项可能给出不同判断：规则达标，但机构开口不合适；或者机构接近目标，但信号导致误动作。

**解释方法：**先复述原标准，再报告结果，最后提出可能原因。不要看到结果后把原标准改宽。未达到目标可以成为下一轮实验的起点。

## 换一个角度检查

如果原定上限是 0.4 秒，首轮得到 0.8 秒，应记录“未达到”，而不是把标准改成 1 秒。你可以另提一个事后目标，不过它属于下一轮研究。这里的首轮是学习过程记录，并不提供防作弊监考；独立评估还需要老师准备另一组条件。

## 留下自己的证据

冻结并打开首轮；记录达到和未达到的指标，提出一个能够通过后续实验区分的原因。
