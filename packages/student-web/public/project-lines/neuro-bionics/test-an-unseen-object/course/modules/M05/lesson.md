# 为自己的结论答辩

最终交付包含事前声明、固定首轮、本人实物证据、修订理由和仍未覆盖的情形。评价重点是证据是否支持结论，不是把每项指标调成绿色。

**答辩例子：**“在目标 A、材料 B 和供电 C 下观察到…；没有控制表面摩擦，因此不能推广到所有物体。下一轮使用同形状不同表面，固定开口和程序。”这比“夹爪很智能”更能说明你做过研究。

下一站可以进入肌电假肢手或脑电游戏控制完整课程。人体信号会带来个体差异与采集问题，复杂机械会引入更多自由度。保留这里形成的版本、原始数据和反例意识，重新验证每个新接口。

## 换一个角度检查

答辩时考虑一个具体反例：同样高度但表面更光滑的物体，能否由现有证据保证保持？如果不能，下一轮应固定形状与尺寸、只改变表面条件。再比较保持结果和停止情况，让新的实验真正回应尚未解决的问题。

## 留下自己的证据

交付完整档案，指出至少一项不能由现有证据支持的说法，并提出一个可执行的下一轮实验。

**表达例子（请填写自己的结果）：**例如：现有证据只支持 …；尚不能说 …；下一轮保持 …，改变 …，测 …。
