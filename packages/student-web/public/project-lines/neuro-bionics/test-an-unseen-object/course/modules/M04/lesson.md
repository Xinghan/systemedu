# 让陌生物体检验实物

先按冻结版本打印或复用对应结构，选择事前写下的轻小物体。它应与练习块在高度、接触形状或表面条件上有区别；不要使用易碎、尖锐或贵重物品。固定测量位置，至少记录三次原始尝试。

在仍使用冻结参数时登记实物证据，并固定首轮实物记录。之后可以改打印接触片、支撑或程序，但需建立新证据组。固定副本不会跟随草稿改变。

**失败分析例子：**同样开口下平面块可保持、圆面物体滑脱，说明接触形状与摩擦值得进一步研究；不能只把舵机继续向内压。先断电修改结构，再重新标定端点。

## 换一个角度检查

实物首轮固定的是完整证据副本，包括当时的测量和照片说明。后来删除草稿照片或换材料，不会重写这一份副本。若发现首轮记录填错，应在解释中注明更正及理由，保留原始记录；不把失误直接擦掉，反而更容易看清工程过程。

## 留下自己的证据

完成冻结版本的真实首轮并固定，之后才修改。用自己的照片指出新物体和接触位置，保留失败行。

**表达例子（请填写自己的结果）：**例如：首轮条件 …；失败表现 …；改进只改变 …，复测方法 …。
