# 自己提出一个可检验的问题

04 级不再给你唯一优化目标。先选一个可测的问题，例如“在不同目标高度下，减小确认次数能否缩短响应，同时控制误闭合？”写明固定哪些条件、改变哪个变量、如何判断失败。

工作台用一段尚未用于前面练习的合成输入和另一个目标高度作为首次数字挑战。它只是新工况，不是大量随机样本，更不是外部监考。你还需要自行选择一个不同于练习块的轻小物体做真实挑战。

**指标例子：**事前给出误闭合时间上限，并补充真实物体、保持时间、停止条件。上限是否达到会被记录，但失败不妨碍交付一份诚实研究。

## 换一个角度检查

研究问题应允许结果与你的预想不同。“让它变好”没有可反驳条件；“固定目标高度，减少确认次数后，误闭合仍不超过事前上限”可以被数据推翻。实物目标可以用形状和尺寸描述，不需要追求昂贵或危险材料。

## 留下自己的证据

写自己的问题，选定误闭合时间上限和实物任务，注明停止条件。先用练习工况调试，不打开首次结果。

**表达例子（请填写自己的结果）：**例如：固定 …，改变 …；若 … 则停止；我接受误闭合不超过 … 秒。
