# 先分清意图、测量和动作

实验台每 0.2 秒读一次数，12 秒保留 61 个点。灰色虚线是出题时设定的意图：想闭合时 0.78，想松开时 0.22；橙线是加了干扰的测量，绿线是处理结果。真实人体信号没有这条自动可知的意图线，所以这里的误差只能评价这个教学任务。

先选“平稳握松”，保持窗口为 1，保留第一次实验。再看“阈值附近有干扰”：即使意图未变，读数也会变化。把动作抖动直接说成“人改变了想法”，就是把测量和意图混为一谈。

**算例：**意图 0.22、读数 0.31，绝对误差为 0.09。若这时控制器仍松开，数值不准确却暂时没有动作错误。后续要同时看误差、误动作时间和响应延迟。

## 换一个角度检查

把表里的“原始收到”和“处理后”分开抄写。窗口为 1 时，两者应相同；若不同，先检查是否选到了接口转换工况。意图高而状态松开叫遗漏，意图低而状态闭合叫误动作，两类错误的代价可能不同。你可以更在意其中一类，但必须先说明任务条件。
