# 只用已经到来的读数

窗口 3 表示最近三个已经收到的读数。新点到来时加入它，移除最早的点，再求平均。启动时只平均已有的点，不能用不存在的零补满；断流时清空窗口，恢复后重新积累。

**算例：**最近三个数为 0.20、0.80、0.20，平均 0.40。尖峰变小了。如果接着一直为 0.80，平均先变为 0.60，再变为 0.80。平滑的代价是新状态需要逐步替换旧状态。

保持同一干扰工况，比较窗口 1 和 3。一次只改窗口，保持阈值和确认次数不变，否则无法判断改善来自哪里。图中输出不是整段录像结束后的前后平均；未来的读数在当前时刻还不可用。

## 换一个角度检查

再手算 0.20、0.20、0.80 的结果，也是 0.40；仅看这个平均值无法判断尖峰发生在何时。这说明压缩历史会丢失信息。遇到缺测时不要偷偷补一个零，否则会把通信问题伪装成真实的低输入。恢复后的第一个平均只使用新的有效读数。
