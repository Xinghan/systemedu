# 别把短动作磨掉

切换到“短促信号”，意图闭合只维持约 0.8 秒。窗口 11 覆盖较长历史，可能在动作已经结束后才达到闭合阈值，甚至整个短动作都没有触发。

平均绝对误差不是唯一目标：迟来的正确动作对抓取任务也可能无用。实验台的首次响应延迟只测第一次意图上升沿；它不能代表所有动作，因此还要查看遗漏时间和整段曲线。

**比较方法：**先写你可以接受的延迟，再在相同短脉冲下比较窗口 1、3、7。不要只选一张看起来顺滑的图。保持干扰工况的两版证据，另留短脉冲结果作为反例。

## 换一个角度检查

若一个窗口减少了误闭合，却增加遗漏，就没有单一的“全面胜利”。把两项指标分别写成一行，决定当前任务更不能接受哪种错误。还应检查第二次短动作，避免只用首次响应延迟代表整个实验；下方原始表能帮你找到遗漏发生的时间。

## 留下自己的证据

比较两个窗口的短促工况，写一条“为了减少…，我接受…；遇到…就需要改方案”。

**表达例子（请填写自己的结果）：**例如：窗口 … 减少了干扰切换，但短动作遗漏 … 秒；我把它限制用于持续动作。
