# 交付自己的信号处理卡

最终作品不是一张波形截图，而是可重现的参数、同工况两版对照和你对代价的说明。回到选定配置再运行一次，确认当前结果属于这一版。旧配置的好成绩不能证明新配置有效。

**交付例子：**“保留窗口 3，因为在相同干扰输入下切换从 A 次变 B 次；首次响应增加 C 秒。我尚未测真实传感器，因此只把此选择用于当前合成信号。”A、B、C 必须替换为你自己的实验。

这份卡可以在系统项目里读入窗口和单位约定。进入脑电大项目时，8–30 Hz 带通滤波处理的是频率成分，不等同于本课的滑动平均；迁移的是对照实验的方法，而不是照搬窗口数字。

## 换一个角度检查

复核时请另一位同学只看你的参数卡，尝试选择相同工况并运行。如果不能重现，检查窗口、阈值、确认次数和采样周期有没有漏记。提交后的档案保留当时版本，后面修改草稿不会改变已交付证据；这是让对照可以被别人检查的基础。

## 留下自己的证据

填写选择理由与模型边界，检查两版对照及当前版实验，再提交最终作品。

**表达例子（请填写自己的结果）：**例如：我选择 …，证据来自相同 … 工况；此结果没有证明真实脑电也适用。
