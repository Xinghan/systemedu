## 从部件作者变成系统作者
02 级只要求把一种方法做好。现在你负责整条流程：读取属性、筛选、关联预测、决定复核顺序、检查预算。一个环节的好结果不能替代系统交付。

如果完成了两门 02 级课程，可以按“接入作品”读取自己正式提交的配置。系统会保留来源提交编号。若尚未完成，也可在本课制作：平台给起始参数，你必须修改方案、比较运行、诊断并解释；默认配置不是你的最终作品。

## 接口合同
筛选器输入是 ID、MW、logP，输出带理由的候选。预测器输入是同一个分子的结构属性，输出 ID 和预测 logS。排序器只处理满足门槛的候选，按预算安排复核。ID 必须一路跟着走，否则一个看似漂亮的分数可能属于另一个分子。

预测来自计算，目标来自公开测量；系统显示的复核成本则是人为教学规则。分清三类量，才能避免把模拟预算误写成真实实验费用。

这一课的难度在相互牵制的责任：放宽筛选增加选择，也增加预算压力；优先预测最高者可能减少环数类别的覆盖。你要做的不是把按钮全部点一遍，而是说明自己愿意付出哪种代价。

## 两个词，先弄明白

- **接口**：部件交换数据的约定，包括字段、单位和每一行属于谁。
- **来源作品**：你正式提交的 02 级版本；与尚在编辑的草稿不同。

## 跟着例子想一遍：给交接数据贴上身份

教学例：筛选结果为 A、C；预测表为 C:-3、A:-1。把“第一行”接给“第一行”，会给 A 错配 -3。交接时保留 ID，才能把 A 找到 A。导入自己的作品只接入参数，组合系统仍需要重新运行；没有旧作品也可在本课选择并修改起始参数。

以上示例用于理解方法，不会自动填入你的作品。实际记录请使用工作台中的 ID 与结果。
