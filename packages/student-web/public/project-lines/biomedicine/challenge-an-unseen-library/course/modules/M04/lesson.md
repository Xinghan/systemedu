## 有证据之后允许改变想法
根据上一步的案例，选择一个实际改变：从均值转为近邻、调整邻居数量，或在近邻中从一个属性改为三个属性。修改一个不被算法使用的标签，不算新的方法。先写你希望改变什么，再运行修订。

## 两份结果并排存在
第一次结果对应冻结方案；新的运行明确标为事后探索。你可以比较它们的 MAE 和同一误差案例。如果整体变好但案例变坏，两种现象都要写。不能只展示你挑中的那个改善。

即使修订后超过了第一次，也不能把这次结果当作独立测试的表现，因为你已经利用了答案。要检验修订能否推广，需要另外准备从未参与选择的新数据。这次课程不伪造第三次“全新”测试，也不通过刷新偷偷重抽。

## 什么算完成
不是一定要把 MAE 压低，而是提出可理解的改动、运行并保留结果、清楚说明它发生在看到答案以后。没有改善的改动同样满足这个研究过程要求。

最终报告会把冻结方案和第一次结果保留为固定快照，再附上修订版本。你承担的是说明证据来历和顺序的责任。

## 两个词，先弄明白

- **事后探索**：见过结果后调整方法，再看同一批数据的表现。
- **独立评价**：需要未参与这些方法选择的数据；同一批答案不能重新变成未见。

## 跟着例子想一遍：改善是线索，不是重新获得的盲测

教学例：只用分子量时某条误差大，加入 logP 与极性表面积后改善。你可以说“这个改动在已看过的数据上改善了表现”，但不能说“我重新独立证明了泛化”。若没有改善，也保留它；有理由的尝试与诚实解释就是这一节的成果。
