## 先回答原来的问题
把第一次 MAE 与事先写下的上限比较。若达到上限以内，只能说这批样本满足你声明的平均误差标准；不能说所有分子都预测准确。若超过上限，则说本批数据未支持这个用途下的目标，不需要把措辞改成成功。

## 找一个让你重新思考的分子
选择一个误差案例，记录 ID、预测、测量和方向。你可以怀疑某类结构或某个输入表示不足，但一个案例只能产生假设。不能仅凭它就证明某种化学原因。

页面给出的原始测量也来自已有数据集，本课没有重新实验，没有提供测量误差条。因此报告中要同时承认模型误差和数据范围的限制。

从这里开始，这 16 个分子对你就不再是没看过的测试。你仍然可以学习它们、修改模型；只是需要把后面的结果另列，让读者区分检验和探索。
