## 检查研究链是否完整
最终作品有四段：你原先提出的问题和标准；事先冻结的方法与预测；第一次核对结果和误差案例；事后修订的改动与结果。缺少任何一段，读者都可能把探索误认为独立检验。

## 结论写得有限而具体
第一句引用第一次 MAE 与原先上限，说明本批数据是否达到。第二句说明修订发生在揭晓以后，结果如何。第三句指出样本范围、目标性质或尚未验证的用途。用自己的数字，不用课程例子的数字。

研究不保证原假设成立。认真保存一次失败，并解释下一步需要的证据，比把标准改到能通过更有价值。作品验收检查流程和材料，不把低误差作为交付门票。
