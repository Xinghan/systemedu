## 方案需要冻结哪些内容
下方表单会保存你的研究问题、方法、输入属性、容许 MAE、选择标准的理由，以及算法对 16 个新分子的预测。预测生成时只使用训练分子的测量值，不读取新分子的答案。

例如“MAE 不超过 1.5”是一个能被检查的标准；“效果应该不错”不是。1.5 是 logS 的误差单位，不是百分比，也不表示每个分子的误差都在 1.5 内。请根据自己的用途解释标准，不要直接复制示例。

## 先存好，再揭晓
当前方法必须已经在验证集上运行，才能冻结。按下保存后，需要确认记录已成功写入账号或本机。若同步失败，界面保留这次待提交内容，可以重试；没有成功保存的方案不能被当成已冻结。

冻结后，第一版问题和标准不能在本课程界面中覆盖。后续方法修改只影响探索版本，第一次检验始终对照原先方案。你不需要把所有参数选到最优才敢保存，因为研究的目的包括发现自己原先判断的局限。

如果还不确定标准，回到 M01 看验证证据。此时允许修改；开箱之后的修改需要另一种名字——事后探索。
