## 这一站增加的责任
02 级比较一种方法，03 级负责组合系统；现在你要负责检验的顺序。研究问题、方法和判断标准需要先写下，再打开尚未参与选择的新数据。否则我们容易在看过答案后挑一个最有利的说法。

你可以问：“只看分子量的近邻方法，在不同骨架分子上误差还能保持在我接受的范围内吗？”这只是例子。请选择自己愿意检验的输入和方法，说出为什么值得检查。

## 先在可见数据上准备
仍然使用 48 个训练分子学习，16 个验证分子选择方案。另 16 个分子的目标值暂时在页面中隐藏；它们的结构属性已可供算法产生预测。三组按骨架分开，并不意味着新数据一定更难，也不保证它们代表未来所有情况。

先运行当前方法的验证预演。看平均误差，也看个别失败。你要声明的 MAE 上限可以参考这个表现和用途，但不能把“希望结果漂亮”当理由。

公开数据本身可以被查到，因此这是练习诚实研究顺序的课堂工具，不是有防作弊保障的盲测。如果已经看过新数据，记录里要说明，不能把自己当成第一次独立检验。

## 两个词，先弄明白

- **可检验问题**：能通过预先约定的数据与指标判断是否得到支持的问题。
- **反驳机会**：允许结果未达预期，不为了成功临时更换说法。

## 跟着例子想一遍：从愿望变成问题

“我想要一个好模型”没有明确标准。可改为“只用分子量的 3 近邻，在本课 16 个新骨架分子上的 MAE 能否不超过我事先声明的上限？”先看验证结果，再说明为什么选择这个容许误差。标准高低由你解释，未达标也能构成完整研究记录。
