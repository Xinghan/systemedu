## 作品不是一张“完成”截图
你的筛选器包含真正起作用的条件、每个样本的处理结果、比较记录和解释。另一位读者应该能回答：你用了哪批数据？上限分别是多少？不知道的值去了哪里？为什么选择这一版？

## 做一次交付前检查
回看当前配置。它应当既保留一些候选，也排除一些候选，这样你才能解释规则如何区分样本。若一条都没有或全部通过，不用编写成功结论，回上一节调整范围再运行。保留这些失败尝试，它们也是你认识数据的过程。

在最终说明中引用一个具体 ID 与数值，说明选择的代价。再写一条限制：例如这里只看了两个结构属性，既没有毒性实验，也没有验证特定疾病的作用。不要照抄例句；根据你实际做的选择说明。

## 保存与交付是两回事
编辑时工作台草稿自动保存。按最终作品按钮才形成正式交付快照，之后改草稿不会改写这一份提交。登录时保存在账号中；未登录时只在当前浏览器。下载只是可选副本。

证据清单通过表示材料齐全、计算能复算，并不代表系统已经判断你掌握了化学或证明分子有效。你可以回到这一节点打开已交付版本，也可以在 03 级把自己的规则接入更大的工作台。

## 两个词，先弄明白

- **草稿**：编辑中的当前工作台，可以继续改。
- **交付快照**：按交付按钮保存的固定版本；后续改草稿不会改写它。

## 跟着例子想一遍：一句能被检查的结论

可用句式：“我采用 MW≤___、logP≤___；与第___次相比，___号样本的去向改变，因为___。这个选择增加/减少了___项复核工作。”空格用自己的记录填写。再写一句边界，例如只用了两个结构属性，没有检验药效。不要把示范数字当自己的实验。

以上示例用于理解方法，不会自动填入你的作品。实际记录请使用工作台中的 ID 与结果。
