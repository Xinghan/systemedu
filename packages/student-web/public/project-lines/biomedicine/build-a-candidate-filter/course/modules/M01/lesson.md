## 今天的委托
你收到一批分子卡片，不能一次仔细复核所有分子。第一步不是决定谁最好，而是看懂卡片写了什么。打开下方数据表，任意找一个 ESOL 编号，追踪这一行。

## 四列扮演不同角色
**ID** 是本课固定的记录编号，不代表分子的优劣。**MW** 是按结构计算的分子量，单位 g/mol。**计算 logP** 描述一种分配倾向，是算法得到的属性。**实测 logS** 是公开数据中的水溶解度目标，本节不拿它当筛选答案。logP 和 logS 虽然都带 log，含义完全不同。

平台从原始 SMILES 重算 MW、logP、极性表面积和环数，保留了原始测量目标。你负责的是读懂信息、设计筛选，而不是声称自己测量过这些化学品。

## 一个可检查的例子
假设教学卡写“MW 280 g/mol，计算 logP 2.1”。只能说这些属性有相应数值。它没有告诉你药效，也不能证明它适合某个人。另有一张标为 QC-MISSING 的故障卡故意缺少 MW；它不是新增实验数据。

把一个属性拆成“名字—单位—来源”三格。后面每一条规则都要能回到这张字典，否则数字比较只是猜测。

## 两个词，先弄明白

- **MW**：分子量，本课用 g/mol 表示。它是从结构计算得到的属性。
- **计算 logP**：对分子在两种相中分配倾向的估计；没有单位，不是水溶解度，也不是药效分数。

## 跟着例子想一遍：给一张卡写身份说明

教学卡 A：ID 为 DEMO-A，MW 为 280 g/mol，计算 logP 为 2.1。可以记录“DEMO-A 的分子量由结构计算得到，值为 280 g/mol”。不能写“我测出了 280”——你没有做称量或测量。下方 QC-MISSING 是故意缺失信息的故障卡，不是第 81 个实验样本。

以上示例用于理解方法，不会自动填入你的作品。实际记录请使用工作台中的 ID 与结果。
