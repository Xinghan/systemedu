## 让规则离开你的脑袋
“我想要小一点、容易处理的分子”还不能执行。筛选器需要明确的量和边界。本课把任务缩小成两道门：MW 小于等于你选的上限，并且计算 logP 小于等于另一个上限。两道门都通过，才进入候选池。

## 边界值也属于规则
教学例子：如果上限设成 300 g/mol，299、300、301 的结果依次为通过、通过、排除。这里使用“小于等于”，不把刚好等于上限的值悄悄丢掉。调节滑块后，按运行按钮留下这一版的配置和逐条理由。

## 缺失不是零
QC-MISSING 没有分子量。把空白当作 0 会让它轻易通过质量门，但你没有证据支持这个决定。先体验“放行”会发生什么，再考虑“暂存待核查”。暂存意味着承认还不知道，不意味着分子一定不好。

每条记录只展示第一个导致排除的门槛，足以重现这次决策；这不代表它只违反这一条。你可以调宽第一道门再检查第二道的影响。

本课的阈值是你为教学任务设计的限制，不是通用的药物筛选定律。真正研究还需要具体目标、更多属性和实验。

## 两个词，先弄明白

- **上限**：规则允许的最大值。本课使用“小于等于”。
- **暂存**：信息不足时先不入选，等待核查；不是断言分子不好。

## 跟着例子想一遍：两道门逐条判定

教学规则：MW ≤ 300 且 logP ≤ 3。A 卡为 300、2.1，通过两道门；B 卡为 280、3.5，卡在第二道门；C 卡的 MW 空白，无法判断第一道门。把空白当作 0 会凭空制造证据。试过“先放行”后，请比较它与“暂存”的不同。

以上示例用于理解方法，不会自动填入你的作品。实际记录请使用工作台中的 ID 与结果。
