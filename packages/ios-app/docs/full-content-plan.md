# 全量课程接入

2026-11-17，用户已批准将全部 SystemEdu 内容接入 iOS。沿用 SwiftUI 导航、本地课堂和 SQLite；不修改课程正文，也不改网站的课程标识。

1. 从 student-web 的本地课程和 systemeduidea/projects_data 的完整课程导出统一清单。检查树中每个节点，保留旧版、依赖、正文、理论层级、讲课、互动、作业和资料。记录源文件哈希，构建缺文件时失败。
2. 原生目录按主题 → 项目 → 阶段 → 课节进入，支持搜索。阅读采用要点翻页，表格逐行卡片；理论、互动和作业从正文进入，讲课保留原顺序。
3. 本机记录按项目、版本、课节隔离，保留原三个演示的记录。阅读位置、答案、实验状态可恢复和导出；本机完成标记不冒充正式评分。
4. 内置可信课堂引擎；旧 HTML 在无原生桥权限的隔离视图中运行。保留源资源及下载入口；外部视频仍用网络。逐项报告不能离线执行或尚未适配手机的内容。
5. 核对节点覆盖与资源，检查多种课文、理论、讲课和练习在小屏中的显示，再在 iOS 模拟器检查目录、恢复、下载和既有模型。

不在本批部署后端、提交 App Store 或接入新的账号系统。代码自动提交并推送 codex/ios。
