# 蚁群课程修订与 App 接入 · 2026-11-18

蚁群课程原来混淆了视频追踪与 RFID，使用不自然的中文、未经验证的设备与动物操作承诺，并把重复读数、个体活动和共现指标解释得过于确定。本次对全部 60 节的正文、概念、作业、讲稿和互动进行了修订。课程显示名称改为“AI 蚁群观察：测量、数据与研究记录”，slug、节点目录、1.0.1 内容版本及原活动 ID 保持不变，另加修订号 20261118。

## 内容与课堂

共享课程源主体修订提交为 systemeduidea 的 `20587a8ea075f7ad81c4956e46bdcd5ae89253fd`，最终措辞修订为 `45e4655428c1d28d442a6d11237686c21da0c396`，分支 `codex/energy-project-line-20260921`。独立科学、游戏机制和课件审查在 `projects_data/ai-ant-ethologist/authoring/revision-20261118/`，逐节点去向表为该目录的 `node-destinations.json`。

课程区分自然观察、测试卡台架、非生物模型和合成数据；活体麻醉贴标不再作为必修任务。演示明确写出假设与局限。正式研究计划保持两路可通行、只加长 A 路；关闭通路和停止读卡器作为另行辨识原因的教学演示。AI 草稿需要和来源及程序计算结果核对，不能代替独立判断。

60 个原游戏入口和 59 个原动画入口都已重做。可操纵系统的内容成为模拟实验，写作和登记内容显示为工作台。保留统一课堂中的正文入口、概念弹层与只读讲课页。修复前 19 节讲课正文未进入展示字段的问题，并补齐数据段的开场字段；App 讲课页不再重复展示正文与要点。

正式下载的 ZIP 包包括合成原始读数、判向程序、运行入口、测试、环境和代码管理说明。标准库版本不调用 API 或硬件；数据分析的可选依赖另有实际测试版本清单。App 直接分享包内文件，不依赖访问线上站点。

## 旧记录

各节点附有修订前的题目文本。阅读器保留旧答案、笔记与互动状态，并提供“修订前的学习记录”；新题目的保存键与旧题不同。概念保留历史别名，旧正文入口仍能解析。

旧版读完标记单独保留，不能直接算作新版已读完。原生课程目录也按修订号统计当前阅读进度，旧节点记录不会被删除或改成新的活动 ID。源内容版本不变，避免把已有 SQLite 记录变成找不到课程的孤立记录。
