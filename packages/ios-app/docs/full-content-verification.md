# 全量内容接入与验收

2026-11-17，`codex/ios`。这是可在模拟器运行的全量内容开发版，尚非 App Store 发布版本。

## 已接入范围

- 12 门完整项目课程，30 套短课程（含 2 套保留的旧版）、14 个探索项目，以及后训练和 Transformer 两项独立课程，共 **58 项、843 个节点**。原有机械手、着陆和驾驶导览入口继续保留。
- 使用原生主题筛选、项目搜索、阶段筛选和课节导航。正文按 Markdown 语法单元翻页，表格逐行显示完整字段；练习面板通过选择器切换作业要求、问题和笔记，避免将所有选项堆在长页面上。
- 保留原文、作业、理论各层级、补学基础、理解自测、阶段检验、资料与正式下载。讲课保留原顺序、讲解文字、公式、图片、声音和专用数学/科学可视化组件。
- 55 段现有项目导览影片可从项目目录右上角打开；保持原中文讲解角色和原视频，不用静帧替换。
- 复用网站中的模型、算法和实验工作台。课程 HTML 在不具有原生桥权限的沙箱中运行。App 只接收当前 iframe 的限定状态、产物和文件导出请求。
- 同一项目/版本内的实验草稿跨课节延续，课节笔记独立。原来三个演示的活动 ID 与记录继续有效。SQLite 将课节状态和共享实验草稿放在同一事务中；账号分区与版本分区独立。
- 复用凌星、pvlib、TeachOpenCADD 的产物验证器。凌星 M24/M25 的预测必须先由原生存储确认，才能获得保留观测；更改参数不能覆盖已经保存的首次预测。原记录字段和源课节 ID 保存在导出文件中。

逐节点清单见 [content-coverage.json](content-coverage.json)。完整构建清单包含 4,716 个源文件的 SHA-256，位于生成资源 `content/coverage.json`。

## 数据来源与构建

课程源是网站 `public/project-lines/`、`standalone-courses/` 和共用的 `systemeduidea/projects_data/`。App 没有另外编写一套课文，也没有修改源仓库。本地路径可用 `SYSTEMEDU_CONTENT_SOURCE` 指定。

```sh
npm --prefix packages/learning-runtime ci
npm --prefix packages/student-web ci
python3 packages/ios-app/scripts/prepare-resources.py
npm --prefix packages/learning-runtime test
python3 packages/ios-app/scripts/generate-project.py
```

需要 Xcode、Node、Python 3 和 FFmpeg。源文件缺失或映射错误会报错；三个明确只有作业的空气质量节点 M28b、M36b、M47b 保留为实践任务，并在覆盖清单标明，不编造缺失课文。

本次全量资源约 **1.93 GB**。这是用于完整内容验收的安装包布局，尚未做按需下载；离线资源目录不提交 Git，由以上脚本从共享源重建。1,093 段 WAV 讲课母版转为单声道 AAC，缓存按母版 SHA-256 命名，源文件保持不变。现有正式下载、图片和影片仍完整保留。正式手机分发前应将全量素材改为按课程下载，不能沿用本开发版体积作为商店发行方案。

## 验证

- 12 项运行时/内容测试：全部节点有文件、ID 唯一、正文和作业与共享源逐字一致、旧版保留、公式分块、表格字段、产物协议和保留观测访问顺序。
- 7 类手机课堂浏览器检查：390×704 下无整页横向或纵向滚动，笔记与 iframe 存储在重新打开后恢复；覆盖凌星、火星车、太阳能、后训练、追光、夹爪和 Transformer。
- 75 个课节工作台入口运行检查，无 JavaScript 运行错误；这是入口及初始化检查，不等于逐个完成了全部实验任务。
- 原生首轮 8 项存储/资源测试与 4 项 UI 测试通过：全量目录、课程恢复、机械手/着陆模型及横屏操作、原有阅读恢复。
- 最后一轮 10 项原生测试与 2 项 UI 测试全部通过，包含实验跨节点隔离、音视频 Range 请求、真实 WKWebView 沙箱工作台与目录恢复。产物为 `build/content-final-tests.xcresult`。

测试脚本在 `scripts/ios/verify-content.mjs`、`verify-workspaces.mjs`；详细产物在忽略的 `packages/ios-app/build/`，不混入用户既有截图目录。

## 当前边界

- 本机学习模式；没有接入账号登录、云端同步、正式评分或后台课程更新。跨项目的“导入前作”流程尚未接入统一原生作品库，当前可导出和手动使用作品。
- 课文与内置素材可离线使用。YouTube、外部网页、Python 运行环境首次加载及个别旧实验的 CDN 样式仍需要网络。
- 旧实验保留既有操作逻辑与界面，提供全屏/横屏入口；部分复杂实验还需要逐个做手机布局优化。不能把已可打开称为所有实验均通过手机完整操作验收。
- 未做真机续航/内存测试、TestFlight、App Store 审核或后端部署。自查、已读完和本机产物保存均不等于课程正式验收合格。
