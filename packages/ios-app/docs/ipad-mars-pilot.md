# iPad 星际远航试学版

本轮交付给模拟器试学，不涉及 App Store、TestFlight 或网站部署。重点是让使用者从项目首页一直学习到项目交付，再根据真实使用反馈修订课程。

## 从哪里开始

1. App 首先显示“我的项目”，顶部可切换“项目库”和“学习记录”。点星际远航封面进入项目全景；项目库还可打开原有完整专题目录。
2. 项目全景以简报影片、当前任务和阶段图片组织入口：探测工程八阶段、行星研究六阶段。点“进入第一阶段”先看阶段介绍，听林岚交代任务，再点“开始本阶段”进入观测课堂。子项目沿用原封面，展开后显示课节；长篇项目介绍与知识地图收在“了解项目”。
3. 做完观测，点“选择探索方向”。研究方向进入 Kepler-10 调查，工程方向进入第二阶段“任务设计所”。阶段页底部和课堂阶段边界都提供“下一阶段”，先进入阶段介绍，再进入课堂；随时可返回项目全景切换。从“任务手册”里的“探测工程地图”仍可打开原有八站地图。
4. 课文按小节阅读，点“本节目录”可以跳到指定小节。“练习与笔记”在右边打开，便于对照课文填写；表格恢复为原来的行列结构。
5. 正文中的动画、游戏、三维模型入口继续保留。“动画与互动”提供本节入口与下载资料，“讲课”打开原来的逐页讲解。
6. 原实验中的保存、项目交付和课堂笔记分别保留。“远征档案”可以关联已经在本机交付的作品；仅填写笔记不能替代项目作品。
7. 关闭再启动 App，从“我的项目”重新进入，再点“继续学习”回到当前阶段和课节。学习记录支持 JSON 导出。“试学手记”自动保存在本机。

## 数据与作品

课程数据和媒体继续共用网站源文件。任务地图由既有 `space-curriculum.json` 导出；iPad 原生导航、视频播放器和排版属于 App。SQLite 保存课堂位置、笔记、答案与实验工作区。项目之间只读取已保存的作品缓存作为输入，不把其他项目记录写回当前项目。

本机作品关联使用原远征档案组件，保留提交版本、摘要和内容指纹；修改上游后，可检查是否需要重新关联。档案保存不代表实物测试通过或能力评定通过。当前没有账号同步；网站已有记录不会自动出现在这台模拟器中。

外部网页、YouTube、在线 Python 环境需要网络。实物制造、树莓派升级、模型迁移和真正的导航闭环仍按原课程要求在设备上完成；原来的三个待验证衔接项在“项目资料”中可见。

## 验收

2026-11-25 导航改版验收：7 项共享内容检查、17 项原生测试、5 条 iPad 界面流程通过；最后的封面顺序、返回首页和按钮对比度调整另行复验首页至第二阶段流程。覆盖项目库、横竖屏项目全景、影片播放、两方向入口、地图、统一课堂、讲课、笔记与档案重启恢复，以及凌星数据资料。截图和命令见 [导航验收记录](../../../artifacts/ipad-navigation-20261125/README.md)。此前课堂、实验操作与交付验收仍保存在 `artifacts/ipad-mars/`。

自动检查不等于逐节教学验收，也不等于全部实验的科学正确性验收。本轮保留源课程内容，用户试学后再针对课程解释、任务难度和互动设计改进。

设计参考：[Apple Split Views](https://developer.apple.com/design/human-interface-guidelines/split-views)、[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。采用按可用宽度调整的并排内容区，较窄时将次要内容移到下方或可关闭面板。
