# iPad 火星探索试学版

本轮交付给模拟器试学，不涉及 App Store、TestFlight 或网站部署。重点是让使用者从项目首页一直学习到项目交付，再根据真实使用反馈修订课程。

## 从哪里开始

1. 横屏打开 App。首页可观看序章，或进入第一次观察。
2. “任务地图”保留八个站点。点击站点后，在旁边查看任务简报、学习顺序和本阶段应完成的成果。竖屏时任务说明放到地图下方。
3. 课文按小节阅读，左侧目录可以直接跳转。“练习与笔记”在右边打开，便于对照课文填写；表格恢复为原来的行列结构。
4. 正文中的动画、游戏、三维模型入口继续保留。“动画与互动”提供本节入口与下载资料，“讲课”打开原来的逐页讲解。
5. 原实验中的保存、项目交付和课堂笔记分别保留。“远征档案”可以关联已经在本机交付的作品；仅填写笔记不能替代项目作品。
6. 关闭再启动 App，可从首页继续最近的课节。学习记录支持 JSON 导出。“试学手记”用于记下读不懂或操作不顺的地方，自动保存在本机。

## 数据与作品

课程数据和媒体继续共用网站源文件。任务地图由既有 `space-curriculum.json` 导出；iPad 原生导航、视频播放器和排版属于 App。SQLite 保存课堂位置、笔记、答案与实验工作区。项目之间只读取已保存的作品缓存作为输入，不把其他项目记录写回当前项目。

本机作品关联使用原远征档案组件，保留提交版本、摘要和内容指纹；修改上游后，可检查是否需要重新关联。档案保存不代表实物测试通过或能力评定通过。当前没有账号同步；网站已有记录不会自动出现在这台模拟器中。

外部网页、YouTube、在线 Python 环境需要网络。实物制造、树莓派升级、模型迁移和真正的导航闭环仍按原课程要求在设备上完成；原来的三个待验证衔接项在“项目资料”中可见。

## 验收

20 项共享课堂测试、16 项原生测试及 2 条 iPad 界面流程通过。自动检查与截图保存在 `artifacts/ipad-mars/`。覆盖节点身份、内容完整性、本地影片文件、横竖屏阅读、笔记恢复、原表格、实验操作、项目交付和远征档案关联。模拟器测试覆盖首页、影片播放、地图、实验、讲课、退出重进和横竖屏切换。

自动检查不等于逐节教学验收，也不等于全部实验的科学正确性验收。本轮保留源课程内容，用户试学后再针对课程解释、任务难度和互动设计改进。

设计参考：[Apple Split Views](https://developer.apple.com/design/human-interface-guidelines/split-views)、[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。采用按可用宽度调整的并排内容区，较窄时将次要内容移到下方或可关闭面板。
