# LLM 后训练工程 · 独立专业课程

五节点：方法体系 → SFT 循环 → LoRA → QLoRA → 可复现项目。直接编写内容与代码，未使用 course_factory。独立网页路径 `/standalone/post-training/M01`，不注册到其他课程目录。

- `nodes/`：课程正文、公式、代码讲解和节点作业。
- `course.json`：YouTube 视频索引、观看问题、大学讲义、5×5 页讲课提纲。
- `project/README.md`：Python 环境、训练/评估命令、代码管理与完整验收标准。CPU测试无需下载模型；正式训练需要 NVIDIA CUDA GPU。
- `package_course.py`：构建下载包，标准库脚本，无课程生成器依赖。
- `verification/`：本轮实际检查证据。GPU训练和远程视频可播放性与本地页面检查分别报告。

网页保留系统已有的正文和讲课组件；学习记录使用独立 course/version 命名空间。15个算法实验分别采用与数学结构对应的表达和操作，具体见下表。LoRA 默认显示真实数值的三维投影，旋转查看 B 的列空间，也保留矩阵计算视图。原装饰性矩阵旋转与旧概览小实验已从正文移除。所有小规模计算均标注边界，非实测模型权重。样例合成数据只用于管线测试，不能用于证明泛化。

视频均为原课程或研究作者讲解，链接在编写时通过公开索引核实。完整视频不标注未经核实的片段时间；大学与作者资料用于参考，本站不代表相关机构。

## 每种算法都有自己的表达与操作

| 算法 | 主要表达 | 直接操作 |
|---|---|---|
| 自回归分解 | 概率分支树 + 条件面积切分 | 拖动分岔概率 |
| BT / DPO | 当前与参考双标尺 + 概率仪表 | 拖动两个 margin，比较参照系 |
| PPO surrogate | 正负优势的裁剪地形 | 选择奖励样例、移动概率比探针 |
| 因果注意力 | 句子中的读取弧线 + Value 贡献带 | 选择 query token、放开未来 |
| Softmax / CE | 概率单纯形中的重心和 SGD 位移 | 选择目标顶点、拖动初始 logit |
| 反向传播 | 三段函数与局部斜率接力 | 拖动上游参数、切断/接回路径 |
| 梯度累积 | token 等权与 batch 等权的两架天平 | 增减 token 砝码，比较支点 |
| AdamW | 损失山谷中的参数轨迹 + 梯度记忆 | 回看历史落点、比较裁剪/衰减 |
| LoRA | B 的三维列空间、低秩直线/平面 | 旋转空间、改变 rank 与输入 |
| LoRA 初始化 | A/B 损失等高线与同步更新轨迹 | 切换单零/双零、点选更新位置 |
| NF4 | 最近邻量化区间与格点吸附 | 选择权重、拖动块内离群值 |
| Double quant | FP32 scale 位模式压缩为8bit码字 | 打包、恢复、比较块大小成本 |
| Checkpoint | 激活生命周期甘特图 + 内存占用曲线 | 点选执行列、切换保存策略 |
| Macro F1 | 预测分拣篮 + TP/FP/FN 集合 | 给样例换篮子、切换观察类别 |
| Paired bootstrap | 配对抽样罐 + 样本槽 + 分差分布 | 更换随机抽样，观察重复编号 |

五种布局与五种配色服务于纸面推导、几何舞台、对照、操作台和执行调度。取消固定的侧边检查器和通用图例；说明随选中对象更新。参数放入可展开区域，场景操作始终直接可见。不是通过同一组节点/连线换标题来区分算法。

保留暂停、0.5/1/1.5倍速、连续时间轴、分章跳转、缩放和平移等基础操作；完整公式和适用边界可展开阅读。十字把手支持指针拖动和方向键/Home/End；图中元素支持点击与 Enter/空格。移动端默认放大局部，可拖动画布或用「适配完整画布」总览。动画仅在主动播放且场景可见时推进。

交互设计参考用户提供的 [Transformer Explainer](https://poloclub.github.io/transformer-explainer/)、[LLM Visualization](https://bbycroft.net/llm) 与 [LLM Visualized](https://www.llm-visualized.com/)，采用逐量追踪、空间关系和连续推演的方法。图形与代码为本课程编写，没有复制参考站点资产；这是可手算的小规模教学场景，并非完整模型的实时执行器。

`verification/check-scenes.cjs` 渲染全部场景及参数边界、过渡时刻，检查可选元素、数值检查器与兼容记录恢复；`check-http.py` 检查正文内的实际图形入口、视频索引与下载包。
