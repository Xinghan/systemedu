# 先驱者协会 (The Pioneers Guild) — 徽章生图 Prompt 全集

通用美术风格（每条 prompt 已内联，无需额外拼接）：厚涂卡通风章徽设计（Pixar 概念美术 +
复古探险家勋章混合），圆形徽章造型，扁平几何图腾为主体，色彩鲜活但不幼稚（禁止圆眼睛卡通
吉祥物/幼儿绘本风），线条硬朗有工业感，适合 10-18 岁青少年审美。

四级叙事模板：**铜=单物件特写 → 银=场景 → 金=仪式(人物剪影) → 大师=史诗传奇**。
四级各自独立设计画面，不是同一图案换边框颜色。

八大分会：生物机所 / 穹际分会 / 绿萌盟 / 机械之心 / 心智工坊 / 算境阁 / 神经回廊 / 深时秘境。

生成建议：一个分会一个分会来，每个分会内先出铜再出银金大师，方便对比同分会内的风格连贯性。
生成后建议按 `<分会英文名>-<等级>.png` 命名存放（如 `bio-forge-bronze.png`）。
