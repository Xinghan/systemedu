# Lightkurve 接入星际远航任务地图

## 目标与边界

补齐上次课程整合剩余的 32 个 Lightkurve 节点。复用正式统一课堂，不生成或改写课程正文、媒体、题目及作业，不修改原节点 ID、内容版本或记录 scope。本次完成实现与本地验收，不部署或合并 main。

## 接入方式

在星际远航内提供两条可切换路线：原火星探测车路线，以及按原六阶段推进的凌星调查路线。将全部 32 节转换为有输入、操作、产物与自检标准的任务，接入既有任务中心、计时和任务记录。每条路线内连续导航、独立计算进度；原车体路线不会新增观测研究的必修要求。

相比将 32 节强行插入火星车制造流程，这种组织保留了真实研究的前置关系；相比只挂独立课程链接，它提供逐节点地图、任务单和阶段交付。

## 实施与验收

1. 从正式课程树和节点内容提取六阶段、稳定标识、版本、操作与验收要求，建立逐节点去向表和来源散列。
2. 接入地图、任务中心、课堂上下节与登录回跳；按课程隔离完成记录，保持旧任务记录兼容。
3. 检查 32 节唯一覆盖、依赖顺序、原节点不变、同编号跨课程隔离、旧记录/实验产物恢复与路线结尾行为。
4. 本地浏览器检查桌面/手机地图、任务单、正式课堂富媒体、讲课模式和资料入口；记录实际验证边界。
5. 检查 diff，明确暂存本批文件，commit、push 并核对远端提交。
