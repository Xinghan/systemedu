# M88 / M89 证据卡片布局补丁

问题：M89 第 1 页的左侧规则表越出卡片，压到右侧结构化说明之下。

根因：共享 `.se table` 的 `white-space:nowrap` 被继承；`.dr-panel` 未限制最小宽度；两栏的媒体查询只判断浏览器视口，没有判断课文中的实际内容区宽度。

实施：仅更新 `diversity-rejection.css`。精确数据不变，文本表格允许换行、固定表格布局、卡片 min-width 为 0；命名容器查询在 850px 以下改为单栏，620px 以下调整统计和结构网格。矩阵保留专用的固定网格，不隐藏溢出数据。

验收：在 1280px 宽浏览器中切换预览区 1152/960/720/480px，对 M88/M89 共 22 页逐页检查（88 个状态）；再测窄视口、浮窗拟合及交互。增加 CSS 回归测试。预览宽度控件仅在本地开发预览中，不发布。

发布：按 upload → stage → build → smoke → switch → verify 分步。服务器当前阅读界面版本为基线，隔离构建，只替换一个 CSS 文件。服务器上保存源码及课程哈希、原版备份；切换失败自动回滚。无课程导入、数据库改动、音频改动、JS 改动或依赖改动。

已完成：22页×4容器宽度及390px视口检查、两节点浮窗检查、66项本地回归、11项服务器回归。生产 Build ID `ea4FB-hqZCwxNKu7J5oIs`，源码白名单、课程哈希、公网CSS及健康验证通过。详见 `docs/deployments/2026-09-09-slide-layout.md`。
