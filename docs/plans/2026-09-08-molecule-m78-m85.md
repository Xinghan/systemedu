## 媒介决策

- M78 主要是排序、阈值和坐标关系：动态精确图表优于图片；三维没有新增的空间教学价值。
- M85 主要是结构与可计算描述符及筛选集合：RDKit 结构 + DOM 数值 + 动态过滤。实物照片或旋转分子不能解释四个阈值，也不能证明吸收或安全性，不强行加入。
- 两节点不设图片或 3D 配额；M42 的图片与 3D 实物路线保持独立，下一次有装配/构象主张再采用。

## 科学审查

- ROC 使用 score ≥ threshold，最高起点为 +∞；相同分数一起进入，不在同分样本间制造不可达点。单类别数据拒绝计算。
- TPR / FPR 随阈值降低不减；精确率不保证单调。AUC 评价本批样本的排序，不自动选阈值、不证明概率校准或真实毒性。
- Lipinski 是吸收/渗透相关经验筛选，不是安全、疗效或可上市许可。
- 允许 1 条违反的集合不必包含在任一单规则通过集合中；原文相关结论需要明确修正。
- KaTeX 使用 String.raw，避免 JavaScript 把 \t 等命令吞为控制符。
