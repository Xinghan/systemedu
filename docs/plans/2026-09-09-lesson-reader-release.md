# 学习阅读界面补部署

用户已明确批准部署此前验收的统一阅读与幻灯片组件。沿用既有设计，不重新设计课件。

1. 核对实现和回归：只保留单页轮播、正文、浮窗、音频与当前页同步、内容自适应。检查已部署视觉渲染不能被旧本地版本覆盖。
2. 生成定向发布：从线上基线隔离复制；仅补丁修改 course-content-view、teacher-scene-view 播放器部分、gateway、types、locale，以及三个必要 helper。teacher 的具体 SlideBody 与所有课件 renderer 保留线上原样。课程内容、首页、后台、依赖锁文件不改。
3. 测试与构建：本地相关回归和真实浏览器检查；服务器测试实际隔离文件，构建、临时端口健康检查。旧版本与基线保存在服务器，不导出生产内容。
4. 正式切换与验证：逐步执行；切换失败自动回滚。验证白名单、课程哈希不变、线上健康及公开路由。登录态不可用时明确说明，不伪称已登录验证。

完成标准：线上构建包含一个课文上方左右切换播放器和浮窗按钮；课程数据适配带回同份 slides；同时只有一个播放器；前后切换保留页码；默认不自动播放；放大后幻灯片主体无内部竖向滚动。正文页面仍可正常滚动，讲稿展开后的独立文本区域允许滚动。

既有全仓 TypeScript 基线错误和无新讲稿音频不属于本次发布的新增行为。没有安装 finishing-a-development-branch 技能；按 Code 检查与留档完成，不创建提交或扩大部署范围。

首次候选构建与 6 项服务器播放器测试通过，切换后严格源码核对发现三处 loading/empty 分支仍引用 sceneMode/setSceneMode。立即恢复上版 `aYd_CSg6L1f2Yf9XIjW4m`，课程无改动。根因是相同补丁前文出现三次，原应用器在非唯一前文时误用“后文已出现”判断而跳过。修正为在预期重复数上限内完整替换，其他重复仍失败关闭。
