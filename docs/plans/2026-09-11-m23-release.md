# M23 PubChem Retrieval Implementation Plan

**Goal:** 重做分子猎人 M23 八页，学生能从真实 PubChem 记录取回结构、核对来源并交付带语法标注的记录，验收后定向部署。

**Architecture:** pubchem-retrieval 独立 renderer/helper/样例快照，复用 RDKit、KaTeX 与现有横向播放器。固定样例检索明确离线，不冒充 API；真实来源由用户在公开网页复制并声明，软件只核验结构和字段一致性。生产基线白名单增量，不发布工作区其他修改。

**Tech Stack:** 当前 Next.js/React、RDKit.js、KaTeX/mhchem；现有 deploy.env/sshpass/import-publish。无新增依赖。
