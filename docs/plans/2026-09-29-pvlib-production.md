# pvlib 生产发布

用户明确授权将已验收的单门 pvlib 课程部署生产。课程源为 `systemeduidea/projects_data/pvlib-solar-forecast-station`，正式版本 1.0.0，共 58 节。

## 发布边界

- 项目库使用真实 Library 发布清单；将课程关联到动力发明家 05 级。原有登录、加入项目与内容权限继续生效。
- 正式入口 `/learn/pvlib-solar-forecast-station/M01` 使用已经验收的课程、动画实验、幻灯片与学习记录界面。内容与实践包通过带认证的现有文件 API 加载；实验 iframe 不接收账号令牌。
- 保持课堂、作业、测验和考试的 scope 与内容版本摘要算法，保留实验产物的保存、恢复与账号隔离。
- 导入学生实际需要的 884 个文件；源码中的审核截图和 authoring 中间稿不进生产课程包。封面复用已生成图片。
- 前端以服务器实际版本为基线，新增五个课程专用文件，只补充公共阅读器导出和能源项目线关联，共七个改动文件。不覆盖工作区中的其他课程改动。

## 验证与切换

依次执行：打包及哈希检查、服务器隔离暂存、生产构建、新旧类型检查对比、候选浏览器验收、提交推送、定向导入和发布、正式 HTTPS 验收。

候选浏览器使用本地已审核课程及明确的模拟账号数据，不向生产写入测试学生记录。生产检查包括课程清单、文件哈希、权限、服务状态和匿名 HTTPS 访问；这不等于使用真实学生账号逐节点验收。

备份留在 `/opt/systemedu/releases/pvlib-20260929`。切换失败恢复原前端并撤下新课程；手动 rollback 会核对后续发布，保留学生数据，不用旧数据库覆盖现有记录。

课程硬件实物验证与儿童试教仍未完成；本次上线不更改这些事实。最终部署结果另记于 `docs/deployments/2026-09-29-pvlib.md`。
