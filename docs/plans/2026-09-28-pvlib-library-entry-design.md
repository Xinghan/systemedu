# pvlib 本地课程项目库入口

## 问题与结果

“给阳光做一份发电预报”的 58 个节点已有本地预览，但项目库仅合并服务端课程清单、静态快照与项目线短课程，因此无法从列表发现它。

沿用现有卡片与筛选，在本地开发环境加入一个完整工程课程入口。它同时出现在“全部项目”和“动力发明家”的 05 级，支持中文标题、pvlib、光伏等关键词搜索，点击进入实际首节点。标记“本地预览”，不声称已发布。

## 实现边界

- 受现有开发环境与 loopback host 条件限制的 catalog 路由读取课程 manifest，提供标题、实际节点数、首节点及现有生成封面。
- 客户端独立加载本地 catalog；课程服务暂不可用时仍可显示。按 slug 去重，缺失 manifest 时保留原列表。
- 卡片支持明确的课程链接、操作文案与制作准备说明。现有课程卡片默认行为保持一致。
- 本地 manifest 图片通过已有 media 路由加载，绕开仅接受无查询字符串路径的 Next 图片优化配置。
- 本次不部署、不修改课程文件、不变更账号权限或学习记录。

## 验证

`artifacts/pvlib-course/library-entry/check.mjs` 检查真实浏览器中的搜索、层级/领域/项目线筛选、课程跳转、封面、移动端及服务失败时的入口保留。保存桌面和移动端截图及验证报告。
