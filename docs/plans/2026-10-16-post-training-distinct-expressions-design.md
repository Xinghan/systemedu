# 为不同算法选择不同的表达方式

用户指出第4版仍然像统一模板：相同的黑色框、节点连线、检查器和播放结构掩盖了算法之间的差异。本次以运算的数学结构为依据重做表达，保留课程正文、视频、作业、讲课与记录标识。不使用 course_factory。

| 算法 | 核心画面 | 直接操作 |
|---|---|---|
| 自回归概率 | 概率分岔树与按条件分割的面积 | 拉动分支分界，观察目标路径质量 |
| BT/DPO | 两把相对优势标尺与偏好概率转盘 | 移动当前/参考差值，比较是否校正 |
| PPO/优势/KL | 正负优势的裁剪地形与信任区间 | 沿概率比拖动探针，切换奖励分组 |
| 注意力 | 围绕句子的上下文弧线、读取贡献带 | 点 token，切断未来可见区域 |
| softmax/CE | 概率单纯形与目标顶点 | 改变 logit，选择顶点，回放 SGD 轨迹 |
| 反向传播 | 三段函数的局部斜率与缩放导数 | 改斜率或切断传递路径 |
| 梯度累积 | 按 token 投票与按 batch 投票的对照天平 | 改长回答长度，比较两种权重 |
| AdamW | 损失山谷上的轨迹、梯度与动量历史 | 沿历史点回看，改变步长/裁剪 |
| LoRA | 投影和列空间中的向量变换 | 旋转空间、改变 rank/input，核对矩阵分解 |
| LoRA 初始化 | A/B 损失等高线与参数路径 | 比较单边零与双边零的出发点 |
| NF4 | 非均匀 Voronoi 量化区间与权重吸附 | 点权重、改离群值、切码本 |
| 双重量化 | bit 存储条与 scale 的二级打包展开 | 改块大小，检查层级恢复 |
| checkpoint | 激活生命周期甘特图与驻留数量剖面 | 点击执行列，比较保存与重算 |
| macro F1 | 预测分拣台与 TP/FP/FN 集合 | 将第六条样例改分到不同类别 |
| bootstrap | 配对样例抽样盘、抽样槽与分差分布 | 再抽一组，检查重复索引与配对关系 |

仅复用精度处理、可访问操作、播放器状态和记录存储。画布里的布局、几何结构、移动对象、直接操作均依算法而异；外层也采用纸面推导、空间舞台、对照实验与执行调度等不同排版，避免每次都显示同一侧栏。

数学不因表现形式改变。所有颜色、面积、长度、坐标及轨迹均关联明确的数值或类别；标注教学近似和模型边界。直接拖动提供键盘等价操作，旧参数与步骤保持可恢复。验收覆盖每类独特表现、关键运算、参数端点、浏览器操作与课堂/资料兼容。
