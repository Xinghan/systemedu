# 恢复阶段简报中的科研角色

用户反馈：阶段视频里没有人物。原因是把“任务中心背景无人”错误套用到视频，能源、机器人与最近三条线的 40 段阶段简报仅有场景和旁白。

修复范围：这五条线的每个阶段简报，恢复中国科研角色面对学生交代本阶段任务的动态出镜段；保留随后原有阶段讲解。星际与分子寻药的既有人物短片保留。任务中心、地图、场景背景继续无人。

每线固定一位虚构中国科研角色和一张高质量实验室参考图，保证人物身份连续；每阶段单独编写短对白并生成跟随音频讲话的动态镜头。复用已有操作说明和静态资源，避免重做整段视频。不能用静态照片缩放冒充人物口型动画。

实现：内置 imagegen 生成五张人物参考图；沿用仓库的 wan2.6-i2v 音频驱动视频管线，每任务先记录提交状态，重试只查询同一任务，防止重复付费。保存 v2 MP4 / VTT / poster，验收后统一切换五条线的视频版本与观看去重键，不改变任何课堂记录。

检查：逐段 ffprobe、字幕与实测音频时长；每线目视检查动态样片与首尾帧，确认人物与实验室；到站/重播/旧观看记录升级；任务中心背景指纹不变；类型与 lint 基线比较。网站和 systemeduidea 只提交本批明确文件并 push，不部署、不合并。
