# 地球侦探社：五个衔接项目

使用 project-line 规范制作；不重写已有三个旗舰课程。状态为本地可试用，不宣称已发布或已验证儿童用时。

## 范围与作品

1. **找出地表的变化**：3 分钟，NASA 同地区影像对比、选择位置与观察类型、保留前后图证据。真实影像，操作标注为学习者贡献。
2. **跟上那只蚂蚁**：3 分钟，自制自然观察场景中的教学轨迹；暂停、定位、遮挡时标未知、回放。明确为模拟，不冒充动物实验。
3. **读懂空气的一天**：4 节 / 60 分钟。时区、单位、缺测；比较处理方法；保留尖峰及解释边界；交付报告。合成训练数据可复算，参考 EPA 资料。
4. **画一张有证据的观察地图**：4 节 / 60 分钟。局部坐标和比例尺；地点与记录 ID 对齐；实测/估计/未测；对照采样计划。预置虚构调查场地，不暴露住址。
5. **组装我的地球调查档案**：5 节 / 100 分钟。导入自己已交付的空气/地图作品（至少一份）；来源契约；探查时区/单位/地点接口故障；修复复测；冻结可打开的证据报告。平台示例不算本人前作。

## 实施顺序

- 核对 NASA / EPA / USGS 原始资料、影像许可、真实视频及旗舰目标节点；保存来源清单。
- 编写独立可测试的 earth-model，数据来源、记录校验、对照计算和版本绑定。
- 复用账号 learning-record 会话、课程阅读与视频组件；新增工作台与微项目路由。交付保存不可变快照；编辑不追改旧版。
- 为不同任务制作影像滑动对比、蚂蚁轨迹、时间图表、点位地图和证据接口检查，保持现有站点风格。
- 生成 13 个课程节点，含正文、具体例子、资源、任务、结构化回答、最终作品门槛。
- 用 imagegen 生成五张真实感编辑封面，构图各异，不用宣传图冒充测量。
- 源包同步到 systemeduidea/project_lines/earth-discovery；网站 public 为运行副本。更新 line.json 和目录，只移除已完成规划。

## 验证

模型：缺测不变为零、平均窗口不跨缺测、时区/单位转换、坐标与来源 ID、修改使旧结果失效、导入仅接受已提交且验证过的本人前作。

浏览器：五个入口、13 个节点、真实操作/重试、刷新恢复、最终交付历史、前作导入、接口修复、窄屏、键盘/减少动画。检查截图；不把自动测试称作儿童试用。

内容：source/public 哈希一致、project-line 校验、资源 URL/视频存在、每个节点目标与作品对应。只报告实测范围；本次不部署、不提交其他既有改动。
