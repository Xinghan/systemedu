# 星际远航整条项目线任务旅程 Implementation Plan

**Goal:** 将视频、任务中心、地图和作品进展提升到整条航空航天项目线，让用户看见从首次操作到完整工程与研究的成长路线。

**Architecture:** 新建 `/mission/space` 项目线任务中心。配置层以现有 12 个项目 ID 为唯一标识，5 个能力阶段、8 个地点组织入口；提取地图交互公共组件复用既有图片。新中心只读取现有作品与完成记录，不新建一套课程完成状态，不以访问或观看算完成。各项目保留原课堂；添加返回任务中心与上下游关系。

**Tech Stack:** Next.js / React / TypeScript / CSS modules，现有 learning records API、课程知识树与完成 API，Playwright。

## 产品流程

1. 项目线入口：看到终点作品与 5 段能力跨度，主按钮进入任务中心，仍可直接浏览项目列表。
2. 新学生：3 分钟拍摄第一张星球照片，无需材料；可选看 29 秒火星探索序章或直接动手。火星短片仅是全线的一个导入场景，不把天文研究也说成造车。
3. 任务中心：一张基地地图呈现全部项目，默认推荐最早尚无作品的基础项目；可自由跨站，不人工锁课。不同阶段显示情境、学生要承担的决策、前序作品如何复用、交付证据与准备要求。
4. 项目课堂：小项目是短操作，多节点课程保留正文/资料/视频/工作台/作业；大型项目仍用统一课堂。始终可以回项目线地图。
5. 作品回收：三分钟作品显示本机来源；正式课程读取已有 final-deliverable 提交；大型课程读取实际完成节点，不用 last-visited 推断完成。不将节点勾选、提交记录等同于专业能力认证。
6. 高阶分流：自主探测车工程与行星数据研究各自成立；地图覆盖两个项目，允许选方向深挖，不把两者伪造成严格串行先修。

## 5 段成长与 8 个任务站

| 阶段 | 扮演角色 / 核心责任 | 任务站和项目 | 升阶证据 |
|---|---|---|---|
| 01 探索新人 | 观察、操作、留下结果 | 启程观测港：spot-a-world、land-a-probe、drive-and-frame | 照片、着陆对照、路线与取景；先完成任意一次建立信心 |
| 02 任务学徒 | 做出一种能验证的方法 | 任务设计所：pick-an-observation-site、plan-a-payload；结构实验室：tune-a-chassis；感知与控制站：label-the-terrain、write-driving-rules | 选址依据、预算、单变量对照、标注样本、规则与测试 |
| 03 系统建造者 | 处理接口和多个约束 | 系统建造区：assemble-a-rover | 数字方案 → 3D 打印结构 → 接线程序 → 实物自测；数字原型不代表完成实物 |
| 04 远征负责人 | 制定标准、在新现场测试和修订 | 远征指挥站：run-an-expedition | 已交付实物车、真实任务数据、失败与改进证据 |
| 05 高阶工程与研究 | 完成长期、自主的工程或研究交付 | 自主工程中心：mars-analog-rover；行星研究站：lightkurve-transit-detective | 真实数据、模型/代码、实物或研究结果、可复现证据与报告 |

成长角色表达挑战深度，不承诺完成后取得“高级工程师”职业资质。五阶段不是靠积分升级；展示真实作品、能力要求和下一项挑战。全线 12 项完整目录可见，推荐主线允许分流。

## 影像与叙事安排

- 复用生成的基地底图，地图地点对应项目群；单项目 8 节地图仍作为制造项目的内部地图，明确两种层级。
- 复用现有林岚、控制室、地形和项目封面作阶段静态简报。
- 可选 29 秒开场影片 + 可操作火星任务作为序章，与课程完成进度分开。
- 不为全部 12 项另生成视频；高成本视频留给未来验证后最有价值的转场。

## 实施批次

1. `src/lib/project-lines/space-journey.ts`：12 项映射、场景、角色、交付物、上下游、5 个成长阶段；检查分类覆盖与链接。
2. `src/components/learning/rover-campus-surface.tsx`：从现有地图提取拖动缩放与地点选择，保持原课程地图行为。
3. `src/lib/project-lines/space-journey-progress.ts`：只读现有三分钟本机作品、7 门课程交付记录、2 门大项目节点进度；未知/失败与未开始分开；不混账号，不将本机匿名作品自动归到登录账号。
4. `src/components/mission/space-journey.tsx` 及样式、`src/app/mission/space/page.tsx`：项目线任务中心，地图、阶段简报、下一步、作品档案与家长准备。
5. 项目线详情、开场完成页、3 分钟项目外壳、多节点课堂、大项目详情/课堂增加全线入口与任务关联，不改内容 ID、记录版本和课程权限。
6. 本地桌面/手机交互、目录覆盖、可达链接、作品恢复、账号隔离、接口失败与地图失败回退验收；保留已有六个 TypeScript 错误说明。
7. 自动 commit、push 当前实验分支并核对；本轮用户改变方向，暂停部署，先本地验收新范围。

## 后续扩展安排

先以航空航天整线验收这个体验，不同步改写七条项目线。通用地图组件已经与单门课的数据解耦；后续领域分别配置阶段、任务站、项目与作品读取方式，不能照搬造车路线。视频只放在启程和显著的阶段转折，平时用角色静态简报、现有课程视频、实验和作品回收形成节奏。

本次完成整线入口、任务分组、阶段简报、地图和作品读取。未新生成十二套课程内容或阶段视频，也未把评阅、职业资格或硬件实测自动化。HiRISE 和 Lightkurve 仍经原正式课程入口校验权限与可用性；Lightkurve 摘要来自既有 manifest，而非旧版八门课程快照，其原课程未提供封面，暂用清晰的研究标识展示。
