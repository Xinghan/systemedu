# 林岚任务开场视频样片

用户已确认先尝试 8～10 秒角色讲话样片。使用现有虚构中国工程师首帧与中文配音，生成一个连续镜头，验证目光、口型、细微动作和身份一致性。

- 输出一个 10 秒 Web 视频样片，先独立验收，不批量生成所有对白。
- 复用项目现有百炼凭据，通过官方 SDK 调用 wan2.6-i2v，1080P；只上传已生成的人物图与合成配音。
- 提交任务 ID 后只查询该任务，不重复提交。保存提示词与不含签名 URL 的状态；凭据不入库。
- 使用 FFmpeg 整理配音停顿、检查编码并制作浏览器版本与抽帧，检查真实人物运动而不只是假运镜。
- 提供独立视频验收入口。沿用 Web 原型及原有课程入口，不改变正式课程完成状态。
- 若服务不可用，如实保存失败原因，不以静态图片推拉伪装生成视频。
- 验收本地视频播放、声音、暂停、重播及手机布局；完成后仅提交本批文件并 push 当前实验分支。
