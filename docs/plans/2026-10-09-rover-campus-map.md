# Rover Campus Map Implementation Plan

**Goal:** 把原三栏任务目录改为真实基地地图，原节点、进度与课堂全部保留。

**Architecture:** 一张生成的无字底图配网页路线和八个定位按钮；选择地点在地图外显示任务卡，进入原 node 链接。仍使用既有学习记录计算状态，地点选择只改变界面，不写完成记录。手机使用可拖动、缩放的地图，提供定位当前任务和简洁目录。

**Implementation:**
1. 内置 image_gen 一次生成研发基地底图，保存原图与提示词，转换 WebP 部署尺寸。
2. 独立 RoverCampusMap 组件处理选择、相邻地点键盘导航、路线状态、平移缩放和图片失败。
3. 原 RoverMissionMap 改为简洁目录备选；任务中心和节点内的展开地图都复用新组件。
4. 验证桌面/手机、地点与原节点对应、拖动不误触、缩放/定位、记录状态不被浏览行为改变、失败回退、原课堂导航和恢复。
5. 只提交本批文件并 push 当前实验分支，不部署。
