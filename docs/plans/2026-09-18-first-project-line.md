# 第一件三分钟作品：我的第一张星球照片

实现范围：project-line 的首个节点 `space-exploration/spot-a-world`；独立 HTML 互动包、学生端项目线入口与本地试用。目标年龄暂按 10–12 岁，三分钟为待试用目标。

## 体验与交付

- 开场直接看见可操作天空，月球和火星可选。月球明确标为地球的天然卫星。
- 拖动天空或使用方向按钮移动望远镜，调整放大倍率，让所选目标进入方形取景框。
- 实际操作及合格取景后才可拍照；保存当前渲染的取景区域，保留视角、倍率、目标、时间和操作记录。
- 拍摄后用一次简短选择表达想保留的细节，可下载照片/完整 JSON 记录，再拍或恢复旧取景。
- 任务向导是本地状态提示，不冒充在线 LLM。记录只保存在当前浏览器；保存失败时明确提示下载。
- 3D 使用本地 Three.js 和程序生成的教学纹理；无外部资源请求。提供 Canvas 简化渲染兜底。教学场景不代表真实天空、天体尺度或真实天文摄影。

## 文件与集成

- 可运行包：`packages/student-web/public/project-lines/space-exploration/spot-a-world/`。
- 学生端地图：`/project-lines`，只将已实现的第一个节点显示为可开始，其他为规划。
- 沉浸式页面：`/explore/space-exploration/spot-a-world`，嵌入同源互动；访客可使用。
- 完成后将 brief、运行包、校验记录同步到 systemeduidea 的该节点目录，保持内容来源清楚。

## 验证

检查实际拖动、选择目标、缩放、拒绝不合格取景、拍摄内容与当前画面一致、保存/刷新恢复、重拍、两种下载、损坏记录/存储失败、键盘操作、窄屏与 Canvas 兜底。进行学生端路由和导航检查，以及本地后端健康检查。
