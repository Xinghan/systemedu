# 星际远航 iPad：身份、连续任务与章节作品

## 已实现的范围

- 我的项目 / 项目库保留同一个大项目入口。进入项目后不再有研究/工程方向 tab、跳章卡片或多路线菜单。
- 入队先填队员名，选择观测员 / 工程师 / 领航员。身份只改变代入角色，所有人沿同一条路线前进。
- 可选照片通过系统 PhotosPicker 选择，显式生成、预览、重试、确认；不传照片也能使用队徽。姓名和形象用于任务主页、课堂身份栏及署名交付。
- 原创动漫中国科研指挥官林岚保持连续；1 段欢迎 + 14 段章节简报。每段有真正的人物动画和本章对白，随后展示该章独立的设备场景，配中文字幕。原写实视频仍保留兼容来源，不作为新路线入口。
- 14 章各有独立插画、到达情境、要交的作品、自检条件、限制和下一章交接。120/120 原节点完整映射，14 个课程来源（含两个历史版）的旧路由和记录保留；未重编号或替换课堂正文。
- 当前章只有一个推进按钮。每节仍复用原有 WKWebView 课堂、讲课、富媒体和资料下载。下一章由当前章作品入档后出现。
- 第一章从真实课堂操作中提取带方向、缩放与取景元数据的星球照片；单纯读完或看完视频不能交付。
- 后续章收任务指定的图表、数据、代码、设计文件或实测材料，保存针对性说明和学生自检。界面明确“材料已收齐 / 学生已自检 / 内容待评阅”，不自动宣称科学结论正确或工程达标。
- 交付冻结署名、形象、作品文件与原课堂存档副本，可回看、打开文件和导出。之后修改名字、形象或笔记不会改写既有交付。草稿自动存本机。

## 保存与部署边界

身份、草稿和交付使用新增的 owner 隔离 SQLite 表，旧课堂表、内容版本和存档协议保持可读。头像服务只接在 Debug 模拟器的本机适配器；生产 HTTPS 后端、账号同步和教师评阅未部署。后续章节的文件由学生从真实工作台或外部制作环境导出后收进作品页；不把平台示例自动算为学生成果。

当前验证以原生自动化、资源结构、合成人物接口测试和测试截图为准。没有儿童试用，也没有逐章真实硬件制作或科研评阅。人工窗口连接工具曾中断，不将自动化截图检查称为人工逐屏操作验收。
