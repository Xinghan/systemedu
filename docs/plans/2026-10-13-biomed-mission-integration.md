# 分子寻药整合 Implementation Plan

**Goal:** 把原大课与小课整合成一条持续推进的候选分子研究任务，保留全部现有节点、内容、历史路由与记录。
**Architecture:** 在旧 114 个任务标识之上重排节点，不重生成课程。8 个稳定站点 ID 保留，按任务次序重排；任务段聚合 112 个课堂节点与 2 个微体验。原课堂仍负责正式学习和提交，项目线负责上下文、调用顺序和研究交接。
**Tech Stack:** Next.js / React / TypeScript、既有 learning-record 服务、JSON 编排、Python 校验、Playwright、FFmpeg（只复用已有媒体，必要时修订解说）。

## 决定与范围

采用节点级融合。保持项目级串联无法消除重新开题和重复交付；重写全部课程会引入不必要的内容及记录风险。所有 47 个分子猎人节点进入主路径，46 个 TeachOpenCADD 节点与 19 个引导节点按实际依赖交错，同一研究档案跟随全程。每次只突出当前任务段和下一步。

顺序：观察启程 → 研究立项 → 数据溯源 → 筛选与结构基线 → 预测开发 → 系统联调与挑战封存 → 独立评价 → 候选评审与复跑交付。室内实验室背景及站点 ID 沿用；地图、时间表、下一步导航均读同一份配置。

整合不删除、缩写或替换原正文、题目、视频、动画、游戏、作业、基础桥及历史课程入口。112 个课堂节点一对一保留；2 个微体验任选。11 个 TeachOpenCADD 基础桥保留原材料位置并挂到使用它们的节点。既有 47 项连续编号映射及旧引用重定向保持原字节。

## 数据边界与任务交接

一个研究档案中区分三类来源：原小课的 ESOL 方法练习、分子猎人的属性/方法实验、TeachOpenCADD 的正式靶点研究。方法可以迁移，数据、标签与成绩不自动转换。保留每个原课的独立交付，档案引用它们；最终收口以正式研究管线为准，不把练习通关视为研究验证。

每个任务段明示输入、输出、下一步用途、来源节点、迁移时须核对的条件。整合不做自动免修、不将完成一个节点同步标记为其他节点完成。原任务状态、检查项、用时与 station 日期全部保持可读；任务总数变化通过界面说明。新研究交接使用单独记录，不重写旧研究档案的五个字段。

## 实施步骤

1. 保存旧 biomed-mission.json、线上树和全部来源 ID；增加“项目线整合不得删节点”的协作规则。
2. tools/mission-authoring 新增声明式任务段配置与生成脚本，替换 biomed-mission.json 的编排字段；所有旧 task.checks 保持原数组以兼容既有自检。生成 node-allocation.tsv、运行时镜像和来源指纹。
3. biomed-mission.ts 统一站点/任务段/前后导航；BiomedJourney 与 BiomedLessonBrief/Outline 使用任务段而非原项目列表；原课标题、独立链接、基础桥和记录保留。
4. MissionControlConfig 添加可选任务分组及任务上下文槽位，仅生物线开启；其他项目线按原行为运行。原任务状态、计时、日期和搜索继续可用。
5. 新增研究交接账本：按任务段保存作品位置/版本、来源类别、迁移检查和下一步用途；保留提交快照与首次结果。不能把填写位置当作文件上传或自动科研验收。旧五字段研究档案保持兼容。
6. 核对八站短片的顺序与台词。沿用人物原片、背景及已有音轨，修订错位的编号/字幕/演示，仅必要台词重新配音；原 v2 文件保留，旧观看记录不删除。
7. 验证：112+2 ID 集合相等、所有任务段和锚点闭合、来源前置链可满足、课堂与编号文件零删除；旧 operations/dossier 恢复；新交接保存/刷新/账号切换；跨大/小课前后跳转；统一课堂正文与讲课入口/下载；八站短片；320/390px 与其他任务线回归。
8. 构建并比较已有类型/lint 基线。明确未进行儿童试用、真实研究实验或上线导入。逐批 commit/push 到各自当前分支；结束提供本地验收入口与精确拆分表。
