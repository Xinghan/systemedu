# M38 multimodal slide implementation plan

> Execute task-by-task with the course-slide-visuals skill. User authorized continuation and specifically requested visible Three.js objects and generated raster images. No production deployment in this batch.

**Goal:** Replace all 10 M38 slides with a source-aligned lesson that visibly includes a generated observation illustration, a genuine Three.js apparatus and exact, interactive chemistry/data explanations.

**Architecture:** A typed `logp-lab` renderer selects one of 10 scenes. Model calculations live separately from React/Three.js; deterministic descriptors are computed from the three original lesson structures. Versioned drafts preserve source order, identity and lesson anchors; original course files remain unchanged. A local preview uses the existing single-slide carousel and labels each medium.

**Tech Stack:** Existing Three.js 0.184, RDKit, KaTeX/mhchem, React, local WebP generated by the built-in image tool. No new dependencies.

## Tasks and acceptance

1. Snapshot M38 source files; record hashes, original teaching claims and renderer decisions. Do not overwrite prior work or canonical course source.
2. Generate one 16:9 light technical raster comparing dispersed oil droplets after stirring with a separated upper oil layer after standing. No generated text; compress a selected version to <300KB. This illustrates the source kitchen experiment, not a measured LogP or a standard apparatus.
3. Implement `src/lib/logp-lab.ts`: P=10^logP; n_w=n_total/(1+P V_o/V_w), n_o=n_total-n_w; c=n/V with µmol/mL=mM. Test conservation, concentration ratio, equality and invalid inputs. Neutral dilute two-phase equilibrium teaching model, not a kinetic or fluid simulation.
4. Implement `partition-object-3d.tsx`: procedural glass vessel, upper organic/lower water phase, cutaway and camera presets, linked volume/amount/concentration evidence. Three.js displays geometry and representative tracer points, not real molecules. Load lazily, render on demand, clean up and show explicit fallback.
5. Implement 10 scenes in `logp-lab-visual.tsx` and scoped responsive CSS: image comparison; 3D phase inspection; exact concentration ratio; log scale; computed molecular ordering; RDKit execution trace; ordering exercise; histogram from disclosed 3-row teaching sample; calculated vs measured evidence; evidence record handoff.
6. Create M38 versioned draft and registry with source hashes, anchors, media type and generated asset mapping. Revised scripts have no old audio reused. Preview page `/slide-preview/m38-multimodal` clearly labels image/Three.js/HTML pages.
7. Test model, actual TeX, SSR all scenes, source identity, compressed asset and real browser interaction/fallback/layout. Inspect initial/intermediate/boundary states. Record verified results and update M38 progress only; keep M90 as next remaining node. Show preview before any deployment.

## References and boundaries

- OECD 107 describes equilibrium concentration ratio in n-octanol/water, not cooking oil/water: https://www.oecd.org/en/publications/test-no-107-partition-coefficient-n-octanol-water-shake-flask-method_9789264069626-en.html
- IUPAC partition ratio: https://goldbook.iupac.org/terms/view/P04440/plain
- Three.js renderer and controls: https://threejs.org/docs/pages/WebGLRenderer.html and https://threejs.org/docs/pages/OrbitControls.html
- The generated image is qualitative illustration, not a recorded experiment. The 3D model assumes non-ionized dilute solute, fixed conditions, no reaction or association; it does not estimate equilibrium time. Real solvent experiments are not instructions for children to perform.
