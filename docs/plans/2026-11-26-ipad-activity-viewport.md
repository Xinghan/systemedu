# iPad 实验空间与视频退出

用户反馈：望远镜实验沿用桌面页面，高度超出 iPad 的可用区域；观看介绍视频后不容易退出或继续。

## 方案

实验打开后，统一课堂通知原生容器暂时收起导航和章节栏；关闭实验后恢复。实验内保留一条带个人头像、标题和关闭按钮的栏，不再叠加第二条队员操作栏。该通知只接受当前课堂主文档、当前会话和当前课程，不修改学习记录。

望远镜使用仅在 iPad 离线课堂加载的适配样式。观测画面占剩余空间，方向、缩放、快门固定在底部，主要操作目标至少 44 px。横屏说明在右侧独立滚动，竖屏和窄窗口将目标与提示放在取景画面下方。照片弹窗同样受实际视口高度约束。桌面资源、渲染器、课程正文、稳定 ID 与原保存结构保留。

视频首次仍自动播放。退出与跳过按钮始终可见，点击画面只切换底部播放控制。结束后继续按钮显示「进入任务」。关闭阶段影片会记录已经呈现过简报，回到项目页再次继续时直接进入课堂，不重复用影片挡住路线。退出不代表完成章节或提交作品。

## 验收重点

- iPad Air 横屏 → 竖屏 → 横屏，不滚动即可触及方向和缩放按钮，快门完整在视口内。
- 关闭实验后原生返回、章节推进和原阅读位置恢复。
- 实际拍照、署名作品、本机保存、重开恢复与入档继续下一章。
- 浏览器测量三个尺寸下的可见边界和按钮尺寸，检查加载失败重试；回归原有讲课、笔记、实验和表格。
- 视频自动播放，隐藏播放控件后仍能退出和跳过；退出后再次进入不重播；播放结束后可以继续。横竖屏均验证。

本批次没有增删或重排课程节点。原 120 节的映射沿用 `2026-11-26-ipad-expedition-node-map.md`，身份与记录仍使用原存储标识。验收使用隔离测试档案。
