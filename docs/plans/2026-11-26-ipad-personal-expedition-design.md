# 星际远航：个人队员与连续故事（实施中）

用户确认：用户只沿一条路线推进，项目内不提供研究/工程 tab、方向分叉或任意跳阶段入口；照片生成卡通队员后，名字与形象贯穿任务。App 的“我的项目 / 项目库”仍是系统入口，不是项目路线分支。

## 故事目标与四幕

学生作为远航计划的新队员，最终交付一份别人能复核的观测与探测档案。

1. 入队与第一次观测：创建队员身份，接受林岚的欢迎，在模拟望远镜留下第一张照片和问题。
2. 星光里的线索：观察 Kepler-10 亮度，整理 Q3 数据，寻找周期，排除其他解释；先写预测，再打开 Q4 检验，交付可复现研究。
3. 从远望到近探：远距离测量有边界，转到地球上的火星类比试验场。通过着陆与驾驶练习，完成选址、载荷、结构、制造、感知和控制。这不是前往 Kepler-10 的航行，也不把虚构场景当成观测证据。
4. 远征与交班：保留首次试验、修改与复测，完成一次类比远征；学生署名和头像出现在最终档案中，交给下一班队员。

每章都有承接前章的来由、当前目标和带往下一章的成果；原课程正文、稳定 ID、内容版本、旧路由及历史记录保留。补充与旧版内容保留映射，不能删除以缩短路线。

## 界面与记录

系统首页 → 入队（昵称、可选照片、角色）→ 欢迎 → 当前任务 → 原统一课堂 → 下一项任务 → 下一章。只有一个推进按钮；全程图只读，解释位置和目标，不充当跳转菜单。角色只影响称呼与职责提示，不改变任务顺序。

身份与导航状态使用独立、按学习者隔离的本机存储；课程读完标记和实验产物保持原语义。更换头像不清除进度。旧学习记录继续可恢复，不因新版故事改课程版本。

## 头像服务

照片通过系统相机拍摄或系统选择器选取，拍摄与选取均不会自动上传。用户点击生成前看到处理用途和服务商说明；生成后预览、重试或确认，不强制提供照片。服务端持有模型凭据，App 不包含 API Key。原照在设备与本地开发代理中只做短期内存处理，重编码去掉 EXIF；仅确认的卡通头像保存到本机。供应商的数据处理政策另行明确，不承诺代理无法控制的供应商零留存。

本轮先在 iPad 模拟器 + 本机头像代理运行真实生成链路；真实设备和线上分发需要已认证的 HTTPS 服务，不把调试代理当正式公网服务。

## 视觉与影片

林岚保持同一位中国科研指挥官身份，改成原创日式太空动画人物。每章使用独立的无人科研场景图片。真实生成讲话动画，配合本章设备/成果镜头，保存中文配音与字幕；不用静态人物缩放冒充动态人物。旧影片归档保留，新路线使用新影片。

## 验收计划

检查单线顺序、全节点覆盖、旧记录恢复、头像与进度隔离、照片错误与重试、生成后确认与删除、横竖屏、当前任务唯一入口、第一至第二章衔接、真实影片运动和播放。自动测试使用虚构生成的人物素材，不使用学生照片。此文档当前为实施计划，不代表功能已完成。
