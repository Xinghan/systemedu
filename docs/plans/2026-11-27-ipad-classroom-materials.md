# iPad 课堂入口与资料处理

用户要求去掉 iPad 讲课模块、右上角分享入口，并修复桌面可下载但 iPad 无法正常使用的资料链接。

## 实现

- iPad 不显示或打开讲课面板，不显示全局导出按钮。保留按路线阅读、笔记和正文活动；失败时仍明确提示记录未保存。
- 桌面网站不改；既有课节、正文、媒体和记录 ID 不改，旧讲课进度仍可解码。
- 新窗口、正文资料和脚本生成文件统一进入原生资料页，不替换课堂。CSV 可读，Jupyter 文件提取说明和代码作预览；ZIP 保留原始内容与文件名。
- 点击「保存到文件」调用系统文档导出，默认到 SystemEdu 文稿目录，也可选其他位置。资料在「文件」App 可访问；学习记录继续在 Application Support，不随文稿目录公开。
- HTTPS 直接文件链接先下载再预览；普通参考网页继续在浏览器页打开。不存在或损坏的资料显示可恢复错误。
- 不重新导出课程包，只重建阅读器，避免混入其他任务正在编辑的课文。

## 验收

对恒星观测原始 CSV、Jupyter 笔记本、HTML 模板、ZIP 做字节一致性检查；在指定 iPad Air 11-inch (M4) 上验证入口精简、资料打开/返回和系统文件保存，检查已有笔记及阅读路线恢复。完成后提交并推送当前分支。

验收记录与截图见 `artifacts/space-expedition-20261127/classroom-materials/README.md`。下载不是运行环境：Notebook 仅预览说明与代码；CSV 预览限制长度以保持流畅，导出内容仍为完整原文件。
