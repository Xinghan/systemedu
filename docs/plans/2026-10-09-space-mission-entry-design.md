# 星际远航：直接进入任务中心与首次序章

航空航天项目线卡片、项目关联入口、职业方向中的项目线入口均通过统一路由进入 `/mission/space`。旧 `/library?view=lines&line=space-exploration` 链接自动替换为该地址，不额外加载课程列表，也不在返回历史中留下重复跳板。任务中心返回“所有项目线”，防止入口重定向形成循环。其它尚无任务中心的项目线沿用原页面。

同一浏览器第一次在前台看到任务中心时自动打开序章并尝试有声播放。浏览器阻止播放时提供醒目的播放按钮；可以关闭、跳过、观看结束，随后进入任务中心。后续访问、刷新、课程返回不重复弹出，保留手动重播。观看提示只记在浏览器偏好中，不写学习完成记录；不同设备会各自显示一次。存储不可用时以当前 JS 会话记忆兜底。序章组件放在账号/地图站点的 keyed session 外，防止账号恢复或地图切换打断视频。

验证直接入口与旧链接、其它项目线、首次播放/被阻止时降级、跳过/结束/重播/再次访问、手机布局、资源错误退出、存储不可用、播放中账号变化以及不写学习完成状态。本轮本地验收，按规则 commit 和 push，不部署。
