# 后训练课程：空间计算图与几何推演

用户反馈：上一版虽然补充了算法细节，但按步骤切换的数字、条形图与装饰性旋转矩阵不能解释运算发生的过程。此次修改现有独立专业课程，直接编写页面组件，不调用 course_factory，不加入其他课程目录。

## 表达方式

采用用户提供的 Transformer Explainer、bbycroft LLM Visualization 和 LLM Visualized 中的交互原则：跟随一个具体量，查看空间关系与中间计算。所有图形与实现均为本课程原创。目标是解释后训练算法的小规模算例，不实现完整 LLM 推理模拟器。

1. 每个算法有专门的图，而不是统一套用条形图。15 个场景覆盖概率链、BT/DPO、策略优势与 PPO/KL、注意力、交叉熵、链式法则、累积、AdamW、LoRA、初始化、NF4、双重量化、checkpoint、混淆矩阵与 bootstrap。
2. LoRA 计算图和几何视图共享 A/B/x 数值。三维视图使用真实三维向量的正交投影，显示 B 列张成的直线/平面；拖动改变相机，不改变算法结果。其余算法采用更适合运算关系的二维计算图、数轴与曲线。
3. 连续时间轴驱动流动标记、数值插值、权重吸附到码本格点、向量增长和样例归入矩阵。可以暂停、调速、逐章跳转、放大、平移和全屏展开。不会自动播放；离开可见区域时暂停推进。
4. 点选或悬停 token、矩阵单元、向量、样例，检查器显示真实的局部乘法、概率、梯度或误差。对参数的改变立即重算。完整数值与边界保留为可展开补充。

## 教学正确性

- LoRA 限制增量的秩，不限制基座的秩；三维轴是输出坐标，不命名为语义概念。
- 注意力 mask 与标签 mask 分开呈现。当前是单头 d_k=1 的可手算例，未来位置在因果模式中权重为零。
- softmax 更新后重新计算指数、分母、概率与 loss；反向路径标注使用更新前梯度。两个 LoRA 因子也同时使用同一次 backward 的梯度。
- DPO 显示参考校正、sigmoid 与 loss 导数。PPO 的 old 与参考策略分开，最后阶段独立呈现完整二行动 KL。
- NF4 显示实际码本查找与反量化误差。二级量化明确使用教学均匀8bit例，不冒充 bitsandbytes 逐位内核。checkpoint 区分前向、重算与反向边。
- 所有前端计算可手算、用 CPU 数值脚本核对；不将演示数值声明为模型实测结果。
