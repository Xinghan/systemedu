# 项目库内的两种视图

用户已明确：项目线并入项目库，不再作为主导航标签。

采用项目库页内的“全部项目 / 项目线”切换。全部项目保留首屏太空入口、类型与挑战筛选；项目线沿用太空探索的短入口卡片和成长路线。两者共享页面标题、主题入口和家庭启动提示。相比把全部内容堆在同一长页，视图切换能让用户按当前目的浏览；相比继续维护独立导航，入口更集中。

实施顺序：

1. 更新 spec 048，删除顶栏项目线入口，增加页内视图链接与中英文文案。
2. 使用 `/library?view=lines` 表示项目线视图；默认与未知值回到全部项目。切换保留本页的筛选状态，浏览器后退、前进和刷新遵循地址。
3. 提取原项目线内容为组件，复用主题横幅，原 `/project-lines` 路由重定向。共享目录中的项目线链接指向新地址。已有游戏返回链接通过重定向继续有效。
4. 浏览器检查顶栏、视图切换、筛选保留、历史记录、刷新、旧链接和游戏返回；检查桌面、手机及英文布局。沿用此前游戏行为测试。
5. 更新验收记录，按本次差异提交并推送，保留其他任务的修改。

不新增后端接口或内容发布状态。主视觉沿用暖纸色、珊瑚色和太空插画；页内切换采用紧凑的分段链接，并提供当前视图标记和键盘焦点。
