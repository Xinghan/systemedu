# 项目库「未来的我」视图

用户反馈：按领域、难度与项目浏览，仍不能让家长和学生迅速理解学习的长期价值。需要从“我可以成为什么样的人”进入，再找到现在能做的事。

本版沿用现有网站视觉与项目数据，增加 `/library?view=futures`，与全部项目、项目线在同一页面切换。职业方向用 `role` 参数保存，支持链接分享和浏览器返回。保留原有默认项目库入口，先让用户验收新视图。

## 设计选择

职业介绍容易停留在远景，长问卷会增加进入成本，推荐采用“职业方向 → 目标作品 → 能力与证据 → 今天的第一步”。方向选择始终可见，一个方向对应一个主要开始按钮。成长路线和器材准备可展开，不要求第一次访问就读完全部课程。

五个首批方向来自现有内容：机器人与具身智能工程师、太空探索工程师、AI 药物发现研究员、新能源系统工程师、地球与环境研究员。照片复用已经生成的项目封面及响应式 WebP，不另造与项目无关的职业人物照。

每个方向包括：

- 一个学生能理解的作品愿望和实际工程示意。
- 三项与课程作品相关的可练习能力。
- 一个明确的 3 分钟起点；不可用时提供查看项目线入口。
- 4–5 件代表性的成长作品，直接连接现有课程，展示能力变化和交付物。
- 家长可以观察的进步，以及浏览器体验到实物制作的器材变化。

这些是职业探索方向与代表性作品路线，不是完成几门课程即可获得职业资格的承诺，也不是所有先修课的完整清单。不新增年龄分流、能力打分、职业预测或强制解锁。工程项目遵循原课程要求；自行制作结构使用 3D 打印，标准电子模块可购买。

## 数据与状态

`future-paths.ts` 只维护职业说明、能力表述和现有项目 ID。标题、交付物、开放状态、正式课程与本地预览入口从 `DiscoveryEntry` 解析，不新建课程或另存一套学生进度。课程处于筹备中或目录请求失败时，不提供虚假的开始链接。

当前工作区的地球入门内容和部分课程映射已有其他未提交改动，本批不将它们混入提交。若目标环境尚未包含这些节点，该方向对应的节点显示筹备中，保留项目线入口；发布时需以目标环境实际目录核对开放情况。

## 验收与下一步

浏览器验收覆盖五方向、中英文、320–1440px、封面加载、路线展开、链接、键盘操作、未知方向降级、完整课程服务失败及原有两个视图。记录保存在 `artifacts/future-path-view-20260930/`，脚本为 `scripts/verify-future-path-view.mjs`。使用目录接口 fixture，不写入学生数据。

本批仅供本地验收，不自动部署。下一步产品验证应观察家长和孩子能否在短时间内说清“想探索的角色、准备做的第一件作品”，以及是否实际开始体验。这些用户行为尚未经过试用验证。
