# 项目库学习路径图

在“全部项目”的筛选器上方，用同一个领域的作品变化说明：用户可以从短体验开始，逐步学习方法、搭建系统，再进入完整工程。以现有“太空探索”项目线为例，不增加必修顺序或解锁限制。

采用一张连续的真实工程场景图，四组作品由三条细箭头连接。相比抽象阶梯或多个领域的拼图，同一主题更容易表达知识与项目之间的连续性。

明确的视觉约束：图片内不写文字；不使用粗块状箭头。保留真实、可制作的 3D 打印探测车质感。阶段标题与说明是图片外的网页文字，沿用现有字体、配色和中英文切换。

- 先体验：3 分钟体验，拍下第一张星球照片。
- 学方法：引导课程，用观察写出驾驶规则。
- 搭系统：系统与挑战，组装并验证探测车。
- 做工程：完整工程，用探测车完成探索任务。

这四组对应现有项目类型；“系统与挑战”仍涵盖原有第 03、04 层，不改变网站的五层难度体系。

桌面使用横向图与四列说明。手机使用同一原图的四个局部画面，按顺序纵向排列，以向下箭头连接；不把横向图和小字缩成无法阅读的缩略图。图片外提供进入项目线视图的链接。

资源采用静态 WebP：桌面 960 / 1440 / 2172 宽响应式版本，约 49 / 93 / 162 KiB；手机共享一份约 89 KiB 的原始场景衍生图。源图、提示词与浏览器验收记录保存在 `artifacts/library-learning-path/`。

仅修改项目库入口并新增独立组件和样式。不改动原有分类、搜索、排序、筛选状态、课程资料或学习记录。
