# 五节总结影片：按内容切换场景

用户反馈：第一版五段几乎都是同一指挥室人物讲话，画面没有跟随阶段任务。此次重做同一章 M01–M05，其他小节不扩展。

选择多镜头卡通场景加精确的动态操作图解。每段均保留林岚指挥官动态出镜，随后切入具体对象、仪器、手部操作与成果。用户再次明确要求所有视频出现指挥官形象，此要求已写入根目录 `AGENTS.md`。保留既定角色、指挥官音色和 Firmament_Active 配乐。只改变媒体，不改节点、进度或视频播放入口。

| 小节 | 生成动画的镜头 | 后半段精确动态演示 |
| --- | --- | --- |
| M01 | 林岚 → 遮挡 → 恒星暗斑 → 探测器校准 | 亮度读数变化；区分观察与待检验解释 |

每段约 28–32 秒。林岚出场约 2–3 秒，接两个本节专属的生成场景；第 4 个镜头切到精确绘制的设备/数据特写，后半段由逐句配音驱动教学动画。生成画面中的坐标特写曾出现不可靠字符，已用精确动态画面替换。具体时长随正常语速配音确定，不加速配音。全片字幕与场景切点写入时间线。情境画面注明示意，数据动画使用明确标注的构造数据，不伪装 Kepler-10 实测，也不声称学生已提交作品。

生成设置：Wan 2.6 i2v，`shot_type=multi`，`prompt_extend=true`。与第一版的固定镜头设置不同。依据[官方多镜头说明](https://help.aliyun.com/en/model-studio/image-to-video-guide)。生成动画与程序绘制的教学动画分别存放、分别检查，最终用 FFmpeg 合成。

验收不只检查不同帧的哈希：按时间线抽取每个场景，肉眼核对对象/景别/操作变化；检测生成段真实切镜；核对数据动画与配音对应；检查完整解码、字幕时间边界、音频峰值。最后在 iPad 模拟器逐一完成五节，检查自动播放、回看、退出、继续。
