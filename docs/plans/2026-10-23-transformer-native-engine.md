# Transformer 自主引擎：实现决策与验收

## 目标与边界

用户要求替换直接复用的 3D Transformer，验证自主实现与跨算法抽象能力。保留已认可的结构总览、数学下钻、Python 练习和学习记录。此次不采用 course_factory，不改正式课程课堂，不训练新权重，不部署。

## 决策

采用“纯数值适配器 → 计算图及逐元素解释 → 算法无关的 Three.js 渲染 → React 教学面板”。没有继续修改 upstream 的模型场景，也没有重写通用 WebGL 基础设施。

- `transformer.ts` 依据标准算子独立计算 114 个张量节点，返回真实中间结果。
- `graph.ts` 定义二维张量、运算、依赖与解释。维度、数值和引用是同一份数据。
- `scenes.ts` 管理八个局部场景及整体视图；折叠节点用最近可见祖先虚线连接，完整计算依赖不被改写。
- `renderer.ts` 实现实例化格子、相机、拾取、精确窗口、依赖高亮。没有 Transformer/CNN 专属分支。
- `explorer.ts` 负责模式、步骤、输入与模型学习面板的适配。
- `convolution.ts` 以相同协议呈现 2D 互相关，使用正方形空间格子和滑动窗口叙事。

权重使用已有公开 minGPT 排序权重，保持 MIT 许可和固定上游提交。Three.js/OrbitControls 是图形基础设施。归档 WASM 仅用于测试对照。运行入口不引用原 bridge.js/vendor。

## 权衡与限制

- 双精度 JS 便于阅读和逐元素追溯，适合这个 3×3×48 小模型；不用于大模型高性能推理。
- 8×12 显示窗口控制 WebGL 对象数量；完整数值不抽样。索引定位同步移动窗口与高度、颜色、范围标签。
- 局部场景可能折叠直接来源；上游追踪可打开真实父节点。不能把当前窗口的高亮数量误当全部参与项。
- 动画逐格回放已算结果，不能当训练过程或实际运行耗时。
- 目前通用范围为二维张量图。新增运算需解释规则；其他数据结构需要协议扩展。
- 既有记录 key/version/节点 ID 不变；卷积只是引擎验证示例，不增加 Transformer 合格进度。

## 验收证据

- `artifacts/transformer-native/numerical-checks.json`：20 项数值/结构检查。归档实现对照最大绝对差 3.1326e-6。
- `verify-study.cjs`：8 部件、65 公式项、30 推导步骤、127 公式渲染和数学行为检查通过。
- 浏览器检查与截图见同目录 UI 证据。QA 使用 `?practice=1`，不写正式学习成绩。
- 改动文件 ESLint；全项目 TypeScript 结果单独记录已有错误，不声称全项目通过。

最终 UI 验收包括真实格子拾取、层/头切换、143/191 列窗口、卷积输入干预与时间线终点、Python 动态模型检查、记录恢复和窄屏无横向溢出。检查发现并修复了窗口更新的颜色/高度/标签同步、跨算法上游播放、播放终点回绕、旧格子信息残留和尺寸变化后的相机适配。全项目 tsc 剩余 6 个既有错误，详情见 typecheck-baseline.txt；本次模块没有类型错误。未运行全站生产构建，未部署。
