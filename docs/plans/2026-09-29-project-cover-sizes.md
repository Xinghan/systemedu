# 项目封面按尺寸加载

pvlib 正式封面原图为 1536×1024 PNG，2,723,229 字节。已发布课程卡片和详情页直接使用内容服务原图，未经过本地项目卡片已有的图片优化路径。

保留课程源的高清原图，生成宽 480、800、1280 像素的 WebP。文件名包含原图摘要，避免替换图片后命中旧缓存。公开静态展示图通过 `srcset` 和 `sizes` 按实际显示宽度与屏幕像素密度选择；卡片延迟加载，详情页封面优先加载。没有预生成尺寸的项目保留已有封面路径与失败回退。

生成脚本：`node scripts/generate-project-cover-variants.mjs pvlib-solar-forecast-station /path/to/cover-concept-v1.png`。本次仅为该课程生成尺寸；其他八个老项目已有独立 WebP，不更换内容或构图。

检查生成图尺寸、体积、解码和原图摘要；在浏览器验证卡片和详情页实际请求 WebP、原图不再下载，并检查手机页面。此改动完成后提交并推送，生产发布状态另行说明。
