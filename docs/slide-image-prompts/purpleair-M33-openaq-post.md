## Prompt set

### s1 — 从读者变成贡献者

青少年创客把节点输出的一颗蓝色数据珠，经简洁石板蓝轨道送入右侧的地球档案柜；新珠在共享馆藏中发亮。突出一条个人观测进入全世界可用的公共收藏。

### s2 — 穿过门槛成为公开数据

左侧室内工作台的空气节点通过敞开的门，把蓝色数据珠送向右侧由学校、家庭和社区建筑共同围成的开放档案桌。门槛与向外移动必须一眼可读。

### s3 — 一取一放的同一座柜子

中央是同一座有圆形插槽的共享档案柜：一侧创客把一颗珠放进个人研读托盘，另一侧创客把空气节点的新珠放入空插槽。只用两种动作解释读取与贡献。

### s4 — 凭证保护写入

同一档案柜左侧开放读架可供查阅；右侧受保护圆形入口前，青少年创客在可信成人陪同下拿着无字的黄铜珊瑚色凭证，把一颗新珠放入入口。凭证和数据珠必须清楚分开，绝不出现密码字符。

### s6 — 一颗珠的完整贡献旅程

一条连续实体轨道连接五个克制的工作台动作：整理携带珠的测量小包、夹上无字凭证、送入档案入口、亮起确认灯、在放大镜下从共享托盘再次找到同一颗珠。无文字、编号、流程图方框或多余分叉。

### s10 — 两条同样成功的公开路径

中央空气节点经过一个小型实体分流器，把相同蓝色数据珠送到左侧全球档案地球和右侧有邻居围观的社区公开展示台；两条轨道都完整、结实、等价，门后数据正离开家。
