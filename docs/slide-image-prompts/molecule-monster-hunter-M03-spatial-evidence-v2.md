## 教学问题与方法选择

本节不是让学生认出一个分子图标，而是把连接、空间观察、计数口径和可复查报告连起来。沿用浅色课程主题、精确结构与真实交互。空间页采用 PubChem 计算构象构建的 Three.js 模型；连接比较用 RDKit；公式用 KaTeX/mhchem。生成图片不能提供旋转或可靠计数，本节点不增加无信息量的物体美图。五个空间页不是反应或分子动力学。

## 来源与模型边界

四组坐标延续 `M03-sources/*.sdf`（水 CID 962、甲烷 CID 297、乙醇 CID 702、苯 CID 241），原始 hash 保留。已计算构象不是实验照片或唯一姿态。原课的“碳永远四只手”“电子绕圈”等绝对/实体化比喻不进入新版讲稿。常见中性闭壳层分子中讨论键级和，平均质量区分 Da、相对分子质量与 g/mol。

Python 模板显式 `from rdkit import Chem`、`Chem.AddHs`、`Descriptors.MolWt`、`rdMolDescriptors.CalcNumRings/CalcNumAromaticRings`，JSON 包含解释器和 RDKit 版本。网页核验字段/参考值不能独立证实执行来源；M02 环境不同会提示复查，不自动覆盖它。
