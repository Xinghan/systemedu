## 纠正的教学语义

- 风险数值越低越偏好，归一化后反向；相同归一化值不等于相同科学价值，更不是安全概率。
- 权重按比例归一化，改变权重不保证名次一定改变，也不保证候选的总分上升。
- M86 已拒绝的候选不能通过加分重新进入排名。
- 二元初筛通过值保留为 1，不执行除零的 min-max；连续常数列明确无区分度。
- 所有候选使用共同范围。未来越界值不静默截断；常数参考范围遇到不同新值时拒绝计算。
- 用未舍入总分排序，真正同分再按 ID 升序。缺失、非有限值和重复 ID 明确拒绝。
- 合成 ID 没有真实结构；M88 的多样性计算必须另接经验证的结构，不能凭 ID 编造分子指纹。
