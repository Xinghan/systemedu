## s1 语义简报与映射

1. 教学主张：分子在正辛醇（油相）与水相之间有不同分配比例；这个比例的对数将“亲油/亲水”变成可比较的 LogP 数值。
2. 具体实体：正辛醇相、水相、分配系数 `P = C正辛醇 / C水`、`LogP = log₁₀(P)`、葡萄糖、乙醇、辛烷。
3. 关系：相中相对浓度 → `P` → `LogP` 数轴位置；`P > 1` 表示油相更多，`P < 1` 表示水相更多。
4. 媒介：HTML/SVG。精确化学术语、公式、刻度、数值与“cLogP 是计算估计”的边界必须是确定性可读文本。

- 映射：仅 `payload.inline_svg`，不引用图片文件。
- 示例值：本地 RDKit Crippen 计算：辛烷 `+3.37`、乙醇 `−0.00`、葡萄糖 `−3.22`。
