A real interactive interface and precise report are the appropriate product visuals. Images and 3D were considered, but a photo-like device, factory analogy or extruded flowchart would not reveal an additional source-backed relationship. This batch therefore has no new generated raster or 3D object; that is a content decision, not an HTML default. M38's approved picture and 3D work remain intact.

## Data and scientific boundaries

- Actual chemical connectivity/descriptors are computed with installed RDKit.js 2025.3.4-1.0.0. The feature method/version/order are part of the interface contract.
- No trained artifact or per-student predictions were found in the inspected M84b/M90 course node sources. Mock predictions and four numeric assessment rows are explicitly pedagogical constructions; none are toxicity/solubility measurements or real course-model metrics. The preview cannot certify the actual final project as complete.
- Go/No-Go means a recommendation under the disclosed **teaching** rule, not safety, efficacy or permission to use a compound. Missing real-model and scaffold evidence is shown separately as “需要更多证据”.
- The original prose overstates scaffold split as guaranteeing truthful future performance. The new narration keeps the intended anti-leakage lesson but explains that scaffold grouping only addresses a particular structural overlap; it does not eliminate all leakage or guarantee performance on every new molecule.
- Metric references: [ROC-AUC](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html), [MAE](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_absolute_error.html), [DeepChem ScaffoldSplitter](https://deepchem.readthedocs.io/en/latest/api_reference/splitters.html#scaffoldsplitter). Group labels in the teaching audit are synthetic, not a newly computed scaffold dataset.
