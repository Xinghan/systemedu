## 精度修正与依据

- 删除“全世界都在用”“环境完全就绪”“安装一辈子一次”“每个单元格都必须导入”等绝对说法。新环境、升级或删除包后可能需要重新安装；重启解释器后需要恢复名称绑定。
- 安装命令要与目标解释器匹配。Notebook 用当前 kernel 的 `%pip`，普通终端用已选环境的 `python -m pip`，不把终端命令写成普通 Python 语法。
- `import rdkit` 不等于自动导入所有子模块；后续 `Chem` 按需显式导入。
- 版本日志仅证明该环境可导入并读取元数据；不证明所有计算都正确。浏览器 RDKit 与学生电脑 Python 是不同运行环境。
- 官方核对日期 2026-09-10：[RDKit 安装](https://www.rdkit.org/docs/Install.html)、[Python 模块](https://docs.python.org/3/tutorial/modules.html)、[IPython %pip](https://ipython.readthedocs.io/en/stable/interactive/magics.html#magic-pip)、[RDKit.js 示例](https://www.rdkitjs.com/)。
