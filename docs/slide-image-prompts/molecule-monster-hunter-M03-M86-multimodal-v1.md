## 数据来源与科学审查

M03：水 CID 962、甲烷 CID 297、乙醇 CID 702、苯 CID 241。读取 PubChem 的公开计算构象 SDF，原始响应保存于 `M03-sources/`，各 SDF 的 SHA-256 写入模型 JSON。RDKit 2025.03.4 比较去显式氢后的拓扑与 SMILES，并独立重算原子数、重原子数、环、芳香环与平均分子质量。

计算坐标模型不是实验照片、唯一构象、分子动力学或电子轨迹。甲烷 H–C–H 角约 109.47°；苯相对前三原子平面的最大偏离约 0.0003 Å，六条 C–C 键长在显示精度内均为 1.395 Å。共面只是几何证据，不独立构成芳香性判据。球半径只为辨认；芳香 C–C 连接用等同连杆，不把 Kekulé 线数伪装成物理长短键。

官方依据：[PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)、[RDKit 氢与计数示例](https://www.rdkit.org/docs/GettingStartedInPython.html)、[RDKit 芳香性模型](https://www.rdkit.org/docs/RDKit_Book.html)。

M86：旧动画给出一组硬编码递减数，旧游戏用保留率相乘，未找到可验证的 5000 条真实分子记录。本轮不把它们冒充 RDKit 真值；采用明确标注的 5000 行固定种子合成数据（LCG，seed 8603），从具体字段逐行计算四个条件。模型风险与溶解度字段均为教学构造值，未调用真实预测模型。成本按每行 1 / 2 / 3 / 4 单位的教学假设计算，不称为毫秒。

默认结果：`5000 → 1764 → 1023 → 880 → 255`，成本 15,117 单位。24 种固定独立规则排列的最终 ID 集合相同；这批数据成本最少的顺序是性质 → 溶解度 → 风险分数 → 固定参考相似度，共 13,487 单位。说明便宜先做不是无需条件的最优定理。相似度规则相对于固定参考，不是有状态的边筛边去重。

原作业 `5000 → 1800 → 600 → 550` 保留为独立练习，页面明确区分它与合成数据运行结果。拒绝数为 3200、1200、50。
