## 决策约束

- `presentation_mode: readonly`。主表达仍由学习问题决定：图片、精确公式、RDKit、3D、流程、实验与模拟均可选。
- 页面内部不提供输入框、答题、参数滑条、执行/保存/下载、完成确认；不访问学生个人草稿，不产生任务完成状态。
- 时间过程用预设输入自动演示，3D 用有教学意义的预设视角/剖面/组装状态。保留完整静态证据；不能停留在“把原有按钮隐藏”后内容不全的状态。
- 翻页、音频、暂停/重播归外层播放器。尊重减少动态设置，离屏/标签隐藏暂停计算。
- 操作练习和提交属于任务区；不得未经请求新建或搬迁练习工作流。
- 讲稿、标题、示例说明要一起改，旧配音不匹配时解绑。保留源 slide ID / kind / lesson anchor。
