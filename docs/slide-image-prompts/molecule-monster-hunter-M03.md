## 本轮语义简报

- **s1**：水、甲烷、乙醇、苯 → RDKit → 4 项骨架报告。媒介为 HTML/SVG，因为“读出什么字段”和具体数值是教学内容。
- **s2**：元素节点 + 化学键 + 乙醇连接图 → 链/支链/环。媒介为 HTML/SVG，因为它讲的是拓扑关系，不是分子的外观。
- **s3**：元素相对质量 → 化学式计数 → 水的展开算式 → 其他分子。媒介为 HTML/SVG，保证公式可读且可核验。
- **s4**：共享电子对 → 键级 → 乙烷/乙烯/乙炔结构式 → `SINGLE/DOUBLE/TRIPLE`。媒介为 HTML/SVG，保证键线数和术语准确。
- **s5**：甲烷、乙烯、乙炔的键级和都为 4 → 碳—碳的链/支链/环拓扑 → 对不成立结构的验算。媒介为 HTML/SVG。
- **s6**：苯的六元环 → 两种共振式 → 电子离域模型 → `c1ccccc1` 的芳香原子与环。媒介为带轻量定时运动的 HTML/SVG；运动表示模型中的“位置不固定”，不充当装饰。
- **s9**：4 个 SMILES 输入 → `AddHs/MolFromSmiles` 读取 → 原子/键/环/芳香环字段 → 可提交表格与一句发现。媒介为 HTML/SVG。
- **s10**：原子与键的结构图 → M03 骨架小报告 → “加一个 —OH 会怎样”的下一个可研究问题。媒介为 HTML/SVG，使结尾成为阶段成果到下一阶段的明确接口。
