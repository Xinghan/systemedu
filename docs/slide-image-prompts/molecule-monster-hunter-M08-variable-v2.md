## 共同手段判断

采用精确 DOM 代码与离散状态过程，而不是盒子图标。图片不能可靠表示引号、名称解析与输出，3D 不增加空间知识；化学结构已在 M05/M07 学过，本节不重复增加分子模型。主要困惑在“名字与值”“引号内外”“运行先后”。所有关键文字可选中，浅色项目配色；不引入人物或低龄道具。
动态是经过 Python 核验的教学轨迹，不声称浏览器运行任意 Python。用户可播放、暂停、单步、重置，离屏停止。解释不等于实机执行证明：最终产物仍是本人在 Python 运行后的脚本与输出记录。
