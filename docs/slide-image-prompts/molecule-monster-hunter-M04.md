## s1 语义简报

1. 教学主张：只把乙烷的一个 `C—H` 替换为 `C—O—H`，就能以对照实验归因于 `—OH`，并在同一 RDKit 指标中观察到 cLogP 的下降。
2. 具体实体：乙烷 `CC` / `CH₃—CH₃`、乙醇 `CCO` / `CH₃—CH₂—OH`、羟基 `—OH`、cLogP。
3. 关系：保持两碳骨架、算法和指标不变；唯一变量为 `H → —OH`；RDKit Crippen cLogP 从 `+1.0262` 到 `−0.0014`，差值 `−1.0276`。
4. 媒介：3D 栅格对象图 + RDKit.js 二维结构 DOM。空间物体补充构型；结构式、变量控制和数值仍须可读、可复制、可核验。

### s1 的 3D 对象层

- **教学主张**：空间模型让学生看见两边都保留两颗碳，只有乙醇模型多出一个氧和羟基氢；它不负责讲解数值或因果。
- **实体与关系**：左为乙烷（两颗深灰碳、六颗白氢），右为乙醇（相同两碳骨架、五颗白氢、一个红氧与一个羟基氢），中间是“乙烷变乙醇”的单一方向。
- **媒介判断**：混合式。3D 栅格图适合传达空间物体；二维骨架式必须由 RDKit.js 根据 `CC` / `CCO` 生成，标签、SMILES、cLogP 和变量控制必须留在 DOM，不能交由图片模型渲染。
- **最终图片**：`knodes/M04-w0-module/images/m04-ethane-ethanol-3d-v1.webp`，1408×792，12 KB；无生成文字。
- **生成提示词（执行版）**：`clean accurate 3D ball-and-stick comparison of ethane becoming ethanol by replacing one hydrogen with a hydroxyl group; ethane left, ethanol right, same two-carbon backbone, red oxygen only on ethanol, warm-white background, simple neutral arrow, no text, no people, no lab equipment, no decorative particles or dark rendering`。

### s1 的精确结构层

- **渲染器**：本地固定版本的 `@rdkit/rdkit`（RDKit.js WebAssembly），不使用 CDN；`RDKit_minimal.js` 与同版本 `.wasm` 一起随学生端静态资源部署。
- **输入**：乙烷为 SMILES `CC`，乙醇为 `CCO`；乙醇的原子索引 `2`（氧原子）以黄色高亮，准确对应唯一新增的 `—OH` 位点。
- **可见证据**：两张 RDKit 骨架式下方并列写出固定变量 `C—C · 同一算法`、`CC` 的 `+1.0262`、`CCO` 的 `−0.0014` 以及 `Δ cLogP = −1.0276`。
- **职责边界**：RDKit 负责可核验的二维化学结构；3D 栅格图只负责空间构型；状态序列负责按“改造结构 → 同尺测量 → 写入证据”呈现实验顺序。

## s2 / s3 / s4 / s5 / s8 / s9 语义简报

- **s2**：从 `CC` / `CCO` 的结构差异出发，明确固定变量为两碳骨架、同一 Crippen 算法和 cLogP，唯一变量为 `H → —OH`；最后写入 `+1.0262`、`−0.0014` 与差值 `−1.0276`。这三件事组成一条实验链，而非三个彼此无关的词。
- **s3**：先画出 `CH₃—CH₂—□` 的连接位点，再分别给出羟基 `—O—H`（一氧一氢）和氨基 `—N H₂`（一氮两氢）。水的 `H—O—H` 仅用于解释 `—OH` 的亲水线索；不把 `—OH` 与 `—NH₂` 混为同一官能团，也不把比喻当作结构证据。
- **s4**：乙烷 `CC` 与乙醇 `CCO`；固定两碳骨架、Crippen 算法和 cLogP，唯一变量为 `H → —OH`；以乙烷与苯的错误比较说明多变量不能归因。媒介为 HTML/SVG。
- **s5**：乙烷基线 `+1.0262` → `—OH` 替换一个 H → 乙醇的水作用位点与 `−0.0014`。SVG 循环让官能团进入结构、虚线作用位点出现、cLogP 指针左移；每帧都对应实验中的真实状态。
- **s8**：`CC` 与 `CCO` 分别运行同一 `Crippen.MolLogP` 计算，按顺序写入两行记录，再补上唯一改动与因果句。SVG 循环高亮对应的计算阶段，不以闪烁代替过程。
- **s9**：把本节记录拆成“唯一改动、同一测量、数值差异、因果句”四项，让学生能复查并交付。底部精确衔接下一节：`CCO` 是将要学习书写和读取的 SMILES，而不是用一枚大勾模糊地宣告完成。

## 动态策略

- s1、s2、s3、s9 都添加 `teaching_sequence`：每 2.4 秒推进一次真实教学状态，依次显示“已保留为证据 / 正在展示 / 等待下一步”。
- s1 的状态是“改造结构 → 同尺测量 → 写入证据”；s2 是“读结构 → 做对照 → 保留数值”；s3 是“定位连接位点 → 读原子组成 → 确定本节变量”；s9 是“保存输入 → 保存测量 → 保存结论”。
- 渲染器以数据驱动的 HTML 状态卡展示这些步骤，后续任意课程页可复用；它不是循环箭头或闪烁装饰。s5、s8 原有的 SVG 状态动画继续保留。
