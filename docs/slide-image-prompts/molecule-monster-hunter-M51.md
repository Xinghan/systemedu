# 分子怪物猎人 · M51 讲课视觉记录

## s1：全库指纹矩阵

### 语义简报

1. 教学主张：循环把每个分子变成同样长度的 Morgan 指纹；这些行可对齐叠成全库指纹矩阵。
2. 具体实体：苯、乙醇、醋酸；三条 16 位 0/1 指纹；由这些行构成的矩阵。
3. 关系：每个分子 → 一条定长指纹 → 每行对齐叠成矩阵 → AI 可以读取。
4. 最终媒介：HTML/SVG。分子式、指纹位、矩阵、形状和箭头都必须是确定性内容，不能让图像模型生成。

### 实现

- 位置：M51-w0-module/slides.json 的 s1.payload.inline_svg
- 风格：暖白底、深蓝线条、青色代表取值为 1 的位；无深色氛围背景。
- 该图直接表达信息流，不使用任何栅格图片。

### 质量检查

- 图中每个分子、指纹行、矩阵行列和箭头均来自原始讲稿。
- SVG 说明“定长才能对齐”，不把化学结构、位值或矩阵关系交给图像模型。
- 未部署生产环境。

## s3：循环批量处理

### 语义简报

1. 教学主张：循环体只写一份；运行时依次改变的是当前 `smi` 和收集到的结果行。
2. 具体实体：`smiles_list` 的乙醇、苯、醋酸三项；`for smi in smiles_list`；Morgan 16 位窗口；`fps.append`；矩阵 `X.shape = (N, 2048)`。
3. 关系：当前 SMILES → 同一段循环体 → 新增一行指纹；`N` 增长而指纹宽度 2048 不变。
4. 最终媒介：带时序状态的 HTML/SVG。代码、SMILES、矩阵形状和逐步变化必须准确；这里没有需要栅格图片承担的空间信息。

### 实现与检查

- 位置：M51-w0-module/slides.json 的 s3.payload.inline_svg。
- 动态：三个当前项的高亮按顺序循环，说明运行中的状态变化不是装饰性箭头。
- 静态执行追踪仍保留三条真实输入和三行输出，即使暂停画面也可读。
