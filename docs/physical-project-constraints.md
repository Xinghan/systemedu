# 实体项目制作边界

2026-09-21 用户明确要求：普通学生没有金属加工设备，实体制作统一使用 3D 打印；课程、运行模型和配图必须与这条路线一致。此约束适用于后续项目线制作与相关改造，不仅是封面风格。

- 学生设计和制作的结构件以普通桌面 3D 打印或代打印完成，不安排车削、铣削、焊接金属、钣金、金属铸造等学生制造步骤，也不用金属增材制造冒充家庭可行方案。
- 制作任务包含实际可修改的尺寸、配合、连接、机构或安装设计；不能只给现成机器换一个打印外壳，就称为学生完成实体制作。
- 有实体交付要求的项目提供可编辑 CAD 源、单位与关键尺寸、对应 STL/3MF、打印方向/材料/支撑与装配说明、试配件及测试方法。未切片、未试配、未实作分别标明，数字检查不等于实物通过。
- 封面与互动模型使用同一实体方案，显示可信的打印件形态、材料与接合结构。不以精加工金属机器作为学生作品的主要展示，也不把生成图片当成真实打印或测试证据。
- 机构、载荷和温度按打印材料重新设计；涉及高温或明火的旧方案不得简单把金属换成塑料。若核心机制不能在这个制造边界内实现，需要改变实体方案，保留相关理论的独立学习价值。
- 用户已确认接近“结构件全部打印、标准件可采购”：允许少量简单通用件，包括简单金属齿轮、电机、传感器、轴承和螺丝等；尽量避免复杂金属件或总成的购买。材料单逐项区分打印件、简单采购件，不以整台金属机器代替学生制作。

当前影响：spec 059“动力发明家”原金属热机与手摇发电主线均已调整，用户最新选择是太阳能、风能、储能与智能控制组成的风光储能源站。核能不纳入这条实践项目线；手摇装置仅保留为可选支线候选。原 `stirling-thermal-controller` 完整课程仍是既有内容，不能宣称其金属/明火方案已经符合新约束，不作为这条新实体路线的必经终点。
