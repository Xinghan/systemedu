# Satellite Archaeology 成品使用 3D 版 — 设计 Prompt

> 项目: satellite-archaeology (AI Satellite Archaeologist, Sentinel-2 Site Detection)
> 范式: **项目级产出物模拟 — 成品使用体验**(不是制作过程), 全屏 3D 场景, 成品是主角。
> 前作参照: emg_prosthetic_hand_3D.html / mars_analog_rover_3D.html (已验收)。
> 旧 2D 制作过程版 satellite_archaeology_project_game.html 已被范式取代, 领域建模继承。

## 0. 范式声明(硬约束)

- 玩家打开页面时, **模型已经训练好、管线已经部署好**: 一颗侦察卫星在低轨待命,
  地面是一片 100 km² 的调查区域 3D 沙盘。没有任何"标注/训练/调参/章节"步骤。
- 玩家做的事 = **使用这台自己造出来的发现机器**: 派卫星过境扫描 → 看探测器把候选遗址
  从麦田里"钓"出来 → 拧阈值旋钮 → 多时相下钻剔除假阳性 → 锁定高置信度候选 →
  生成负责任披露报告。全程是"指挥 + 判读 + 决断", 感受"学完 32 周你将拥有什么"。
- 全屏 3D(Three.js r149 UMD 内联, 自写轨道相机), 深空背景 + 地表沙盘 + 卫星都是实体。
  禁止 2D 看板式界面; HUD 只做薄薄一层遥测与指令条。

## 1. 成品定义(玩家拥有的东西)

学生 32 周后的最终产出物, 在游戏里表现为一套已部署的**卫星考古发现平台 "ARGUS-1"**:

1. **侦察卫星**(Sentinel-2 风格): 多光谱相机, 10m 分辨率, 条带宽约为沙盘宽度的 1/6,
   沿准极轨道过境, 每次过境向侧步进一条轨道(5 日重访周期的游戏化)。
2. **训练好的 CNN 探测器**: 对扫过区域逐格打分(0-1 置信度), 已在 3 处已知遗址上训练
   (沙盘上有 3 个金色"训练遗址"标牌, 开场即可见 —— 这是"你训练过它"的叙事锚点)。
3. **多时相档案**: 每个格子存 4 季 NDVI, 下钻时拉出季节曲线做真假鉴别。
4. **负责任披露流水线**: 坐标模糊化(fuzzCoord) + 文物局邮件式报告生成器。

## 2. 3D 场景与美术

### 2.1 地表沙盘(主角之一)
- 安纳托利亚/美索不达米亚风格农业平原: 程序化 heightmap(平缓起伏 + 一条古河道洼地
  蜿蜒穿过 + 2-3 个极低矮的 tell 遗丘鼓包, 高度低到肉眼几乎看不出 —— 这正是
  "肉眼看不见, 光谱看得见"的戏剧点)。
- 地表纹理: **程序化 canvas 农田拼块**(卫星正射视角最像真): 不规则四边形田块
  棕/绿/黄绿拼色 + 细田埂线 + 村庄灰色像素簇 + 河道深色蜿蜒带 + 2-3 个现代喷灌圆
  (圆形深绿盘, 假阳性诱因之一)。法线/粗糙度可复用 CC0 sandN/sandR 微起伏。
- **NDVI 揭示层**: 地形上方 0.05 处同尺寸透明平面, 独立 canvas 纹理。未扫描区域全透明;
  卫星条带扫过后, 该条带区域渲染 NDVI 假彩色(棕→黄→绿色带) + crop mark 处显出
  几何异常(矩形/圆形/线性轮廓, NDVI 系统性偏低)。扫描揭示 = 本产品的"啊哈"时刻:
  真彩色农田上什么都没有, NDVI 层一铺, 埋 3000 年的城墙轮廓浮出来。
- 沙盘边缘渐隐到深空(边缘环形渐变或雾), 呈"轨道视角看一块被切出来的大地"。

### 2.2 卫星(主角之二)
- Sentinel-2 风格: 金箔 MLI 包覆主体(继承 mars 金箔材质做法: 金属+皱褶法线) +
  双太阳翼(深蓝电池片+格线) + 下视镜头筒(金色环) + 数传天线。
- 沿直线轨道匀速飞越沙盘上空(高度 ~ 沙盘宽度的 0.4), 过境时向下投**半透明扫描幕**
  (窄长条棱台/面片, 青色微光), 地面 NDVI 层同步沿飞行方向揭示 —— 扫描幕扫到哪,
  地上亮到哪。过境结束卫星飞出沙盘外淡出, 下次过境从另一侧进入(轨道侧移一条带)。
- 待命时卫星悬停在沙盘一角上空缓慢自转(呼吸感)。

### 2.3 候选遗址标记
- 探测器打分 > 当前阈值的格子升起**置信度柱**: 半透明橙色圆柱, 高度与分数成正比,
  顶端小球, 底部脉冲环。点击可选中(射线拾取)。
- 已确认真候选 → 柱变青色; 已剔除假阳性 → 柱塌缩成暗灰矮桩(留痕, 不消失)。
- 3 个训练遗址: 金色低圆台 + 小旗, 开场即在, 不参与候选逻辑(它们是"已知"的)。

### 2.4 光照与基调
- 深空背景(星点) + 主平行光(硬阴影) + 半球光; 地表暖色(麦田金), NDVI 层伪彩,
  整体"轨道上的科学仪器"冷暖对比。PMREM 环境给卫星金箔真反射。

## 3. 交互与任务链

### 3.1 核心交互(使用旋钮)
1. **派过境扫描**: 点地面任意点 → 下一条轨道对准该点; 或按底部"下一次过境"顺序扫。
   卫星入场-扫描-出场全程 6-9 秒, 遥测实时刷新覆盖率。
2. **置信度阈值滑杆**(右面板): 拖动即时增减候选柱。拖低 → 假阳性丛生(喷灌圆全亮),
   拖高 → 只剩最强信号但可能漏检。旁边实时显示"当前候选数 / 预估查准率"。
3. **季节切换**(春/夏/秋/冬 4 键): NDVI 层整体重渲。crop mark 春末最深、夏季变浅,
   喷灌圆四季常绿, 古河道秋季反差最大 —— 切季节本身就是一次判读教学。
4. **候选下钻**: 点置信度柱 → 侧卡拉出该格 **4 季 NDVI 曲线 + 40x40 局部放大图**,
   两个按钮: `确认为候选` / `判为假阳性`。判对判错都有即时反馈(引擎知道真值):
   判错弹出解释(如"这是中心支轴喷灌: 四季 NDVI 都高且圆形过于完美"), 判对加进短名单。
5. **生成披露报告**: 短名单 ≥1 时可用。报告 overlay: 模糊坐标(1km 网格 + 加盐)、
   证据缩略、给文物局的邮件式正文、CC-BY 方法开源声明(坐标除外)。
   报告里有一个诱饵按钮"附上精确坐标公开发布" → 触发**盗掘风险警示演出**(红闪 +
   ICOMOS 负责任披露说明), 必须选"仅送文物局内部评审"才能完成 —— 伦理是产品的一部分。

### 3.2 任务链(SOL 式仪式, 非门控)
1. 完成第一次过境扫描, 看 NDVI 层揭示。
2. 让候选数 ≥ 12(覆盖率不足时提示继续过境)。
3. 下钻: 剔除 1 个假阳性 + 确认 1 个真候选。
4. 生成负责任披露报告(仪式收尾: Discovery Report + Parcak "17 座金字塔"致敬语)。

### 3.3 隐形礼物 bubble(点破产品替玩家做了什么)
- 第一次扫描出候选时: "探测器刚替你看了 4 万个格子 —— 你 32 周训练的 CNN, 3 秒扫完一个县。"
- 第一次剔除假阳性时: "它学会了看时间: 单季会骗人, 四季不会。"
- 报告生成时: "坐标已模糊化 —— 发现权属于科学, 位置只属于文物局。"

## 4. 真算引擎(纯函数, node 可单测)

- `genRegion(seed)`: 确定性生成 heightmap、田块图、古河道路径、村庄、3 训练遗址、
  6-8 个埋藏真遗址(类型: tell 遗丘/罗马别墅 crop mark/几何土方; 各带几何签名参数)、
  8-12 个假阳性源(喷灌圆/田界十字/古河道弯/云影斑)。真值表玩家不可见。
- `ndviAt(x,z,season)`: 基底作物 NDVI(按田块+季节) + 遗址 crop mark 压低效应
  (几何形状内 NDVI -0.12~-0.2, 春季最强) + 假阳性源效应 + 确定性噪声。逐像素真算。
- `detectorScore(cx,cz)`: 模型对格子的打分 = 几何规则度响应 + NDVI 异常深度 +
  纹理方差项, 真遗址 0.75-0.95, 强假阳性 0.55-0.8, 背景 <0.35 + 噪声。**有重叠**
  (阈值旋钮才有意义)。
- `planPass(k | targetX)`: 第 k 条(或对准目标点的)轨道条带几何。
- `applyPass(strip)`: 标记覆盖格, 返回新增候选(score>0.3 的格聚类成 candidate)。
- `seasonCurve(cand)`: 4 季 NDVI 均值曲线; `classifyCurve(curve, meta)`: 引擎真值判别
  (真遗址: 持久低+春谷; 喷灌圆: 全季高; 田界: 高频线状; 河道: 秋季不对称)。
- `fuzzCoord(x,z,seed)`: 1km 网格化 + 确定性盐偏移, 返回模糊坐标串。
- `coverage()`: 已扫格/总格。
- 卫星运动学: 直线轨道参数化 pos(t), 扫描幕与条带映射同一参数 —— 视觉与数据严格同源。

## 5. UI 硬规范(继承前作验收)

- **所有说明文字深底亮字**: 深棕半透明面板(rgba(30,24,20,.84)) + 米白字(#f5ecdc),
  绝不让文字裸糊在地表/星空上。顶部任务讲解条、左任务卡、右遥测卡、底部指令条。
- 遥测卡(右): 当前 Pass 编号/覆盖率/候选数/短名单数/阈值滑杆/季节 4 键/模型卡
  (F1 0.87 / 训练集 3 sites / Sentinel-2 10m —— 静态铭牌, 强化"这是你训练的模型")。
- 数字/坐标 JetBrains Mono, 正文 Inter/PingFang SC。禁 emoji, 图形全 SVG/canvas/3D。
- 中英双语即时切换(EN 键), 全部文案走 T 表。
- 1280x800 无滚动条; devicePixelRatio 适配。

## 6. 技术规格

- 单文件 HTML, 内联 three r149 UMD + 少量 CC0 法线纹理 base64, 零外部依赖。
- 状态机: `S = { ready, pass, coverage, candidates[], shortlist[], dismissed[],
  threshold, season, scanning(卫星过境动画态), tasks[], lang, camFollow, phase }`。
- rAF 主循环 + `simStep(dt)` 帧率无关(headless 慢帧安全); 关键对象与纯函数挂 window
  便于 Playwright 驱动与断言。
- NDVI canvas 纹理增量重绘(只画新揭示条带), 全季切换时整层重渲一次。
- 射线拾取候选柱; 轨道相机(拖旋转/滚轮缩放/双击复位), F 键跟随卫星。
