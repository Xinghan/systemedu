# 项目级"成品使用"模拟游戏设计 Prompt — emg-prosthetic-hand

> **范式定义(重要, 适用于所有项目)**: 这是"成品使用体验"版, 与旧的"制作过程"版根本不同。
>
> - **旧方向(废弃)**: 模拟学生**制作项目的过程** —— 分章节走开发流程(采集/训练/标定/调参),
>   有步骤门控、诊断返工。本质是"教你怎么做出来"。
> - **新方向(本文件)**: 模拟**做完之后的最终成品怎么用** —— 打开就是一个**已经做好的产品**,
>   用户直接**操作成品本身**、看它工作、感受"我学完这个项目就能得到这么个能用的东西"。
>   **没有制作步骤、没有章节达标、没有调参诊断返工。** 就是一个成品的操作台/使用现场。
>
> 用途: 项目级(而非 knode 级)。一个项目一个 HTML。让学生在开始学习前就"用到"自己
> 61 周后将做出的**成品**, 先尝到甜头、被成品的能力和价值打动, 从而想学。
> 本文件是给实现者(Claude Code)的完整设计规格, 实现时严格遵循。

## 0. 项目背景(来自 blueprint)

- 项目: 3D 打印肌电义肢手 — 用你自己的肌肉信号 (sEMG) 控制你打印的一只手, 10-12 岁, 61 周。
- 真实原型: Open Bionics Hero Arm (商用 3D 打印肌电义肢) + e-NABLE 全球志愿者网络。
- **最终成品**: 一只贴在前臂上、跟着肌肉发力开合抓握的仿生手 —— 五指腱驱动、五个舵机、
  前臂 sEMG 传感器读"握拳"信号、内置力反馈能握住鸡蛋而不捏碎、能做多种手势、能抓起并搬运物体。
- **成品的能力(游戏要让用户体验到的)**:
  1. 用肌肉意图(握拳强度)控制手开合 —— "用意念抓东西"。
  2. 多种手势: 握拳抓握 / 两指捏取 / 三指握 / 指向 —— 不同物件用不同抓法。
  3. 内置力控智能: 抓鸡蛋自动轻柔不捏碎、抓钢块用力、抓杯子适中 —— 用户不用调, 成品已经会。
  4. 能完成真实任务: 拿起物体、搬运、放到指定位置(如把鸡蛋放进碗、把杯子端到杯垫)。

## 1. 游戏定位与核心幻想

**名称**: 我的仿生手 / My Bionic Hand
**核心幻想**: 你戴上了自己做的这只仿生手。它已经调校完毕、随时能用。现在, **用你的肌肉去操作它** ——
握拳, 手就抓起桌上的鸡蛋且不捏碎; 换个手势, 捏起一支笔; 去抓沉甸甸的钢块, 它稳稳拿起。
你在**使用一件属于你的、真正能用的仿生装置**, 感受"这就是我 61 周后能亲手做出来的东西"。

**这不是制作模拟, 是产品体验**:
- 打开即面对一只**已经做好、已经戴在前臂上**的手 —— 不造它、不调它、不标定。
- 用户身份 = **佩戴者/使用者**, 不是工程师。
- 交互对象 = **成品本身 + 它要抓的物体**, 不是流水线/参数。
- 没有"章节/达标/诊断/返工"。有的是"一张摆满东西的桌子 + 一只随你意图动作的手 + 可完成的小任务"。

**设计原则**:
1. **零门槛即时爽**: 打开 3 秒内, 握拳 → 手动 → 抓起东西。先给甜头, 不讲原理不设关卡。
2. **成品的智能是"隐形的礼物"**: 力控、手势识别这些"做项目时辛苦调好的东西", 现在**默默替用户工作**
   (抓鸡蛋自动轻柔), 用户只体验结果, 偶尔用一个小提示点出"这只手内置了力反馈, 所以不会捏碎"。
3. **物理真实但服务于爽感**: 手的运动学、抓取的力/稳定性仍真算(不做假动画), 但目的是让"抓起来"
   这件事有真实的手感和反馈, 不是考核。
4. **给探索空间**: 多物体 + 多手势 + 可选小任务, 让用户自由玩、反复玩, 每次都发现手能做更多。
5. **传达价值而非难度**: 结尾不是"验收达标", 而是"看, 这只手能为你做这些" —— 落在成品的用途和意义上。

## 2. 结构: 单场景使用现场(非分章)

**不分章节**。一个连续的"仿生手使用现场"单页, 各能力自然铺开, 用户自由探索。
布局建议(1280×800):

- **主舞台(中央大区)**: 一张桌面工作台的侧视/等视图。桌上摆着一排可抓物体(鸡蛋、水杯、钢块、
  笔、方块、门把手等)。一只**戴在前臂残肢接口上的仿生手**悬在桌面上方, 可水平移动到不同物体上方。
  手随用户的"发力"实时开合抓取。抓起的物体跟着手移动, 可搬到桌上的目标区(碗/杯垫/收纳格)。
- **左侧控制区**: 用户操作手的输入 ——
  - **发力控制**: 一个大"握拳"按钮(按住=发力, 松开=放松)或一个发力强度滑杆(0-100%),
    模拟佩戴者的肌肉。手的开合跟随。空格键也可。
  - **手势切换**: 握拳抓握 / 两指捏取 / 三指捏 / 指向 —— 几个手势按钮, 决定手怎么闭合。
  - **移动手**: 左右移动手到不同物体上方(按钮/滑杆/点击目标物体自动移到其上方)。
- **右侧信息区(轻量, 服务爽感不做考核)**:
  - **实时握力表**: 当前抓握力(N) + 一条"安全区"提示(抓鸡蛋时显示"轻柔握持, 不会捏碎")。
  - **成品铭牌**: 手的规格(5 指腱驱动 / sEMG 控制 / 内置力反馈), 像产品说明卡。
  - **小任务卡(可选, 非强制)**: "把鸡蛋放进碗里""端起水杯放到杯垫""举起钢块证明力气" ——
    完成给正反馈(不是过关门控, 是成就点缀)。
- **顶部 HUD**: 项目名 + 当前手势 + 当前握力 + 一句"你正在使用你亲手做的仿生手"。

## 3. 用户能做的事(成品能力清单 → 交互)

1. **用肌肉抓东西**: 按住握拳 → 手闭合 → 抓起手正下方的物体 → 松开 → 放下。即时、直接。
2. **切手势抓不同东西**: 握拳抓杯子/钢块; 捏取(拇指+食指)夹起笔/小方块; 三指握中等物体。
   手势决定哪些手指参与、闭合形态 —— 抓不对的手势会抓不稳(物体滑落, 轻量反馈, 提示换手势)。
3. **体验内置力控(隐形礼物)**: 抓鸡蛋时, 无论用户发多大力, 成品**自动限力**在安全区 →
   鸡蛋完好; 抓钢块时自动给足力 → 稳稳拿起。用户感到"这手好聪明", 一个小气泡点破
   "内置力反馈: 抓易碎物自动轻柔"。(对比: 如果没有这层智能会捏碎 —— 但成品有, 所以不会。)
4. **搬运与放置**: 抓起后移动手, 把物体搬到目标区放下。完成"鸡蛋→碗""杯子→杯垫"等。
5. **自由探索/炫技**: 随便抓、随便搬、试所有物体和手势。可反复玩。
6. (可选)**双传感器/多手势彩蛋**: 呼应 blueprint stretch goal —— 一个"高级模式"开关,
   解锁更细腻的手势, 让用户看到"这只手还能升级到更强"。

## 4. 物理与真算(服务手感, 不做考核)

- **手运动学**: 腱驱动手指弯曲用正向运动学真算(与旧版同款连杆累加), 不同手势对应不同手指
  参与和目标弯曲。手闭合到接触物体 → 抓取建立。
- **抓取力与稳定**: 接触后握力按接触刚度真算; 内置力控(成品自带)自动把力稳定在物体安全区
  [hold, crush] 内 —— 用户发力只决定"要不要抓/抓的意图强度", 具体力由成品的闭环托管。
  力 < hold → 抓不稳滑落(给"没夹稳, 试试握紧点/换手势"提示); 力在窗内 → 稳稳抓住;
  力永远不会到 crush(成品限力保护, 这正是成品价值)。
- **物体差异**: 每物体有重量、大小、安全力窗、适配手势。抓法/发力不合适 → 滑落(可重试),
  合适 → 抓起。钢块重需要足够握力才不滑; 鸡蛋娇贵靠成品限力保护; 笔细需捏取手势。
- 全部纯函数, 逐帧真算, 与旧版共享 fingerKinematics / contactForce 思路, 但**力控是成品内置的
  自动闭环**(不暴露 PID 调参给用户 —— 那是制作过程的事, 成品里已经调好)。

## 5. 视觉规格(遵循既定契约, 沿用 ROB-10 色板)

- 视口固定 1280×800(meta width=1280), body 100vw/100vh overflow hidden, 外层等比缩放。
- 深空共享画布(--bg-0: oklch(0.14 0.035 265) 系列) + ROB-10 生机义体色板:
  MYO 肌红(发力/意图) / SINEW 腱橙(手结构) / NEURAL 神经蓝(界面) / FORCE 力绿(握力/安全) / DAWN 高光。
- 但注意基调更"产品感、明亮、友好" —— 这是展示成品的现场, 不是实验室。桌面/物体可用更饱和活泼的
  功能色(鸡蛋暖白、钢块冷灰、杯子蓝),让"桌上一排东西"看起来诱人可玩。
- 数字/握力/规格用 JetBrains Mono, 正文 Inter/PingFang SC。
- 硬边框 1.5px + 3px 硬阴影按钮; 禁圆角软阴影玻璃拟态; 禁 emoji; 图形全 SVG/canvas 手绘。
- canvas 直接父容器 display:flex + flex-direction:column。顶层禁用 history/location/name/status 同名变量。
- 手要画得**精致可信**(五指关节、腱线、残肢接口/腕部舵机盘), 物体和抓取有真实手感。
- 文字排布逐对检查不重叠。

## 6. 技术规格

- 单文件 HTML, 零外部依赖, 内联全部 CSS/JS。代码量不限。
- 实时 rAF 循环驱动: 用户发力动态 → 手势对应的手指目标 → 手闭合运动学 → 接触/力/稳定判定 →
  抓取/搬运/放置状态 → 物体跟随。可暂停无所谓, 是使用现场不是仿真考核。
- 状态机(建议): `S = { grip(手势), effort(发力0-1), handX(手位置), handClosure, held(抓着的物体或null),
  objects[{id,x,type,held,placed}], force, task(可选当前任务), lang, advancedMode }`。
- 纯函数: `fingerTargets(grip, effort)` 手势+发力→各指目标弯曲; `fingerKinematics` 弯曲→指尖位置;
  `contactForce(closure, obj)` 接触力; `builtinForceControl(intent, obj)` **成品内置**自动限力→实际握力;
  `graspStable(force, obj)` 是否夹稳。
- i18n: `T = {zh, en}`, langBtn 即时切换。暴露 window.S 及关键函数便于调试/自动化测试。
- 手/桌面/物体/握力表均 2D canvas 手绘, devicePixelRatio 适配。

## 7. 验收清单

- [ ] 打开即是一只做好的手 + 一桌物体, 无任何"制作/章节/标定"步骤; 3 秒内可握拳抓起一个物体。
- [ ] 用肌肉(握拳/滑杆)控制手开合抓取即时生效; 抓起→移动→放下顺畅。
- [ ] 多手势可切换, 不同物体需/适配不同手势(捏取夹笔、握拳抓杯), 手势不当会滑落可重试。
- [ ] 内置力控体验成立: 抓鸡蛋无论多用力都不捏碎(成品限力), 抓钢块给足力稳稳拿起; 有小气泡点破
      "内置力反馈"这一成品价值。
- [ ] 至少一个可完成的小任务(如鸡蛋放进碗), 完成有正反馈(非门控)。
- [ ] 运动学/接触力/稳定判定真算(抽查与手算一致); 手的动作和抓取有真实手感。
- [ ] 中英切换无漏翻、无布局溢出; 1280×800 无滚动条; 无 console error。
- [ ] 整体基调是"体验一件属于你的、能用的成品", 传达价值与成就感, 不是重走制作流程。
