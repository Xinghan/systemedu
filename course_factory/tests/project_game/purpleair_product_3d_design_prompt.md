# 项目成品 3D 交互展示设计 Prompt — purpleair-airquality-node

> 用途: 项目级"成品 3D"品类 —— 每个项目一个 HTML, 用 Three.js 直接呈现**做完项目后得到的那台成品**,
> 可旋转、可拆看、真的在工作。回答学生一个问题: "我做完这个项目, 能得到什么东西?"
>
> 与前一版"项目模拟游戏"(purpleair_design_prompt.md)的本质区别:
> **不模拟做的过程**(没有接线/选址/跑 30 天), 直接给成品。功能收敛到"看懂它 + 玩它"。

## 0. 成品是什么 (来自 blueprint Final Deliverable)

一台装在户外墙上的**空气质量监测节点**: 带通风挡板的防水外壳, 内含 PMS5003 激光颗粒传感器、
BME280 温湿度计、Pi Zero 2 W; 它每秒测 PM2.5, 做 EPA 湿度校正, 算 NowCast AQI,
实时推送到 PurpleAir / OpenAQ 公开地图, 配一个公开仪表盘。

## 1. 核心体验 (保持简单, 五个动作)

1. **拖拽旋转 / 滚轮缩放** — 360° 端详这台设备(默认自动缓转几秒吸引注意)。
2. **打开外壳** — 一个按钮(或点击壳体), 前盖铰链打开 + 三大件轻微 exploded 抬升,
   看到里面是什么; 再点还原。这是"拆看成品", 不是组装。
3. **点击核心零件下钻** — 4 个可点击件, 弹出 L1 子场景 modal (沿用 3d_template 下钻骨架):
   PMS5003(激光 + 风扇 + 颗粒计数动画) / BME280(为什么湿度是校正的钥匙) /
   Pi Zero(每秒: 读帧 → 校正 → NowCast → 推送) / 通风挡板(挡雨不挡气流)。
   每个 L1 配 3-4 句"它在成品里干什么"的文案, 不展开 L2。
4. **切换空气场景** — 侧栏 4 个按钮: 晴天 / 湿雾天 / 野火烟雾 / 大风。
   3D 空间中的漂浮颗粒密度、颜色、流速立刻变化, 设备读数跟着响应。
   这是成品的灵魂: **它感知的是它周围的世界**。
5. **看实时仪表盘** — 右侧 HUD 卡: 原始 PM2.5 → EPA 校正值 → NowCast AQI(EPA 六色) +
   24h 迷你曲线 + "PUBLIC · LIVE on PurpleAir" 徽标 + 迷你社区地图(你的点按 AQI 色脉冲)。
   这是成品的终点: 数据是公开的、有公共价值的。

## 2. 设备形态 (L0 场景)

- 一小段砖墙/立柱托着设备(交代"装在户外视线高度"), 米黄纸面地面 + 棕色细网格。
- 外壳: 竖式防水盒, 正面下方两排通风百叶(louvers), 底部进气口, 侧面出线孔 + 一根下垂电缆,
  顶部小檐挡雨。壳体半透明度适中, 隐约可见内部。
- 状态 LED: 壳侧一颗, 颜色 = 当前 AQI 类别色(绿/黄/橙/红/紫/褐), 每 2s 呼吸闪一下(心跳)。
- 内部三大件(开盖后可见+可点): PMS5003(金属方盒, 风扇窗), BME280(紫色小板), Pi Zero(绿色长板)。
- 空气颗粒: 场景中 100-300 个漂浮小点(Points), 从进气口方向被缓缓吸入设备;
  场景切换时密度/色调/速度过渡: 晴天(稀, 暖灰) / 湿雾(中密, 泛白泛蓝, 大颗) /
  烟雾(密, 棕橙, 天光转暖褐) / 大风(极稀, 快速横飘)。

## 3. 读数引擎 (真公式, 但收敛)

- 场景参数: clean{true 12, RH 45} / fog{true 14, RH 88} / smoke{true 160, RH 30} / wind{true 4, RH 40},
  每 tick 加小噪声; 场景切换时 true/RH 用 ~8s 平滑过渡(让 NowCast 的滞后可见)。
- raw = (true − 5.75 + 0.0862·RH)/0.524 (Barkjohn 逆变换, 湿雾天 raw 显著虚高 — 面板上原始 vs 校正的差距就是教育点)
- corrected = 0.524·raw − 0.0862·RH + 5.75
- NowCast: 1 真实秒 ≈ 1 模拟小时, 环形 24 长度历史, EPA 权重公式取最近 12 点。
- AQI: EPA 2024 PM2.5 分段线性插值, 六色与 LED/地图点/面板联动。

## 4. 视觉与技术契约 (与 3d_template/object_template.html 一致)

- 米黄手册插画风(flipbook): --paper #f5f3ee 基底, 全部 mesh 浅色填充(fill-1/2/3/pcb/glass...),
  MeshToonMaterial + 3 档 gradientMap + EdgesGeometry 30° 黑描边(#2a2620), 唯一深色是描边与文字。
- 灯光五件套: Ambient 0xfff5e0 + 暖白主光(带影) + 冷蓝副光 + 暖 rim + HemisphereLight。
- accent 用 earth sepia #c97a4e; AQI 六色为功能色特例(与项目游戏版同一组 oklch→hex 近似值)。
- 布局: 240px 左 sidebar(lang 按钮/使用方法/零件列表/场景按钮/功能链速览) + 主 canvas 占满,
  左上标题 overlay, 右上实时仪表盘 HUD, 底部 hint bar; 下钻 modal 带面包屑 + Back/Close。
- three@0.160 importmap CDN + OrbitControls; 响应式 resize; i18n cn/en 全量; 无 emoji。
- 单文件 HTML; 颗粒/风扇/LED 动画全在 rAF 循环, 下钻 modal 打开时主循环继续(设备不休息)。
