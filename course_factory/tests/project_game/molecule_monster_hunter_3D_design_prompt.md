# Molecule Monster Hunter 成品使用 3D 版 — 设计 Prompt

> 项目: molecule-monster-hunter (AI Drug Discovery + Computational Chemistry)
> 范式: **项目级产出物模拟 — 成品使用体验**(不是制作过程), 全屏 3D 场景, 成品是主角。
> 前作参照(均已验收): emg_prosthetic_hand_3D / mars_analog_rover_3D / satellite_archaeology_3D。
> 本试点定位: **纯软件类** —— 验证范式在"无实体产出物、全在电脑上跑的数据科学管线"上成立。

## 0. 范式声明(硬约束)

- 玩家打开页面时, **模型已训练好、Workbench 已部署好**: 一台 AI 药物发现工作台在线,
  ADMET 预测模型已在公开数据集(ESOL/Tox21)上训练完毕(HUD 模型卡摆着 ROC-AUC)。
  没有任何"学 SMILES / 装 RDKit / 训练模型 / 调参"步骤。
- 玩家做的事 = **使用这台自己造出来的分子筛选机器**: 拿一把"分子钥匙"去配"分子怪物"的口袋 →
  看工作台实时算出描述符/Lipinski/预测属性 → 把候选池推过漏斗筛到 Top 10 →
  给被拒分子写风险解释 → 出 go/no-go 报告。全程"分子猎手"的判读+决断。
- 全屏 3D(Three.js r149 UMD 内联, 自写轨道相机)。分子球棍模型 + 靶点蛋白怪物都是 3D 实体。
  禁 2D 看板式界面; HUD 只做薄薄一层遥测+指令条。
- **诚实框架是硬约束(贯穿全程, 呼应 cover 的科学诚信基调)**: AI 不"发明治愈", 只**缩小搜索空间**。
  必报验证指标; scaffold split 防数据泄漏; 每个被拒分子给理由; 绝不让玩家宣称"找到了解药"。

## 1. 成品定义(玩家拥有的东西)

学生 44 周后的最终产出物, 在游戏里表现为一套已部署的**分子怪物猎手工作台 "HUNTER-Rx"**:

1. **靶点"分子怪物"**(cover 主角): 一团 3D 蛋白 blob(半透明/金属表面), 表面有一个凹陷
   **结合口袋(pocket)**, 口袋里预置 3-4 个**药效团特征点**(pharmacophore): H 键供体位(蓝球)、
   H 键受体位(红球)、疏水位(黄球)、芳香位(紫环)。这就是 cover 里怪物胸口的"钥匙孔"。
2. **分子钥匙候选池**: 一排/一片可选的候选分子(~12 个精选 + 一个 ~2000 的池用于漏斗数字)。
   每个分子有 SMILES; 选中即在中央渲染成 3D 球棍模型。
3. **训练好的 ADMET 模型**: 溶解度回归(ESOL) + 毒性分类(Tox21 代理) + 活性预测(对接分)。
   HUD 模型卡: `Tox ROC-AUC 0.83 · ESOL RMSE 0.72 · scaffold-split`。
4. **候选漏斗 + 风险解释 + go/no-go 报告生成器**。

## 2. 3D 场景与美术

### 2.1 靶点蛋白怪物(主角之一)
- 一团有机 blob: IcosahedronGeometry 高细分 + 顶点噪声起伏(cover 的"疙瘩肉球"质感),
  MeshPhysicalMaterial 半透明(transmission/clearcoat)偏粉橙肉色, 表面点缀更小的球簇(残基感)。
- 正面挖一个**口袋**: 一个朝向相机的凹陷(可用一个内凹半球 + 深色内壁表现)。口袋中央悬浮
  药效团特征点(发光小球/环, 各自颜色), 特征点之间有细虚线连成"药效团骨架"。
- 怪物**缓慢起伏呼吸**(整体 scale 微脉动)。默认待命时口袋朝向相机。
- 不做卡通脸(保持科学工具调性), 但整体轮廓致敬 cover 的软萌 blob。

### 2.2 分子球棍模型(主角之二)
- 当前选中分子在场景中央偏左悬浮, 可整体缓慢自转。**CPK 配色**原子球 + 圆柱键:
  C 深灰(#3a3a3a)、H 白、N 蓝(#3060d0)、O 红(#d03020)、S 黄(#d0b020)、
  F/Cl 绿(#40b040)、Br 棕红、P 橙。原子半径按元素(范德华简化), 键=细圆柱(双键=两根)。
- 芳香环用环内浅色盘/虚线圈表意。整体 MeshStandardMaterial + 高光, PMREM 环境给通透反射。
- 分子由**真算引擎从 SMILES 生成的 2D 图**做一次力导向/环感知布局 → 抬升成 3D(给每个原子
  一个确定性 z 抖动 + 环共面), 不追求真实构象, 追求"一眼是这个分子且好看"。

### 2.3 对接演示(cover 的"插钥匙"时刻)
- 玩家点"对接(Dock)": 当前分子从中央**平滑飞入怪物口袋**, 尝试与药效团特征点对齐。
  分子上满足某特征的官能团**高亮绿色连线**到对应特征点; 不满足的特征点**闪红**。
  对接完成给**对接分(0-100)** + 特征命中数(如 "3/4 药效团匹配")。这是活性预测的可视化。
- 契合度高 → 分子"咔哒"卡进口袋 + 绿色脉冲; 契合差 → 分子被"弹出"口袋 + 红色提示。

### 2.4 光照与基调
- 暗色"计算化学空间"背景(深蓝黑 + 稀疏分子点云/网格) + 主平行光(柔阴影) + 补光。
  分子与蛋白冷暖对比。整体"未来制药 R&D 工作台"科技感, 深色 + Claude coral 强调色。

## 3. 交互与任务链

### 3.1 核心交互(使用工作台)
1. **选分子 / 输入 SMILES**: 候选池点选, 或输入框敲一个 SMILES(如 `CC(=O)Oc1ccccc1C(=O)O` 阿司匹林)
   → 引擎解析 → 中央渲染 3D 球棍 → 右侧描述符面板实时刷新。解析失败给友好报错。
2. **描述符实时算(RDKit 风格)**: MW / LogP / HBD / HBA / TPSA / 环数 / 可旋转键 / 芳香环。
   每个都真算(见 §4), 数字旁给一句人话("LogP 高 = 太亲脂, 难溶")。
3. **Lipinski 五规则灯**: MW≤500 / LogP≤5 / HBD≤5 / HBA≤10 四条, 每条亮绿/红, 违反计数。
   全过=可成药性 OK; 违反≥2=预警。
4. **模型预测卡**: 溶解度(logS, ESOL)/ 毒性概率 / 活性概率(=对接分归一)。带置信标注。
5. **对接(Dock)**: §2.3, 把当前分子怼进怪物口袋看药效团匹配。
6. **跑漏斗(Screen the pool)**: 把 ~2000 候选池推过多层漏斗:
   Lipinski 过滤 → 毒性阈值过滤 → 溶解度过滤 → 活性排序 → **Top 10**。
   每层 3D/HUD 显示"剩余数"逐层坍缩(2000 → ... → 10), 漏斗动画。
7. **风险解释**: 点任一被拒分子 → 给结构化理由("含硝基 → 毒性预警"/"MW 620 超 Lipinski"/
   "logP 6.2 太亲脂"/"活性 0.21 太低")。这是"每个拒绝都要给理由"的诚实规范。
8. **出报告**: Top 10 ≥1 时可用。R&D 候选报告 overlay: Top 10 排名(结构缩略+分数+推荐)、
   模型验证指标(ROC-AUC/RMSE/scaffold split)、Lipinski 通过率、候选多样性、5 条拒绝理由。
   **诚实闸门**: 报告里有诱饵按钮"宣布找到治愈 / 上市" → 触发**科学诚信警示演出**(红闪 +
   "AI 只缩小搜索空间, 这些是待湿实验验证的候选, 不是药"), 必须选"移交湿实验室验证"才能完成。

### 3.2 任务链(R&D 里程碑式仪式, 非门控)
1. 选/输入一个分子, 看它的 3D 结构 + 描述符。
2. 对接一次: 让某分子药效团命中 ≥3/4。
3. 跑一次漏斗, 得到 Top 10。
4. 给 ≥1 个被拒分子写风险解释。
5. 出 R&D 报告(诚实收尾: "缩小搜索空间" + Insilico/Atomwise 致敬语)。

### 3.3 隐形礼物 bubble(点破产品替玩家做了什么)
- 第一次算描述符: "工作台刚把这个分子拆成了 8 个可计算特征 —— 你 44 周学的 RDKit, 一瞬间完成。"
- 第一次跑漏斗: "它刚替你筛掉了 1990 个分子 —— 人类化学家只需在剩下的 10 个里做实验。"
- 出报告时: "记住诚实规则: AI 缩小了搜索空间, 没有发明治愈。真相在湿实验室里。"

## 4. 真算引擎(纯函数, node 可单测)

### 4.1 SMILES → 分子图
- `parseSmiles(s)`: 支持有机子集: 原子 `C N O S P F Cl Br I` + 芳香小写 `c n o s`,
  单/双/三键 `- = #`, 支链 `( )`, 环闭合数字 `1..9`(及 `%nn`), 常见括号原子 `[nH]` `[O-]` 等
  (至少容错跳过电荷/同位素而不崩)。产出 `{atoms:[{el,arom,charge}], bonds:[{a,b,order,arom}]}`。
  解析失败返回 null(UI 友好报错)。
- `implicitH(atom, graph)`: 按价(C4 N3 O2 S2 P3 F/Cl/Br/I 1, 芳香 C 补到 4)减去邻键级和,
  得隐式 H 数; 芳香原子按 aromatic model。
- `layout2D(graph)`: 环检测(找环) + 力导向/环规则布局给每原子 (x,y); 供 3D 抬升。

### 4.2 描述符(RDKit 对齐, 真公式)
- `molWeight`: Σ 原子质量 + 隐式 H 质量。元素质量表内置。
- `logP`: 简化 Crippen 原子贡献法(按原子类型: sp3 C / 芳香 C / N / O / 卤 / 极性 H 各查贡献求和)。
- `hbd`: N-H、O-H 的 H 数(供体); `hba`: N、O 原子数(受体, 排除某些情况)。
- `tpsa`: Ertl 拓扑极性表面积, 按 N/O(及其 H/芳香/电荷状态)片段贡献查表求和。
- `ringCount` / `aromaticRingCount`: 环感知计数。
- `rotatableBonds`: 非环单键且两端非端点。
- `aromaticFraction`: 芳香原子 / 重原子。
- 全部对齐已知分子(阿司匹林/咖啡因/布洛芬)手算值 ±合理误差, 供单测断言。

### 4.3 模型预测(确定性模拟"训练好的模型")
- `esolLogS(desc)`: **真实 Delaney ESOL 经验式**
  `logS = 0.16 − 0.63·LogP − 0.0062·MW + 0.066·RotB − 0.74·AromFrac`。
- `toxProb(graph,desc)`: 毒性代理 = 按毒性警示基团(硝基/卤代芳香/Michael 受体/环氧/偶氮)
  确定性加分 + 亲脂惩罚 → sigmoid 到 0-1。
- `dockScore(graph, pocket)`: 分子对靶点药效团的匹配度 —— 检测分子是否携带各特征点要求的官能团
  (H 键供体/受体/疏水/芳香), 命中率 + 几何可行性 → 0-100。**活性概率 = dockScore/100**。
- `lipinski(desc)`: 四规则布尔 + 违反数。
- 预置**模型验证卡**(静态但真实量级): Tox ROC-AUC 0.83、ESOL RMSE 0.72、
  scaffold-split vs random-split 差距(演示泄漏: random 虚高 0.9+)。

### 4.4 候选池 + 漏斗
- `genPool(seed, n)`: 确定性生成 ~2000 候选(从若干骨架 + 取代基组合枚举, 各带 SMILES/描述符)。
  预埋少量"真命中"(高 dockScore + 过 Lipinski + 低毒) 和大量该被筛掉的。
- `runFunnel(pool, target)`: 逐层过滤返回每层计数 + 最终 Top 10(按 dockScore 排序, 兼顾多样性)。
- `rejectReason(mol)`: 结构化拒绝理由(命中的第一/主要否决项)。
- `fpTanimoto(a,b)`: Morgan 指纹 Tanimoto 相似度(用于 Top 10 多样性去冗余)。

## 5. UI 硬规范(继承前作验收)

- **所有说明文字深底亮字**: 深色半透明面板 + 亮字, 绝不让文字裸糊在场景上。
  顶部任务讲解条、左任务卡、右描述符/预测遥测卡、底部指令条、SMILES 输入框。
- 遥测卡(右): 分子名/式量/LogP/HBD/HBA/TPSA/环数 + Lipinski 四灯 + 预测卡(logS/毒性/活性) +
  模型卡(ROC-AUC/RMSE/scaffold-split 铭牌, 强化"这是你训练的模型")。
- 数字/SMILES/指标 JetBrains Mono; 正文 Inter/PingFang SC。禁 emoji; 图形全 SVG/canvas/3D。
- 中英双语即时切换(EN 键), 全文案走 T 表。
- 1280×800 无滚动条; devicePixelRatio 适配。

## 6. 技术规格

- 单文件 HTML, 内联 three r149 UMD + 少量 CC0 法线纹理 base64, 零外部依赖。
- 状态机: `S = { ready, mol(当前分子图+描述符), pool, funnel(各层计数), top10[],
  docked(对接态), rejected(被点开的), tasks[], lang, camFollow, phase }`。
- rAF 主循环 + `simStep(dt)` 帧率无关(headless 慢帧安全); 关键对象与纯函数挂 window
  便于 Playwright 驱动与断言(parseSmiles/descriptors/esolLogS/dockScore/runFunnel/lipinski)。
- 分子球棍/蛋白怪物/口袋药效团/对接连线均 3D; 结构缩略图 canvas 手绘。
