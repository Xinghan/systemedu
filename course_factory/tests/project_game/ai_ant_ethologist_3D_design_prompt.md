# AI Ant Ethologist 成品使用 3D 版 — 设计 Prompt

> 项目: ai-ant-ethologist (RFID Tracking + LLM Field Notes)
> 范式: 项目级产出物模拟 — **成品使用体验**, 全屏 3D, 成品是主角。skill: project_product_game。
> 前作参照(均已验收): emg / mars / satellite / molecule / eeg_minecraft_bci 3D。

## 0. 范式声明(硬约束)

- 玩家打开时, **观测站已建好、蚁群已标记、LLM PI agent 已部署**: 50 只蚂蚁贴好 RFID, 巢口
  读卡门在线, LLM "首席研究员" 待命读数据写田野笔记。没有任何"抓蚂蚁/贴标签/写脚本/调 prompt"步骤。
- 玩家做的事 = **运行这套观测站 + 指挥 LLM 研究员**: 看 RFID 标记的蚂蚁进出巢口触发读卡事件流 →
  做一次扰动实验(关一个门看蚂蚁改道) → 让 LLM PI agent 读当天数据写田野笔记(谁是"明星"、谁"偷懒"、
  殖民地怎么从扰动中恢复)。全程"当一个用 AI 当研究助手的蚁群行为学家"。
- 全屏 3D (Three.js r149 内联, 自写轨道相机)。剖面蚁巢 + RFID 读卡门 + 蚂蚁 + LLM 田野笔记本都是实体。
  ❌ 不做 2D 看板。HUD 只是薄薄一层遥测 + 事件流。
- **诚实框架 (呼应 blueprint "ants don't perform on demand" + 伪重复警告)**: 观测数据是真实涌现的,
  蚂蚁不听你指挥 (你只能改环境, 不能命令某只蚂蚁); LLM 会 confabulate, 需要人核对; 样本量小时
  结论不可靠 (伪重复)。这是真行为学, 不是魔法。

## 1. 成品定义(玩家拥有的东西)

学生 24 周后的最终产出物, 在游戏里表现为一套已部署的 **蚁群观测站 "MYRMEX-1"**:

1. **RFID 标记的蚁群** (~24-40 只, 性能考虑不做满 50): 每只带唯一 tag_id + 隐藏的性格参数
   (勤奋度/探索性/领导力)。在剖面蚁巢里真实觅食/巡逻/护卵。
2. **巢口 RFID 读卡门** (cover 的门禁): 蚂蚁经过门触发一条读卡记录 (tag_id, gate_id, timestamp,
   direction in/out)。事件流实时滚动。多个门 (主巢口 + 觅食路)。
3. **LLM PI agent "首席研究员"**: 读当天读卡数据, 输出田野笔记 (3 条观察 + 1 条假设 + 建议)。
   HUD agent 卡: `Claude PI · 日报模式 · 读 RFID → 田野笔记`。
4. **分析层**: 活跃度排行 (谁跑最多 = 明星, 谁最少 = 偷懒者)、社交网络 (共现)、
   扰动恢复曲线、Sol 式日报。

## 2. 3D 场景与美术

### 2.1 剖面蚁巢 (主角之一, cover 的核心意象)
- **地下剖面视图**: 一块土壤剖面 (棕色分层纹理), 里面挖出多个**腔室** (圆润凹室) 用**隧道**连通,
  像 cover 那样有机分布。腔室分工: 卵室(白色卵堆)、储粮室、育幼室、主厅。
- 土壤用 CC0 泥土/沙纹理或程序化 canvas 分层棕色 + 颗粒噪声。腔室内壁略亮 (挖空感)。
- 顶部是地表线, 地表上有落叶/小枝 (cover 的枝叶)。

### 2.2 蚂蚁 (主角之二)
- 简化但可辨的蚂蚁: 三节体 (头/胸/腹, 椭球) + 6 腿 (细圆柱) + 触角。RFID 标记 = 背上一个
  **微小彩色圆点/方块** (每只颜色/编号不同, 呼应"贴标签")。选中的蚂蚁高亮 + 显示 tag_id。
- 蚂蚁沿隧道/腔室**真实路径行走** (引擎驱动, 腿摆动动画), 觅食的会走到地表再回来。
- 数量 ~24-40 (InstancedMesh 或轻量 group), 性能优先。

### 2.3 RFID 读卡门 (cover 的门禁)
- 巢口/隧道关键位置的**读卡门框** (两根柱 + 顶梁 + 天线线圈, 金属质感)。蚂蚁穿过时门框
  **闪一下** + 发一条读卡记录到事件流。可**关闭**某个门 (扰动实验) → 门变红 + 蚂蚁被迫改道。

### 2.4 LLM 田野笔记本 (cover 的笔记本, overlay)
- 点"生成田野笔记" → 一本**田野笔记 overlay** 拉出: LLM PI agent 的当天记录 (观察/假设/建议),
  配活跃度排行小表 + 社交网络缩略图 + 恢复曲线。手写笔记本风 (深底亮字, 不是纸白 —— 遵循 UI 规范)。

### 2.5 光照与基调
- 暖土色地下 + 地表冷光 (剖面感)。主平行光从地表打下 + 补光照亮腔室。PMREM 给读卡门金属反射。
  整体"一个活着的、被科学观测着的地下城市"。

## 3. 交互与任务链

### 3.1 核心交互(运行观测站)
1. **观察 RFID 事件流**: 右侧滚动读卡记录 (tag_id / gate / in-out / 时间), 蚂蚁过门实时追加。
   点一条记录 or 点一只蚂蚁 → 高亮该蚂蚁 + 显示它的 tag_id / 今日过门次数 / 角色。
2. **时间控制**: 加速/暂停 一"天"的观测 (sim 时间压缩), 看活跃度累积。
3. **扰动实验**: 点某个读卡门"关闭 48h" → 门变红 → 蚂蚁被迫绕行其他门 → 觅食路线重组。
   观察哪些蚂蚁最快改道 (领导者)。可重开门看恢复。
4. **活跃度/leader 分析**: 面板实时排行 (明星蚂蚁 / 偷懒者), 扰动后"谁先改道"高亮领导者。
5. **LLM 生成田野笔记**: 点"生成田野笔记" → LLM PI agent 读当天数据 → 田野笔记 overlay。
   笔记里有一处**诚实提示**: 若观测天数/样本太少, 笔记标注"样本量小, 结论待验证 (伪重复风险)";
   笔记末尾附"LLM 生成, 需人工核对"—— 点破 confabulation。

### 3.2 任务链(里程碑式仪式, 非门控)
1. 观察一天, 让读卡事件累积, 认出活跃度最高的"明星蚂蚁"。
2. 做一次扰动 (关一个门), 看蚁群改道, 认出最快改道的"领导者"。
3. 让门恢复, 观察恢复 (改道流量回落)。
4. 生成 LLM 田野笔记 → 6 个月纵向数据集 + LLM logbook 仪式 (Zenodo DOI 致敬 Kronauer 实验室)。

### 3.3 隐形礼物 bubble
- 第一次认出明星蚂蚁: "观测站刚替你盯了 <b>{n} 条过门记录</b> —— 你 24 周搭的 RFID 网, 24/7 不眨眼。"
- 第一次扰动改道: "它让你<b>只改环境、不改蚂蚁</b> —— 这是观察实验与干预实验的分界。"
- 生成笔记: "LLM 写了田野笔记, 但它会编造 —— <b>真科学要人来核对</b>, 样本太小的结论不算数。"

## 4. 真算引擎(纯函数, node 可单测)

- `genColony(seed, n)`: 生成 n 只蚂蚁, 各带 tag_id + 隐藏性格 {diligence, exploration, leadership}
  (确定性)。巢结构 (腔室坐标 + 隧道图 + 门列表) 也确定性生成。
- `antStep(ant, t, nest, closedGates)`: 一只蚂蚁的行为状态机 (在巢/觅食往返/巡逻), 沿隧道图寻路;
  勤奋度高 → 觅食频率高; 门关了 → 走替代路径 (领导力高 → 更快找到替代路径)。返回位置 + 是否过门。
- `gateEvent(ant, gate, dir, t)`: 生成一条读卡记录 {tag_id, gate_id, dir, t}。
- `activityRank(events)`: 按过门次数排行 → 明星 (最多) / 偷懒者 (最少)。真算计数。
- `cooccurrence(events, windowSec)`: 时间窗内共现 → 社交网络边权 (谁常和谁一起过门)。
- `perturbation(closedGate)`: 关门后重路由; `reroutingSpeed(ant)`: 每只改道快慢 (leadership 相关)。
- `recoveryCurve(events, tClose, tOpen)`: 扰动期 vs 恢复期 各门流量时间序列 (改道→回落)。
- `fieldNotes(dayStats, sampleDays)`: 模板化田野笔记生成 —— 用真实统计填充 (明星 tag / 改道最快 tag /
  流量变化%), 若 sampleDays < 阈值则加"伪重复风险"警示; 附"LLM 生成需核对"。**真实数据驱动的文本, 不是假话术。**
- `pseudoReplicationFlag(sampleDays, nAnts)`: 样本量判定。
- 抽样断言: 勤奋度高的蚂蚁过门次数统计上更多; 关门后对应门流量下降、替代门上升; 领导力高的改道更快;
  活跃度排行与勤奋度参数正相关; 田野笔记含真实明星 tag。

## 5. UI 硬规范(继承前作)

- **所有说明文字深底亮字**。顶部任务讲解条、左任务卡、右 RFID 事件流卡 + 活跃度排行、底部指令条
  (时间加速/暂停 + 关门/开门 + 生成田野笔记)。田野笔记 overlay 也深底亮字 (不是纸白)。
- 事件流/排行/曲线用 canvas 或 DOM 列表; 数字/tag_id/时间 JetBrains Mono; 正文 Inter/PingFang SC。
- agent 卡: `Claude PI · 日报模式 · RFID → 田野笔记` (静态铭牌, 强化"你部署的 LLM 研究员")。
- 中英双语即时切换; 禁 emoji; 1280×800 无滚动条; devicePixelRatio 适配。

## 6. 技术规格

- 单文件 HTML, 内联 three r149 + 少量 CC0 法线纹理 base64, 零依赖。
- 状态机: `S = { ready, colony(蚂蚁数组), nest(腔室+隧道+门), events[], day, simSpeed,
  closedGates[], selectedAnt, activity(排行), recovery, tasks[], lang, camFollow, phase }`。
- rAF + `simStep(dt)` 帧率无关; 蚂蚁行为在 simStep 里推进; 关键纯函数挂 window 供 e2e。
- 剖面蚁巢/蚂蚁/读卡门均 3D; 事件流/排行/社交网络/恢复曲线 canvas 或 DOM。
