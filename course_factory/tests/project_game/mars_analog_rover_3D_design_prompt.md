# 项目级"成品使用"3D 模拟游戏设计 Prompt — mars-analog-rover

> **范式(与 emg-prosthetic-hand 3D 成品版同一套, 严格沿用)**:
> - 模拟**做完之后的最终成品怎么用** —— 打开就是一台**已经做好的火星漫游车**, 用户直接**指挥它执行任务**,
>   感受"我学完这个项目就能造出一台能自主跑火星的车"。**无制作步骤、无章节门控、无调参返工。**
> - **全屏 3D 场景**(Three.js r149 UMD 内联 + 自写轨道相机), 火星车是主角, 可旋转/缩放/环绕观察。
> - **极度逼真, 大量细节**: 写实 PBR 材质(ambientCG CC0 扫描纹理: 金属/塑料/沙地/岩石 法线+粗糙度,
>   512px base64 内联) + PMREM 摄影棚/天空环境反射 + 火星地表大量岩石/沙纹/撞击坑细节。
> - 成品的"智能"是**隐形的礼物**: 自主导航/地形分类/避障这些"做项目时辛苦训练调好的", 现在**默默替用户工作**
>   (车自己看地形减速、绕开大石头), 用户只下高层指令(去哪采样), 一个小气泡点破"车内置了 HiRISE 训练的地形
>   分类器, 所以会自己避坑"。
> - UI: 深色 scrim 底板 + 亮字(**教训: 浅字浅底看不见**), 说明文字要够大够清晰; 中英双语 data-i18n;
>   1280×800 固定视口; 暴露 window.S; e2e(引擎单元 + Playwright 全流程 + 零 console error)。

## 0. 项目背景(来自 blueprint)

- 项目: 用 NASA HiRISE 影像训练的火星模拟漫游车, 10-12 岁, 28 周, 预算 $300, 难度 4/5。
- 真实原型: NASA JPL 的 Curiosity/Perseverance, 用 AEGIS(自主targeting) + ENav(自主导航);
  地形数据来自火星勘测轨道器 HiRISE 相机(PDS 公开); traverse log 格式 JPL 公布; 斯坦福 Mars Yard。
- 硬件: 4WD 铝底盘 + Pi4 + 广角摄像头 + 9轴 IMU + GPS + 电池。
- **最终成品**: 一台能**自主导航**的火星车 —— 看地形→用车载 CNN 分类 5 种火星地貌(TAR 横向沙脊/波纹/
  沙丘/平滑/粗糙)→据此调速转向(粗糙/沙丘减速, 平滑加速)→从 A 自主开到 B→回传 NASA 格式 traverse log。
- **成品的能力(游戏要让用户体验到的)**:
  1. **自主穿越**: 下达"从着陆点开到目标点", 车自己规划路径、看地形、避开危险, 一路开过去。
  2. **地形感知**: 车实时用摄像头看脚下地貌, 车载分类器识别 5 类地形, HUD 显示当前地形 + 置信度。
  3. **自适应速度**: 平滑地形加速、粗糙/沙丘自动减速(陷车保护) —— 用户不调, 成品已经会。
  4. **科学采样(AEGIS 彩蛋)**: 车能自主发现"科学上有趣的岩石"并停下拍照采样。
  5. **回传数据**: 到达后打出 traverse log(每个航点的 GPS/地形/朝向/能耗/危险) + Sol 日报。

## 1. 游戏定位与核心幻想

**名称**: 我的火星车 / My Mars Rover
**核心幻想**: 你是任务操控员。一台你亲手造的火星漫游车停在火星地表的着陆点。你给它一个目标 ——
"开到那片露头去采样" —— 然后看着它**自己**看地形、绕开大石头、在沙丘前减速、在平地上加速, 一路
自主开过去, 到达后传回一份 NASA 格式的任务日志。你在**指挥一台真正能自主跑火星的车**, 感受
"这就是我 28 周后能造出来的东西"。

**"成品使用"映射**: 打开即一台做好的火星车 + 一片火星地表(散布岩石/沙丘/撞击坑/科学露头)。
用户身份 = 任务操控员(下高层指令), 不是造车的工程师。交互对象 = 车 + 火星地形 + 任务目标。
没有章节/门控/诊断/返工。有的是"一片火星 + 一台自主车 + 可下达的任务"。

**设计原则**:
1. **零门槛即时爽**: 打开点一下目标点, 车就自主开过去了。先给甜头。
2. **成品智能是隐形礼物**: 自主导航 + 地形分类 + 避障默默替用户工作; 小气泡点破"这是你训练的
   HiRISE 分类器在帮你避坑"。用户只体验结果。
3. **物理真实但服务爽感**: 车的驱动/转向/爬坡/陷车、地形对速度的影响都真算(不做假动画), 目的是让
   "自主穿越"有真实的过程感和张力(会不会陷进沙丘?会不会撞石头?), 不是考核。
4. **给探索空间**: 多目标点 + 多地形 + 科学采样 + 自由驾驶, 反复玩。
5. **传达价值而非难度**: 结尾是 traverse log / Sol 报告仪式 —— "看, 你的车完成了一次真正的火星任务",
   落在成品的用途和意义上。

## 2. 结构: 单场景火星任务现场(非分章)

不分章节。一个连续的"火星任务控制现场"单页。布局(1280×800):
- **主舞台(全屏 3D)**: 一片火星地表(程序化生成 + 写实材质): 红沙地(沙纹法线贴图)、散布的岩石
  (大小不一, 大石头是障碍)、沙丘(减速区)、撞击坑、几处"科学露头"(采样目标, 发亮标记)。
  一台**做好的 4WD 火星车**停在着陆点。相机可环绕/缩放/跟随车。
- **左侧任务面板(深底亮字)**: 当前任务目标一句话 + 试试看清单(开到目标点 / 采一块样 / 穿越沙丘区 /
  完成一次完整 traverse) + 相机操作提示。
- **右侧遥测面板(深底亮字)**: 实时遥测 —— 当前地形分类 + 置信度、速度、朝向(罗盘)、电量、
  已行驶距离、成品规格铭牌(4WD / HiRISE 分类器 / IMU+GPS / 自主导航)。
- **底部控制坞(深底, 浅底按钮深字)**: 用户的高层指令 ——
  - **目标点**: 点击 3D 地表任意点 → 放下一个目标旗 → 车自主规划路径开过去。或点"科学露头"直接采样。
  - **模式切换**: 自主导航(默认) / 手动驾驶(WASD/方向键, 供想自己开的用户) / 采样模式。
  - **任务控制**: 开始任务 / 暂停 / 回传日志(到达后解锁)。
- **顶部 HUD(深 scrim)**: 项目名 + 任务名 + 当前 Sol + 一句"你正在指挥你造的火星车"。

## 3. 用户能做的事(成品能力清单 → 交互)

1. **派车去某处**: 点 3D 地表一个点 → 车自主规划 + 开过去(A* 或简单向量导航, 真算)。看着它绕石头、
   进沙丘减速、上平地加速。
2. **看它感知地形**: 车开动时, 遥测面板实时刷新"当前地形: 沙丘 87%"(车载分类器对脚下地形块打分, 真算);
   HUD 地形色带联动。
3. **体验自适应速度(隐形礼物)**: 平滑地形车自动加速; 进粗糙/沙丘车自动减速(否则会陷)。用户感到
   "车好聪明", 气泡点破"内置 HiRISE 地形分类器: 遇沙丘自动减速防陷车"。
4. **科学采样(AEGIS)**: 点一处科学露头 / 开"采样模式" → 车开到岩石旁, 停下, 机械臂/相机采样演出,
   传回一张"样本卡"。
5. **完成完整任务 + 回传日志**: 从着陆点自主穿越到目标点 → 打出 **NASA 格式 traverse log**(每航点:
   GPS 坐标、地形类、朝向、能耗、危险) + **Sol 日报**(今日行驶距离、见到的地形、能耗、异常)。
6. **自由驾驶/探索**: 手动模式自己开、随便逛、反复采样。可换新的目标/新地形种子。
7. (可选)**多 Sol 任务**呼应 stretch goal: 累积多天航迹, 生成 Sol 报告集。

## 4. 物理与真算(服务过程感, 不做考核)

- **地形生成**: 程序化 heightmap(fbm 噪声)→ 火星地表起伏; 叠加地形类型图(平滑/粗糙/沙丘/波纹/TAR,
  由另一层噪声决定), 每块地形有(速度系数, 陷车风险, 分类特征)。散布岩石(障碍, 大石头挡路)、
  撞击坑、科学露头。
- **车辆运动**: 4WD 差速驱动真算 —— 目标航向 vs 当前航向 → 转向; 地形速度系数 → 实际速度;
  爬坡受坡度影响; 电量随距离/爬坡消耗。IMU 朝向(罗盘)、GPS(虚构但格式真实坐标)真算更新。
- **自主导航(成品内置)**: 从当前位到目标点规划路径, 避开大石头(障碍绕行), 遇高陷车风险地形自动
  降速。用户只给目标, 导航是成品替他做的。
- **地形分类(成品内置)**: 车脚下地形块 → 分类器打 5 类置信度(真算, 用地形特征 + 一点噪声模拟识别),
  HUD 显示 top1 + 置信度; 偶尔误分类(呼应真实 domain shift, 但不惩罚)。
- **陷车/危险**: 高风险地形若强行高速 → 陷车(打滑, 停住) —— 但成品自动降速通常避免; 手动模式才可能陷。
- 全部纯函数逐帧真算, rAF 循环驱动。

## 5. 视觉规格(沿用 emg 3D 写实管线)

- 视口固定 1280×800; body overflow hidden; 外层等比缩放。
- Three.js r149 UMD 内联; 自写轨道相机(拖拽旋转 + 滚轮缩放 + 双击复位 + 可选跟随车)。
- **写实 PBR**: 火星红沙(sand 法线+粗糙, 暖橙红 albedo)、岩石(rock 法线, 灰褐)、车体(金属/塑料/
  橡胶轮胎 CC0 扫描贴图)、太阳能板(蓝黑反光)。PMREM 环境: 火星天空(橙粉渐变) + 太阳, 给金属真反射。
- 火星天空盒: 橙粉色渐变(火星大气), 远处地平线/山脊剪影, 淡尘霾雾。
- 布光: 强暖白主光(火星阳光, 略偏冷因为大气薄) + 天空补光 + 地面反弹。硬阴影(火星空气稀薄影子锐)。
- 车要画得精致可信: 4WD 独立摇臂悬挂/6轮(仿真实火星车摇臂转向架 rocker-bogie)、桅杆相机(Mastcam)、
  太阳能板、天线、车身仪器盒、线缆细节。**摇臂悬挂随地形起伏(真实火星车招牌)**。
- **UI 教训(硬要求)**: 顶部说明文字必须有深色 scrim 底板 + 亮字, 字号够大(说明 14px+); 所有浮动
  面板深底亮字; 浅底按钮用深字。不能让文字糊在地表上看不见。
- 数字/遥测/坐标 JetBrains Mono; 正文 Inter/PingFang SC。禁 emoji; 图形 SVG/canvas/3D。
- 文字排布逐对检查不重叠。

## 6. 技术规格

- 单文件 HTML(内联 three + CC0 纹理 base64), 零外部依赖。代码量不限。
- 状态机(建议): `S = { rover:{x,z,heading,speed,battery,pose(摇臂角)}, mode(auto/manual/sample),
  target(目标点或null), path(规划路径), terrain(heightmap+类型图+岩石+露头), currentTerrain(类+置信度),
  traverseLog[], sol, tasks[], sampledRocks[], lang, camFollow }`。
- 纯函数: `genMarsTerrain(seed)` 地形+类型+岩石+露头; `classifyTerrain(x,z)` 地形分类置信度;
  `terrainSpeed(class)` 速度系数; `planPath(from,to,obstacles)` 避障路径; `stepRover(dt)` 运动学积分;
  `roverPose(x,z,terrain)` 摇臂随地形; `sinkRisk(class,speed)` 陷车判定。
- rAF 实时循环: 用户指令 → 自主导航算路径 → 逐帧 stepRover(转向/速度/电量/位置) → 地形分类刷新 →
  摇臂姿态 → 到达判定 → traverse log 追加。手动模式 WASD 直接控。
- i18n: `T={zh,en}`, langBtn 即时切换。暴露 window.S 及关键函数便于调试/自动化测试。
- 火星地表/车/岩石/露头/遥测罗盘均 3D 或 canvas 手绘, devicePixelRatio 适配。

## 7. 验收清单

- [ ] 打开即一台做好的火星车 + 一片火星地表, 无任何"制作/章节/训练"步骤; 3 秒内点目标点车就自主开过去。
- [ ] 自主导航成立: 点目标 → 车规划路径、绕开大石头、开到目标停下。
- [ ] 地形感知成立: 车开动时遥测实时刷新当前地形分类 + 置信度, HUD 联动。
- [ ] 自适应速度体验成立: 平滑地形加速、沙丘/粗糙自动减速; 有小气泡点破"内置分类器自动避坑/防陷车"。
- [ ] 科学采样: 能派车到露头采样, 传回样本卡。
- [ ] 完整任务 + 回传日志: 从着陆点穿越到目标 → 打出 NASA 格式 traverse log + Sol 日报(非门控, 是仪式)。
- [ ] 摇臂悬挂随地形起伏可见(火星车招牌细节)。
- [ ] 车辆行驶动作规范(所有车辆类项目通用, 实测踩坑沉淀):
  - 车头始终对齐速度方向(实现时严格推导 yaw 与 heading 的映射, 差 90 度就是"横着滑");
  - 车轮必须真实滚动: 转速 = v/r, 左右差速(转弯外侧快), 原地转向时两侧反转;
  - 逐轮贴地: 每帧采样每个轮子脚下地形高度, 增量反解摇臂/转向架角度, 轮子随起伏上下伸缩;
    横坡的左右高差摇臂吸收不了, 必须反馈进车身 roll; 轮底目标比解析地面低 ~0.1(压进沙里,
    否则渲染网格格点间比解析面低, 轮子看着悬空);
  - 行驶扬尘: 后轮后方粒子尾迹(生命 1.6-2.4s 拉出尾迹长度; 尘色要比沙地暗一档否则看不见;
    CanvasTexture 记得设 sRGBEncoding)。
- [ ] 写实 PBR: 火星红沙/岩石/车体金属质感 + 橙粉火星天空 + 锐利硬阴影, 达到 emg 3D 版的精致度。
- [ ] 运动学/地形分类/路径规划/陷车判定真算(抽查与手算一致)。
- [ ] UI 文字全部清晰可读(深底亮字, 无糊在地表); 中英切换无漏翻无溢出; 1280×800 无滚动条; 无 console error。
- [ ] 整体基调是"指挥一台属于你的、能自主跑火星的成品车", 传达价值与成就感, 不是重走制作流程。
