# 项目级模拟游戏设计 Prompt — satellite-archaeology

> 用途: 项目级(而非 knode 级)交互模拟游戏。一个项目一个 HTML,整体模拟该项目的**最终产出物**,
> 让学生在开始学习前就"玩到"自己 32 周后将做出的东西。
> 本文件是给实现者(Claude Code)的完整设计规格,实现时严格遵循。
> 范式基线: 复用已验证的 purpleair_design_prompt.md 全部工程契约(两步流程、真算数值、
> 决策留后果、诊断循环、深空共享画布、单文件零依赖、中英双语、1280×800 固定视口)。
> 本文件只详述本项目独有的设计,通用契约见第 5-6 节。

## 0. 项目背景(来自 blueprint)

- 项目: AI 卫星考古学家 (Sentinel-2 遗址检测), 16-18 岁, 32 周, 预算 $80, 难度 5/5。
- 真实原型: Sarah Parcak 的 GlobalXplorer / TED Prize; 2024 Nature (Auld-Thomas et al.)
  用 PyTorch 在 LiDAR + Sentinel-2 上发现数百个玛雅遗址; ESA Sentinel-2 免费 10m 多光谱全球影像;
  工具链 Google Earth Engine + rasterio + scikit-learn/PyTorch。
- 最终产出物: 一个**训练好的 CV 模型** + 一次**真实区域考古普查** + 一份**负责任披露的候选遗址短名单** +
  一份 6 页论文式报告 + 与真实考古学家的对接。最高可能: 发现一处新遗址; 即使零发现,方法学本身可发表。
- 核心科学信号: 埋在地下的墙基/夯土改变上方土壤持水与作物长势, 在近红外/植被指数上留下**规则几何**
  的作物标记 (crop mark); 真彩色几乎看不见, 假彩色(NIR-R-G)与 NDVI 上现形。
- 独有伦理维度: 负责任披露 (ICOMOS/责任规范) —— 发现遗址**不得直接公开精确坐标**,
  须先通知国家文物主管机构、获许可后坐标脱敏发布, 否则招致盗掘。

## 1. 游戏定位与核心幻想

**名称**: 卫星考古学家 / Satellite Archaeologist
**核心幻想**: 你是一名 AI 卫星考古学家。从一片真实地理区域的多光谱卫星影像出发,学会辨认地下遗址
在植被上留下的作物标记, 训练一个能识别这种信号的 CV 模型, 把它**放到一片从未被扫描过的区域上跑**,
在成百上千候选点里层层筛掉假阳性, 锁定一处高置信度疑似遗址, 走负责任披露流程, 最终等来考古学家
无人机确认 —— 你的名字进入论文。

**"部署到应用环境"的映射(本项目的关键)**:
产出物是软件(CV 模型 + 数据流水线), 非实体。它的"应用环境"= **真实多光谱数据 + 真实地理空间 +
真实评估指标**。玩家操作的对象就是这条流水线本身和它在真实地图上的产出:
- 部署 = 把训练好的模型放到一片 100 km² 真实感区域上逐格扫描(第 3 章)。
- 环境反馈 = 候选点在地图上一个个亮起 / 混淆矩阵 / ROC / 假阳性在真实地物上显形。
这与 purpleair 的**物理部署**(焊线/外壳/选址)形成正交对照 —— 证明范式能覆盖软件/AI 类产出物。

**设计原则**:
1. 模拟的是**产出物**, 不是课程知识点 —— 玩家操作的对象是这条 CV 流水线和它扫出来的候选遗址。
2. 所有数值必须**真算**: NDVI/NDWI 逐像素、特征提取、分类器打分、混淆矩阵、F1、ROC、
   置信度全部用真实公式在 JS 里算, 不做假动画。地形与遗址信号由同一套程序化噪声函数生成,
   "真值"(哪里真有遗址)与"假阳性诱因"(河曲/田界/云影)都由该函数确定性注入。
3. 玩家的**每个决策都留下后果**: 负样本没标云影 → 实扫时云影全成假阳性; 不做地理分割 →
   测试 F1 虚高、实扫崩盘; 特征只用真彩色 → 模型基本瞎; 阈值太低 → 候选爆炸难以三查。
   后果在第 3/4 章以数据形式显形, 允许回头修复(镜像项目 W15 误差分析 → W21 精修 → W22 重扫的循环)。
4. 失败不是终局而是诊断入口: 实扫全是假阳性 / 验证不过时给出可交互诊断芯片, 修复后重扫重评。
5. 伦理是硬闸门: 跳过负责任披露直接公开坐标 → 触发"盗掘风险"失败演出, 必须补走披露流程才能结算。

## 2. 章节结构(镜像项目 4 个 Phase)

单页四章连续推进, 侧栏 roadmap 显示进度。全程一个存档状态对象 `S`, 前章决策影响后章数据。
四章: SIGNAL(信号) → TRAIN(训练) → HUNT(搜寻) → DISCLOSE(披露)。

### 第 1 章 SIGNAL — 认识遗址信号并标注样本 (对应 Phase 1: 选区 + 目标信号)
- 场景: 多光谱瓦片查看器。中央大图为当前瓦片, 顶部波段合成切换条:
  `真彩色 (R-G-B)` / `假彩色 (NIR-R-G)` / `NDVI` / `NDWI` 四个模式即时重渲。
- 真科学演出: 同一瓦片, 真彩色下遗址几乎不可见; 切到假彩色植被变红、切到 NDVI 时,
  地下墙基上方作物长势偏弱 → 呈现**规则几何**(方形广场轮廓 / 直线道路 / 直角地块),
  与天然地物(蜿蜒河道、不规则田块、圆形云影)形成"规则 vs 不规则"的辨认训练。
  NDVI = (NIR − Red) / (NIR + Red), 逐像素真算并映射到绿-棕色带; crop mark 处 NDVI 系统性偏低。
- 交互 A — 波段探索: 玩家必须切到假彩色或 NDVI 才能看清信号(真彩色下"通过标注"按钮禁用并提示
  "试试其它波段"), 建立"选对波段才现形"的认知。
- 交互 B — 样本标注: 给 6 个瓦片(3 含遗址、3 天然噪声), 玩家逐个判定
  `含遗址信号(正样本)` / `天然地貌(负样本)`。其中天然噪声瓦片刻意包含三类假阳性诱因:
  蜿蜒河道、规则农田边界、圆形云影 —— **玩家是否把这三类正确标为负样本, 直接决定第 3 章
  实扫时这三类地物会不会被误判为遗址**(标注不足 → 模型没见过该类负例 → 实扫假阳性)。
- guide 知识点: 为什么真彩色看不见遗址? (可见光只反映地表颜色, 近红外反映植被健康,
  地下结构通过影响作物长势"泄露"到近红外)。
- 通过条件: 至少标注全部 6 瓦片(正负都要有), 点"完成标注 → 进入训练台"。
  标注质量(尤其三类噪声是否标对)记入 S, 不当场评分, 后果留到第 3 章。

### 第 2 章 TRAIN — 训练与标定 (对应 Phase 2: 基线 + CNN + 标定)
- 场景: 训练台。三块可调配置 + 右侧实时评估面板。
- 配置项(玩家决策, 每项都留后果):
  1. **特征选择**(多选波段/指数): 真彩色 R/G/B、NIR、NDVI、NDWI、纹理(局部方差)。
     只勾真彩色 → 分类器几乎无判别力(遗址信号在可见光里没有); 勾上 NDVI+NIR+纹理 → 判别力强。
  2. **正负样本比例**滑杆: 1:1 ~ 1:10。过度偏向负样本 → 高精确率但低召回(漏掉真遗址);
     偏正 → 假阳性泛滥。默认引导到均衡区间。
  3. **地理分割开关**(防数据泄漏): 开 = 训练区与测试区地理隔开(诚实评估);
     关 = 随机分割, 相邻像素同时进训练和测试 → **测试 F1 虚高**(演出上直接显示一个诱人的高分),
     但第 3 章实扫会崩(诊断芯片会点破"你在泄漏的分数上自我感觉良好")。
- 真算引擎: 用第 1 章玩家标注的样本, 在 JS 里真跑一个轻量线性分类器
  (逻辑回归式加权打分, 见第 5 节 `classify()`), 对留出测试集算:
  **混淆矩阵(TP/FP/FN/TN)、精确率、召回、F1、ROC 曲线(扫阈值真算 TPR-FPR 点集, canvas 绘制)**。
  全部由玩家的特征/比例/分割选择真实决定, 改配置即时重算重绘。
- 通过条件: 点"训练"跑出评估后, 测试 F1 ≥ 0.60 且**地理分割为开**才允许"部署到搜寻区"。
  (地理分割关时即便 F1 高也拦截, 提示"这个分数不可信 —— 打开地理分割再看真实水平"。)
- guide 知识点: 数据泄漏为何致命(测试集偷看了训练信息, 分数是幻觉); ROC/F1 怎么读。

### 第 3 章 HUNT — 实区扫描 (核心章, 对应 Phase 3: 扫区 + 三查 + 精修重扫)
- 场景: 一片 100 km² 真实感区域地图(canvas 程序化生成, 见第 5 节 `genTerrain`):
  蜿蜒河流、农田网格、林地斑块、地形晕渲(hillshade), 整体贴合遥感假彩色/NDVI 色调。
  可在 `假彩色 / NDVI` 两个底图间切换(复用第 1 章渲染逻辑)。
- 部署演出: 玩家点"运行扫描", 模型逐格(如 40×30 网格)扫过整片区域, 扫描线从上到下推进,
  每格用第 2 章训好的分类器对该格特征真算置信度, **候选点按置信度着色**逐个亮起,
  最终产出 100+ 候选(具体数量取决于阈值与模型质量)。
- 真值与假阳性来源(确定性, 玩家不可见实现): `genTerrain` 里预埋 N 个真遗址(规则几何 crop mark)
  和大量天然噪声地物; 每格置信度 = 分类器对该格 NDVI/纹理/几何规则度特征的打分。
  - 若玩家第 1 章漏标"云影"为负样本 → 云影格特征未被压制 → 成片假阳性亮在云影区。
  - 若漏标"河曲/田界" → 对应地物触发线状假阳性。
  - 若第 2 章特征只用真彩色 → 满图随机噪点, 无结构。
- 玩家任务 — 三级筛选漏斗(镜像 W16→W17→W18→W19: 100+ → 30 → top10):
  1. **置信度阈值滑杆**: 拖高阈值, 低分候选批量熄灭(100+ → 约 30)。滑杆旁实时显示"当前候选数"。
  2. **人工三查**(逐个点候选看详情卡): 详情卡叠加"历史地图图层 / 地形坡度 / 已知设施数据库"
     三个可开关的证据层。玩家据此剔除明显误报: "这是现代水库(NDWI 全水体)""这是天然圆形台地
     (坡度均匀无几何边)""这点命中已知现代农场数据库"。剔除是主动动作(点"排除")。
  3. **跨季交叉验证**: 对剩余候选点"调另一季影像复核"—— 真遗址两季 crop mark 都在(持久地物),
     云影/临时积水只在一季出现 → 一键"跨季比对"把只在单季出现的候选标红建议排除。
     (实现: `genTerrain` 对每格附带 season1/season2 两个置信度, 真遗址两季一致, 噪声两季不一致。)
  - 目标: 筛到 **top 3** 高置信度候选, 点"提交专家复核"进入第 4 章。
- 诊断循环(候选异常时): 若三查后仍无法收敛到干净 top3(假阳性过多/真遗址被阈值误杀),
  指标区给出诊断芯片, 点击展开:
  - "满图云影假阳性 → 第 1 章漏标云影负样本" (按钮: 回第 1 章补标 → 补标后自动重训重扫)
  - "分数虚高但实扫全错 → 第 2 章数据泄漏, 打开地理分割重训" (按钮: 回第 2 章)
  - "满图随机噪点无结构 → 第 2 章特征缺 NDVI/NIR" (按钮: 回第 2 章加特征)
  - "候选太多 → 提高置信度阈值" / "真遗址被误杀 → 阈值过高, 略降"
  修复动作触发局部重算(补标→重训→重扫, 快进演出数秒), 重新进入三查。

### 第 4 章 DISCLOSE — 专家复核与负责任披露 (对应 Phase 4: 复核 + 披露 + 发表)
- 场景 A — 专家复核台: 把 top 3 提交虚拟考古学家。专家逐条给反馈(据候选真实属性生成):
  - 命中已知遗址数据库的 → "#X 是已知的殖民时期农庄, 你查过 Open Context 吗?" (要求玩家排除)
  - 几何太规则疑现代的 → "#Y 边缘过于笔直, 疑似现代地块, 再用高分辨率核对"
  - 真遗址 → "#Z 的规则广场轮廓 + 两季一致的 crop mark, 值得实地核查"
  玩家据反馈把 3 个收敛到 1 个高置信度**主候选**。
- 场景 B — 负责任披露闸门(本项目独有、必须体现的伦理核心):
  给两个选项 —— `直接公开精确坐标发帖` vs `走负责任披露流程`。
  - 选"直接公开" → 失败演出: 地图上主候选点被标"COORDINATES LEAKED", 弹出盗掘警示卡
    (未经许可公开遗址坐标 → 盗掘/破坏风险), 强制回到披露选择, 不可跳过。
  - 选"负责任披露" → 三步流程闸门(点击逐步推进):
    1. 通知国家文物主管机构(生成脱敏披露邮件预览: 只含区域范围, 不含精确坐标)
    2. 等待许可(演出: 状态从 PENDING → CLEARED)
    3. 坐标脱敏发布(精确坐标打码为网格级)
- 场景 C — 结算仪式(披露通过后解锁): 视角拉到区域地图, 主候选点脉冲, 无人机图标飞越确认,
  弹出**遗址发现卡**: 脱敏坐标、置信度、信号类型(crop-mark / 规则广场)、发现方法(Sentinel-2 + CV);
  随后打出**产出物徽章**: GitHub 仓库(代码公开、无坐标) + HuggingFace 数据集(仅训练集、不含预测);
  最终结算卡: 扫描面积、候选总数、假阳性剔除数、最终置信度、模型 F1、工程决策回顾
  (哪些一次做对 / 哪些返工: 是否漏标噪声、是否踩数据泄漏、是否试图跳过披露)。
- 结算后开放"自由搜寻"模式: 可换目标信号(玛雅广场 / 罗马别墅 crop mark / 新石器土墩)与换区域
  重新生成地形反复扫, 观察不同信号/地物下的假阳性模式(供反复把玩)。

## 4. 视觉规格 (遵循 purpleair 同款契约, 仅调色板)

- 视口: 固定 1280×800 设计视口(meta width=1280), body 100vw/100vh overflow hidden,
  外层由前端 ScaledIframe 等比缩放 —— 不做响应式。
- 基底: 深空共享画布(--bg-0: oklch(0.14 0.035 265) 系列)。
- 主题色板 AER-16 遥感穹顶(建议, 实现时可微调保持 oklch 一致性):
  ORBIT oklch(0.72 0.14 230) 冷蓝(界面主色/扫描线) /
  VEG oklch(0.70 0.16 145) 植被绿(NDVI 高值/假彩色植被) /
  SOIL oklch(0.62 0.12 70) 土黄(裸土/低 NDVI) /
  RELIC oklch(0.80 0.15 55) 遗址高亮金(候选点/crop mark 描边) /
  DAWN oklch(0.92 0.06 230) 高光文字。
- NDVI 色带为功能色特例(科学语义, 允许突破色板): 棕(低)→ 黄 → 绿(高), oklch 定义并降饱和贴深色主题。
  假彩色渲染: 植被→红/品红, 水体→深蓝, 裸土→青灰(近似 NIR-R-G 合成的经典观感)。
  置信度着色: 低→冷蓝暗, 高→ RELIC 金亮; 假阳性簇在诊断时可临时描红。
- 数字/HUD/坐标/指标一律 JetBrains Mono(带系统等宽兜底), 正文 Inter/PingFang SC。
- 硬边框 1.5px + 3px 硬阴影按钮(与现有 game 一致), 禁止圆角软阴影玻璃拟态。
- 禁止任何 emoji / Unicode 装饰符号, 图形一律 SVG/canvas 手绘。
- canvas 的直接父容器必须 display:flex + flex-direction:column(shim flex 契约)。
- 顶层禁用 history/location/name/status 等 window 同名变量。
- 文字排布逐对检查不重叠(尤其 NDVI 色带标签、混淆矩阵格子数值、ROC 轴标 vs 图例、候选详情卡)。

## 5. 技术规格

- 单文件 HTML, 零外部依赖, 内联全部 CSS/JS。代码量不限, 以表达清楚为准。
- 状态机(建议形态, 实现可增补):
  ```
  S = {
    chapter,
    band,                       // 当前波段模式 'rgb'|'false'|'ndvi'|'ndwi'
    labels: { [tileId]: 'pos'|'neg' },   // 第1章标注; 记录三类噪声是否标对
    features: {rgb,nir,ndvi,ndwi,texture},// 第2章特征选择(bool)
    posNegRatio,                // 第2章样本比例
    geoSplit,                   // 第2章地理分割开关(true=诚实)
    model: {weights, f1, roc[], confusion:{tp,fp,fn,tn}},
    terrain,                    // 第3章程序化地形 + 每格真值/双季置信度
    threshold,                  // 第3章置信度阈值
    candidates: [{x,y,conf1,conf2,truth,knownDB,geomReg,excluded}],
    top3, mainCandidate,
    disclosure: 'none'|'leaked'|'notified'|'cleared'|'published',
    lang
  }
  ```
- 纯函数(重算 = 重跑纯函数, 与 purpleair 同哲学):
  - `hash01(x,s)/n11(x,s)/smoothstep` — 与 purpleair 同款确定性噪声原语。
  - `ndviAt(px)/ndwiAt(px)` — 逐像素指数真算。
  - `genTerrain(seed, signalType)` — 程序化生成 100 km² 区域: 河流(蜿蜒曲线)、农田(规则网格)、
    林地(斑块噪声)、hillshade; 预埋 N 个真遗址(规则几何 crop mark, truth=1)与噪声地物;
    每格产出特征向量 + season1/season2 双置信度基底(真遗址两季一致, 噪声两季不一致)。
  - `classify(featVec, S.features, weights)` — 轻量线性分类器打分(逻辑回归式), 训练=用第1章样本
    最小二乘/感知机式估权; 只勾真彩色时权重对遗址信号近乎为零(判别力自然坍塌)。
  - `evaluate(model, testSet, geoSplit)` — 算混淆矩阵/精确率/召回/F1; geoSplit=false 时故意让
    测试集含训练邻域(泄漏) → F1 虚高。
  - `rocCurve(scores, labels)` — 扫阈值算 (FPR,TPR) 点集。
  - `scanRegion(terrain, model, threshold)` — 逐格 classify → 生成候选集(含 truth/knownDB/geomReg)。
- 折线图(ROC)、混淆矩阵热力格、区域地图(假彩色/NDVI 底图 + 候选点 + 扫描线 + hillshade)、
  瓦片查看器均为 2D canvas 手绘, devicePixelRatio 适配。
- i18n: 所有文案存 `T = {zh:{...}, en:{...}}`, langBtn 切换即时刷新。
