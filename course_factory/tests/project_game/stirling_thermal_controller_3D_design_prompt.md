  手动调火看功率曲线 → 打开 AI 让**爬山算法自己找到最大功率点** → 强制过热触发**自我保护**。
  全程"点一根火柴, 指挥一台会自己学习、会自我保护的发电厂"。
- 全屏 3D (Three.js r149 内联, 自写轨道相机)。斯特林发动机 + 酒精灯火焰 + 发电机 + LED 阵列 +
  OLED 屏 + 伺服调火都是 3D 实体。❌ 不做 2D 看板。HUD 只是薄薄一层遥测 + 曲线。

## 1. 成品定义(玩家拥有的东西)

学生 66 周后的最终产出物, 在游戏里表现为一套已部署的 **火焰 AI 发电厂 "PYRA-1"**:

1. **斯特林发动机**: 金属受热缸 + 位移活塞(displacer) + 动力活塞(power piston) + **飞轮** + 连杆机构
   (90° 相位)。受热端底下一盏**酒精灯火焰**(可调大小)。飞轮受热后自己转起来。
2. **发电机 + 能量链**: 飞轮同轴带一个小发电机(线圈)。发出的电点亮一排 **LED 阵列**(功率越大亮越多)、
   给**超级电容**充电、驱动一块 **OLED 屏**自报 `POWER: x.x W`。cover 般的"火→电→光"链。
3. **传感器眼睛**: 受热端 K 型热电偶(温度)、飞轮光电测速(RPM)、INA219(实测发电功率 W)。HUD 实时显示。
4. **AI 控制大脑**: 伺服调进气口(改火大小) + **PID 稳功率** + **爬山寻优**(自己找最大功率点, MPPT 同理) +
   **异常检测/自我保护**(过热→切火→报警→冷却)。HUD 模型卡: `PID + Hill-Climb + Safeguard · Arduino`。

## 2. 3D 场景与美术

### 2.1 斯特林发动机 (主角之一)
- 经典 β/γ 型斯特林: 一个横置或竖置的**金属受热缸**(黄铜/不锈钢质感) + 玻璃/金属**飞轮**(带辐条,
  转起来) + 连杆 + 动力活塞缸。受热端一侧, 冷端另一侧(散热片)。整体桌面仪器感, 金属 PBR + 反射。
- **飞轮真转** (引擎驱动 RPM), 转速随功率变化肉眼可见。连杆随飞轮联动。
- 受热端底下**酒精灯**: 灯座 + 灯芯 + **火焰**(程序化: 锥形半透明橙黄渐变 mesh + 摇曳动画 + 发光)。
  火焰大小随"进气/火力"改变 (伺服调)。

### 2.2 能量链 (主角之二, cover 的"火→电→光")
- 飞轮同轴**发电机**(圆柱线圈体)。一条细电缆连到旁边的**电路板**上: 一排 **10 颗 LED**(功率越高亮越多颗,
  从暗红→亮白依次点亮)、一个**超级电容**(圆柱, 充电时有进度环)、一块 **OLED 小屏**(canvas 贴图,
  自报 `POWER: 0.92 W` + 迷你功率条)。
- 发电时电缆/LED 发光, 超级电容进度环填充。这是全场最"哇"的一环。

### 2.3 伺服调火 + 传感器
- 进气口一个小**伺服 + 挡板**(SG90 风格), 转动改变进气→火焰大小。控制回路的"手"。
- 受热端一个**热电偶探针** + 飞轮旁**光电测速模块** + 板上 **INA219 模块**(小方块, 标签)。
  过热时热电偶探针/受热缸**染红警示**。

### 2.4 光照与基调
- 暖科技桌面: 深色台面 + 主平行光 + 火焰自发光(点光源随火焰跳动) + 补光。金属发动机冷反射 vs
  火焰暖光对比。PMREM 给黄铜/发电机金属真反射。过热时全局微微泛红。

## 3. 交互与任务链

### 3.1 核心交互(运行发电厂)
1. **点火**: 点"点火" → 酒精灯火焰亮起 → 受热端温度上升 → 温差建立 → 飞轮**自己转起来**(spin-up 动画,
   延迟几秒, 呼应 Hook) → 发电 → LED 依次亮 → OLED 显示 POWER。第一次点火是核心"哇"时刻。
2. **手动调火**: 一个火力滑杆(伺服角度) → 火焰大小 + 温度 + RPM + 功率实时联动。**火焰-功率有峰值**
   (火太小功率低, 火太大反而过热降效/危险), 让玩家手动找峰难受 → 引出 AI。
3. **PID 稳功率**: 设一个目标功率, 开 PID → 控制器自动调火把发电功率稳在设定点 (有扰动时能拉回)。
4. **AI 爬山寻优 (MPPT)**: 点"自动寻优" → 机器从当前火力**自己小步试探**(加火→功率涨?继续; 降了?退回)→
   几步内爬到**最大功率点**并稳住。屏上画出"火力-功率"爬山轨迹。这是"机器自己学会控制自己"的高光。
5. **强制过热 → 自我保护**: 点"强制过热"(把火开到危险) → 受热端温度冲高 → 异常检测触发 →
   **自动切火 + 屏幕报警 "I'm too hot, cooling down" + 冷却** → 温度回落。点破"它会自我保护, 不等人救"。
6. **能量守恒诚实提示**: 酒精量条随燃烧下降; 烧完则熄火 → 提示"不是永动机, 酒精是能量来源"。

### 3.2 任务链(里程碑式仪式, 非门控)
1. 点火, 让飞轮转起来发电, 点亮第一颗 LED (看 POWER 上屏)。
2. 手动调火, 体会"火力-功率有个甜点, 手动难找"。
3. 开 AI 爬山寻优, 让机器自己爬到最大功率点。
4. 强制过热, 看自我保护切火冷却 → 火焰 AI 发电厂闭环报告 (峰值功率/收敛时间/保护触发时间 +
   NASA Kilopower/Stirling + 太阳能 MPPT 致敬)。

### 3.3 隐形礼物 bubble
- 第一次发电点亮 LED: "你用<b>一根火柴</b>点亮了一座发电厂 —— 火→热→飞轮→电→光, 全链条从零你亲手接通。"
- 第一次爬山寻优: "它在<b>自己找最大功率点</b> —— 和太阳能逆变器全天跑的 MPPT 是同一个算法。"
- 第一次自我保护: "它有了<b>自保护本能</b> —— 过热就自己切火, 不等你救。NASA 的发电厂也这么做。"

## 4. 真算引擎(纯函数, node 可单测)

- `stirlingPhysics(fire, dt, state)`: 热力学状态推进。火力 → 受热端温度上升(一阶滞后); 温差 =
  热端 − 冷端; 温差驱动飞轮扭矩 → RPM(带惯性/阻尼); **发电功率 = f(温差, RPM)**。
  关键: **火力-功率是单峰曲线** —— 火太小温差不够功率低; 火太大热端过热但效率/材料降(引入过热惩罚),
  所以有一个最优火力 `fireOpt`。确定性。
- `powerAt(fire)`: 稳态功率-火力曲线(单峰, 峰在 fireOpt), 供爬山/绘图/断言。
- `pidStep(target, measured, state, gains)`: 位置式 PID 输出火力增量(P 比例/I 积分/D 微分), 稳发电功率。
- `hillClimb(state)`: 爬山寻优一步 —— 记住上次功率, 小步试探火力方向, 功率涨则继续、降则反向,
  自适应步长 + 读数平均(抗噪), 收敛到 fireOpt。返回新火力 + 是否收敛。
- `anomalyCheck(temp, rpm, power, limits)`: 异常检测 —— 过热(temp>Tmax)/失速(rpm≈0 但火大)/
  读数异常 → 返回 {alarm, reason}。
- `safeguard(state)`: 触发后切火(fire→0) + 进入冷却态 + 温度回落。
- `fuelBurn(fire, dt, fuel)`: 酒精消耗 = f(火力), 烧完熄火 (能量守恒: 不是永动机)。
- `ledCount(power)`: 功率 → 点亮 LED 数(0-10); `capCharge(power, dt, cap)`: 超级电容充电。
- `itrOrMetrics(...)`: 报告用指标(峰值功率/爬山收敛步数/PID 稳态误差/保护触发时间)。
- 抽样断言: powerAt 单峰(峰在 fireOpt, 两侧下降); PID 把功率收敛到目标; hillClimb 从任意起点收敛到
  fireOpt 附近; 过热触发 anomaly+safeguard 后温度回落; 火力越大燃料消耗越快; ledCount 随功率单调。

## 6. 技术规格

- 单文件 HTML, 内联 three r149 + 少量 CC0 法线纹理 base64, 零依赖。
- 状态机: `S = { ready, fire, temp, tempCold, rpm, power, fuel, mode(manual/pid/auto/overheat/cooling),
