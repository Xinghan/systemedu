# 动手任务: 把几项分数综合成一份 Top10 榜单

这一节你做出了工作台的加权综合排名器。下面这几道题, 帮你确认自己真的弄懂了"为什么相加之前要先统一尺子"和"权重到底是什么"。

## 选择题

### 第 1 题

漏斗筛剩的几百个幸存分子, 每个身上带着溶解度分、毒性分、活性分这几个数。直接把这几个数加在一起当总分, 主要的毛病是什么?

A. 加起来太慢, 几百个分子算不过来
B. 几个数量级、方向都不一样, 数最大的那一项会盖住别的项, 总分其实只由它一项说了算
C. 加法本身算错, 应该用减法
D. 分子太少, 加起来没意义

**答案: B**

这几项量的是不同的东西、刻度不同、方向有时还相反。溶解度可能在几十上下, 活性概率只在 0 到 1 之间, 硬加的话, 那个大数把小数全淹了, 你以为在算"综合", 其实只有一项在拿主意。所以相加前必须先归一化。

### 第 2 题

毒性是"越大越危险, 越小越好"。在归一化(都压到 0 到 1、越接近 1 越好)的时候, 对毒性这一项要特别多做哪一步?

A. 不用管, 跟别的项一样直接压到 0 到 1
B. 把它从总分里删掉, 不参与排名
C. 把方向翻过来, 让毒性最小的分子拿接近 1 的好评、毒性最大的拿接近 0
D. 把它的数都乘以 2

**答案: C**

"越大越好"的项和"越小越好"的项, 不翻方向就没法放一起加。毒性不翻过来的话, 越毒的分子反而总分越高, 整个名次会被它带歪。翻完之后, 四项才统统变成"0 到 1、越大越好"的同一种东西。

### 第 3 题

同一堆分子、同一套已经归一化好的分数, 你只把"毒性"这一项的权重调大了一些, 重新算总分再排队。会发生什么?

A. Top10 完全不变, 权重不影响名次
B. 那些特别安全(毒性小)的分子总分上升, 往榜单前面挤, Top10 跟着洗牌
C. 所有分子的总分都变成 0
D. 分子的数量变少了

**答案: B**

权重装的是你的偏好。你更看重毒性, 总分这杆秤就更偏向安全的分子, 它们的名次自然往前提。人没变、分数没变, 变的是"什么最重要"的标准, 排出来的前十名就不一样了。

## 问答题

### 第 4 题

用你自己的话说清楚: 归一化(把每一项都换算到 0 到 1 的同一把尺子)这一步, 如果偷懒跳过, 为什么特别坑人? 它跟"算出来报个错"的普通 bug 有什么不一样?

**参考答案**: 跳过归一化, 程序不会报错, 总分照样算得出来、Top10 照样排得出来, 看着一切正常。但这串"看起来很专业"的总分其实早被数量级最大的那一项绑架了, 别的项参不参与几乎没区别, 排出来的顺序是错的。它不喊疼、不报警, 你光看结果根本发现不了, 全靠心里清楚"加之前必须先统一尺子"。普通 bug 会崩、会报错, 提醒你去修; 这种错却悄无声息, 还排得理直气壮, 所以更危险。

### 第 5 题

漏斗用的是"一票否决"的硬门槛(有一项不达标就直接出局), 这一节的加权综合却允许某一项稍弱。为什么到了"从合格者里挑最好的十个"这一步, 加权综合比硬门槛更合适? 举一个生活里的例子说明。

**参考答案**: 硬门槛太粗暴, 一个综合很强、只在某一项上差一点点的好分子, 会被一刀切掉, 太可惜。加权综合是算总账: 允许某项稍弱, 只要在更重要的几项上够强, 总分照样能排到前面。现实里好东西很少样样满分, 多半是"有短板但整体出色", 加权综合正好能把这种捞出来。生活里的例子: 班级选三好学生, 不会因为某人体育稍弱就直接刷掉, 而是把学习、品德、体育各打个分、按看重程度凑成总评再排——一个学习品德都很突出、体育一般的同学照样能评上。(言之成理即可)

## 动手做

找一张纸或一个表格, 给你身边的 3 样东西排个名次, 亲手走一遍"归一化 → 配权重 → 加权求总分 → 排名"。比如给 3 个想买的零食排名, 每样从三个方面各打一个原始分: 好吃(0 到 10 分)、便宜(价格元数, 越小越好)、份量大(克数)。

1. **归一化**: 把这三列分别压到 0 到 1。"好吃"和"份量"是越大越好, 直接按最小对齐 0、最大对齐 1; "便宜"是价格、越小越好, 记得把方向翻过来(最便宜的拿接近 1)。
2. **配权重**: 想清楚你最看重哪一项, 给它配最大的权重(三个权重加起来等于 1)。比如你最在乎好吃, 就给好吃配 0.6、便宜 0.2、份量 0.2。这一步**建议[需家长协助]**, 和大人讨论着定。
3. **加权求总分**: 每样东西"归一化分 × 它的权重"三项加起来, 算出总分, 从高到低排出名次。
4. **改一个权重再排一次**: 把"便宜"的权重调大(比如改成好吃 0.3、便宜 0.5、份量 0.2), 重新算、重新排, 看名次怎么洗牌。

把两次的名次都写下来, 用一句话说说: 是哪一样东西的排名变了? 为什么权重一改它就动了? 这一刻你就真切体会到——**权重就是你的偏好, 你看重什么, 榜单就替你把什么排在前面。**
