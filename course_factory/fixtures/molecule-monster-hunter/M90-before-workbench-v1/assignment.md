## 阶段作品

**我的怪兽猎人 Go/No-Go 报告**：把分子证据、模型预测和局限整理成一份可追溯的选择报告，明确哪些只是下一步研究假设。

## 交付物

- **我的怪兽猎人 Go/No-Go 报告**：保存一份清楚、别人也能查看的版本。

## 自检清单

- [ ] 报告里有一个候选分子、对应数据证据和模型预测。
- [ ] 我用 Go、No-Go 或“需要更多证据”说明自己的决定。
- [ ] 我写清模型局限和不能据此做医疗决定的原因。
- [ ] 我向一位观众讲过报告，并记下一个问题或反馈。

## 下一关会用到它

我会把报告展示给同伴或老师，并选择一个想用更多公开证据继续研究的问题。

> 这是全课终点的成品交付节点(capstone)。你要交出的不是一张卷子, 而是一台**能跑起来的分子怪兽猎人工作台** + 一份**它自己吐出来的诚实候选报告** + 一张**打过勾的总装验收清单**。下面告诉你怎么算合格、要交什么、怎么写自评。这一节需要家长陪你一起跑。

## 一、考核要点说明

这一关验收的核心只有一句话: **你的工作台是不是"一串 SMILES 进、一份诚实报告出"的能跑通的完整成品**。逐条对照下面的标准。

**标准 1: 接通整条线, 输进 SMILES 能一路自己走完。**
- 评判要点: 从输入一串 SMILES 出发, 经 RDKit 读通并画结构图、算特征、模型预测、多层漏斗打分排序, 末端真的吐出一份报告, 中间不用你手动一道道接力。
- 常见扣分: 各零件还是各跑各的, 得手敲五六步才出结果——那不是工作台, 还是一抽屉零散脚本。

**标准 2: 接缝处对得上, 特别是特征那一道。**
- 评判要点: 拿一个你知道答案的熟分子(如阿司匹林、乙醇)从头丢进去, 每个接缝都对得上, 不报错也不串味。
- 常见扣分: 喂给模型的特征少一列或换了顺序, 模型把油水性当分子量理解, 预测全错还偏偏不报错。

**标准 3: 报告诚实, 含真实指标。**
- 评判要点: 报告在 scaffold 划分(按骨架分开训练和考试分子)下算出真实 ROC-AUC / MAE, 每个候选标了 go/no-go 和理由, 列了 Top10, 配了 Lipinski 门槛。
- 常见扣分: 嫌分数难看就美化、偷换高分算法。**分数低也照实写**才算过——诚实是这份报告的命根子。

## 二、交付物自检清单(逐项打勾, 这张打过勾的清单本身就是交付证据)

**交付物: 能跑的工作台 + 一份诚实候选报告 + 一页验收报告**

- [ ] **一键跑通**: 输进一串 SMILES, 工作台从结构图到报告一路自己走完, 中途不用手动接力。
- [ ] **熟分子验证**: 拿阿司匹林或乙醇走一遍, 每个接缝都对得上, 末端吐出结果。
- [ ] **特征对齐**: 喂给模型的特征, 跟训模型时同一排、同一顺序, 没少列没换序。
- [ ] **报告含真实指标**: scaffold 划分下的真实 ROC-AUC / MAE 都如实写进了报告。
- [ ] **每个候选有理由**: 每个 go/no-go 旁边都写清是哪一条把它定下来的。
- [ ] **诚实护栏**: 哪怕 Top10 分数都一般, 也照实交, 没动手美化任何数字。

## 三、自评说明写作指引

交完成品, 写一小段自评(三到五句话), 老老实实回答下面四件事:

1. **我做了什么**: 我把哪几块零件(结构图 / 特征 / 诚实模型 / 多层漏斗 / 拒绝理由)按什么顺序接成了一条线, 装成了工作台。
2. **用了什么方法**: 我拿哪个熟分子走通了全程? 我怎么确认特征的列和顺序跟训模型时一模一样?
3. **遇到什么困难**: 总装时有没有出现"各零件都对、接起来出问题"的情况(比如某道接缝格式对不上、特征串了序、报告分数难看)?
4. **怎么解决的**: 我是怎么把那个藏在接缝里的毛病找出来、补好的? 报告分数不好看时我是照实写还是动了手脚?

**好的自评示例**: "我按 SMILES→结构图→特征→模型→漏斗→报告的顺序把六块零件接成了一条线。每接一道我就拿乙醇走一遍核接缝, 接到特征那道时发现少喂了一列, 模型预测全偏, 我把特征排成跟训模型时一模一样的顺序才对上。最后 scaffold 划分下 ROC-AUC 只有 0.7 出头, 不算好看, 但我一个数字都没改, 照实写进了报告, 六项验收全打了勾。"

**差的自评示例**: "我把工作台拼好了, 能跑, 报告也出来了, 没什么问题。"(没有证据、没有过程, 看不出你是否真接通了、报告是否诚实。)

## 四、一句话提醒

这是整门课的毕业作品, 别把它当成又一份要赶紧交掉的作业。它真正考的不是你会不会某一道工序——那些你早会了——而是你能不能把一整条线稳稳接通、再交出一份自己敢拍胸脯说"句句是真"的报告。所以验收时我们最看重两点: 一是**真接通**(熟分子能从入口一路自己走到出口、每个接缝都对得上, 不是手动一道道接力), 二是**真诚实**(报告里的 ROC-AUC / MAE 是 scaffold 划分下实打实算出来的, 哪怕难看也一个数字没动)。把这两点做扎实, 哪怕 Top10 分数平平, 这台工作台也算真正做成了——你也就从一个只会单点本事的人, 变成了一个能把一整条流水线攒成产品、并为它的诚实负责的人。跑通那一刻, 记得为自己好好庆祝一下。
