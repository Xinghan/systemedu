# 方案

在 guided-course 内容配置中增加最终交付说明（名称、交付节点、组成、验收描述）。首屏和侧栏链接指向对应节点的作品卡。驾驶规则验收复用已有确定性模型与实验记录验证，展示已保存规则和实际运行步骤。

课堂 notebook 将当前规则附件和说明交给作品卡。点击最终交付时快照到独立 assignment/final-deliverable 活动；复用现有账号隔离、版本冲突、幂等重试与历史，不新增数据库或评分服务。输入变更不覆盖已交付版本，缺失 / 失效证据不允许标为可交付。

更新作者规范与项目线 skill；对当前实现进行真实浏览器的空状态、缺件、有效作品、证据篡改、提交恢复与手机版检查。只提交本次涉及文件。
