# 可查看、可检验的项目最终交付物

Status: implemented locally (2026-09-20), pending production deployment

除三分钟 micro 体验外，项目必须在开始时明确最终交付物、学生贡献、验收方法与保存位置。学习笔记、游戏通关和课程节点提交不能替代项目作品。

本次落实驾驶规则课程：交付一份驾驶规则作品包，包括四种地形的可运行规则、同版本训练路线与换路测试记录，以及 unknown 处理和贡献 / 测试范围 / 平台能力的说明。首页显示交付目标，M04 汇总作品与验收状态，说明缺少的证据。已保存的作品可以查看每一步运行结果。

项目作品使用已有 learning records 的 assignment 类型单独保存并提交，保留版本历史；课堂记录原逻辑不变。通过测试仅指当前教学模型和两条路线；文字填写只核对完整性，不冒充理解评分。匿名用户明确仅在本机保存。

同步加强 systemeduidea 的 project-line 生成规范。三分钟入口保持轻量，不增加长报告；guided / integration / flagship 都要求具体作品、证据、自检和重新查看入口。已有完整课程沿用原课程工厂的交付规范，不在本次声称已逐一改造所有旗舰项目。
