# 项目线入口与难度分层项目库

Status: locally-complete (2026-09-19，待发布)

用户要求项目线视图展示大主题入口，而全部项目视图跨线展开具体项目，并从简单到困难排列。本次落实五个主题入口、可分享的主题详情与课程归属、全部项目的难度分组。主题依据内容仓库八个已有完整项目：太空探索、生物医药、脑机与仿生、地球探秘、能源与动力。

四条新主题线补齐短体验、引导制作、组装与完整课程的规划契约。规划节点明确标为筹备，不提供虚假启动链接。当前内容服务未接入的本地课程保留目标作品与课程元数据，但不生成不可达的详情链接。

项目线首页只包含主题入口与主题简介；进入主题后显示项目及路线。全部项目按短体验、引导制作、完整工程深度分组，最新排序只影响同层，不能把困难项目移到简单项目上方。筛选、两种视图切换、浏览器历史与双语保留。封面使用生成图片。

验收：五个入口均可打开、直接访问和返回；既有四个小游戏可达；所有八个已有课程有主题归属；课程发布状态准确；同层内排序、难度分组、窄屏无遮挡；内容服务故障下主题和本地短体验可用。

验收结果：12 组浏览器检查通过，390 / 768 / 1440 / 1920 像素宽度无横向溢出和封面遮字；五条内容契约结构校验通过；变更文件 ESLint 通过。全量 TypeScript 检查仍受仓库已有 slide-demo 与 learning 组件错误影响，本次变更文件无类型诊断。结果和截图见 `artifacts/themed-library/`。尚未进行真实儿童试用，新增四条线的短项目仍为设计，未部署生产。
