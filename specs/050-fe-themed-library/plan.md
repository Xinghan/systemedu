# 实施计划

1. 从内容仓库 manifest、知识树和蓝图生成五条主题的目录快照，保留源文件与课程 ID。新增主题线契约使用 project-line/1；不修改原课程。
2. 项目库统一使用 /library。项目线目录为 ?view=lines，详情为 ?view=lines&line=<id>，未知 ID 提供返回入口。主导航不增加 tab。
3. 主题目录用生成插画的入口卡片；详情采用主题横幅、可开始内容与分层规划，课程卡片通过真实 API 决定是否能打开。
4. 全部项目合并本地互动、真实课程服务和本地课程元数据快照；唯一 slug 去重。默认展示已有课程（包括待接入者），筛选可隐藏筹备项。短项目规划仅在主题详情显示。
5. 难度是稳定的外层顺序：轻量体验 → 引导制作 → 完整工程深度 1–2、3、4、5、待标注。发布/最新/推荐在同组排序，不跨组；组装未实现时不伪造可开始项目。
6. 验证目录、路由历史、状态异常、分组排序、封面边界、双语与手机。同步内容契约及图片，分别精确提交并推送两个仓库。
