# 超能机械师实施方案

既有样式和课程阅读器保持一致，使用 Three.js + SVG 构建真实受参数控制的机械/信号实验台，复用 useLearningRecord 与 GuidedProjectCourse。数据模型独立存放 bionics-model.ts，避免把能源状态字段改名后机械复制。

先完成能源线隔离发布和线上验收；新线仅本地预览，待用户查看后再发布。

1. 核对原肌电 M20/M25/M28/M38/M41、脑电 M13/M58 的任务与接口，查阅 Arduino、TI、Adafruit 一手资料。
2. 建立 7 项目、24 节正文/资料/任务生成器与源目录同步，保留既有旗舰引用。
3. 实现确定性因果处理、状态控制、角度—间隙几何、版本校验、受限规则解析和首次挑战记录。用边界/对照测试验证，不以实现镜像测试充数。
4. 制作可交互夹爪、信号门、精确 SVG 曲线与参数控件，兼容触控、键盘和无 WebGL。
5. 提供学生可改的 SCAD、对应 STL、器件/接口/接线说明、限位标定程序；未试制如实标注。原始测量、源代码和照片归属明确。
6. 接入两种微体验、课程工作台、数字原型/最终实物交付、本人前作参数消费与挑战记录。
7. 生成真实、成熟的主题封面，实际课程器材与画面对应，避免玩具造型或昂贵机器替代学生作品。
8. 验证模型/网格、每节访问、保存隔离/快照、微体验操作/重试、独立挑战、手机与降级。同步 systemeduidea，更新文档，仅提交本批并推送。

候选比较：纯波形线启动容易但缺少实体作品；直接上人体采集准备负担高。采用浏览器模拟到电位器控制夹爪的桥梁，保留向原生物信号课程迁移的明确边界。
