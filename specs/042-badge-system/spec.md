# 042-badge-system

**Status**: shipped (2026-07-03)
**Owner**: Claude + Xinghan
**Created**: 2026-07-02

## 背景 / 问题

student-app 当前完全没有激励徽章体系（老 `career_paths`/`earned_badges` 表只存在于已废弃的
`packages/core/education/career_path.py`，是 cloud-app 时代 Phase 3 设计，API/前端从未做完，
未迁移到当前主架构）。学生完成节点/项目后除了进度条和知识树点亮外，没有即时的收集向正反馈。

## 目标（WHAT）

为 student-app 新增一套"先驱者协会"世界观的徽章激励体系：

1. **世界观**：先驱者协会（The Pioneers Guild）下设八大分会，对应项目领域（覆盖当前本地
   library 实际 domain：Biotech/Aerospace/Climate/Robotics，以及用户指定新增的 AI/计算科学/
   脑科学/古生物）：
   - 生物机所 Bio-Forge Chapter（Biotech）
   - 穹际分会 Skyward Chapter（Aerospace）
   - 绿萌盟 Verdant Chapter（Climate/环保）
   - 机械之心 Mecha Core Chapter（Robotics）
   - 心智工坊 Mind Forge Chapter（AI）
   - 算境阁 Codex Chapter（计算科学/CS）
   - 神经回廊 Neural Spire Chapter（脑科学）
   - 深时秘境 Deep Time Chapter（古生物）
   - 未覆盖领域的项目暂不掉落徽章（等后续新增分会美术资源）

2. **徽章等级**：铜 → 银 → 金 → 大师，四级，**每级各自独立设计画面**（不是同一图腾换边框），
   统一按"单物件 → 场景 → 仪式 → 传奇"的叙事模板演变：
   - 铜：核心图腾特写（单一物件）
   - 银：图腾置入场景，画面元素更丰富
   - 金：加入人物剪影，构图更具仪式感
   - 大师：史诗级宏大场景，图腾升华为传奇意象

3. **掉落规则**（knode 无 `difficulty_level` 字段，改用实际存在的 `stage` 字段 S1-S6 表示
   阶段顺序，按相对位置推导难度）：
   - 节点所在 stage 处于该项目 stage 序列的**前半段** → 掉 1 枚铜
   - 节点所在 stage 处于该项目 stage 序列的**后半段** → 掉 1 枚银
   - 若该节点是所在 stage 的最后一个 knode（milestone 收尾）→ 在上述基础上额外多掉 1 枚
     （等级跟随该节点本身等级）
   - 前后半段的切分：`stage_index < ceil(total_stages / 2)` 为前半段，否则为后半段
     （比如 6 个 stage 时 S1-S3 前半段掉铜，S4-S6 后半段掉银）

4. **晋级兑换**：同一分会内，10 枚同色徽章自动合成 1 枚上一级（10 铜→1 银，10 银→1 金，
   10 金→1 大师）。大师为顶级，不可再兑换。各分会独立计数（生物机所的铜与穹际分会的铜不互通）。

5. **展示**：学生可在个人页面查看已获得的徽章墙（按分会分组，显示铜/银/金/大师数量与已合成的
   高等级徽章），项目详情页/节点完成时有即时掉落提示。

## 非目标（不做什么）

- 不做徽章之间的交易/赠送（不涉及学生间互动）
- 不做徽章反向消耗（比如换取其他权益），仅同分会同色数量晋级
- 不重做知识树点亮/进度条等现有进度可视化，徽章是新增的独立正反馈层
- 本期不做徽章掉落动画特效的精细设计（先用简单的 toast/modal 展示即可，视觉打磨可后续迭代）
- 本期只覆盖上述八大分会，新领域项目上线后再决定是否新增分会（需要新美术资源，独立迭代）

## 用户故事 / 场景

- 学生完成一个 bio-tech 项目的普通节点，看到"获得 1 枚生物机所铜质徽章"的提示
- 学生完成该项目某个 milestone 的最后一个高难度节点，看到"获得 2 枚生物机所银质徽章 + 里程碑
  奖励 1 枚"的提示（共 3 枚银）
- 学生攒够 10 枚生物机所铜徽章，系统自动合成 1 枚银，学生在徽章墙看到合成提示
- 学生在个人主页查看"我的徽章"，看到四个分会各自的收集进度和已获得的最高等级

## 验收标准

- [ ] 完成节点后能正确按 stage 相对位置掉落对应等级和数量的徽章
- [ ] milestone 收尾节点正确触发额外掉落
- [ ] 10 枚同色自动合成上一级，合成记录可追溯（不是简单删除旧徽章，需保留获得历史用于展示）
- [ ] 徽章墙页面正确展示四个分会的徽章数量与最高等级
- [ ] 项目领域到分会的映射规则明确（覆盖当前已上线的所有项目，无遗漏）
- [ ] 新增 DB 表 + API + 前端展示三层都完成，测试覆盖掉落/合成核心逻辑
