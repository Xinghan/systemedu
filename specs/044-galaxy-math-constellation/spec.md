## WHAT

在全学科知识星图 (`/galaxy`, 前端静态数据 `packages/student-web/public/galaxy/concept-galaxy.json`)
里新增一个独立的 **Mathematics (数学) 星系**。

当前星图有 13 个学科、445 个概念,但没有"数学"。数学不是缺失,而是被打散——
扫描 8 门课的 558 个原始概念,有 **179 个概念带明显数学内涵**,全部散落在
AI(34) / 统计(39) / 系统(16) / 编程(15) / 控制(14) / 地球科学(14) / 信号(12) 等学科下。
星图上看不到数学星系,学生感受不到"这些真实项目背后是同一套数学在支撑"。

本 spec 新总结出一个数学概念星系 (预计 70-95 个概念),作为第 14 个学科加入星图。

## WHY

- **数学是横切工具学科**: 8 门项目课全都在用数学 (传感器读数的比例换算、P/I 控制的
  代数与微积分、脑波信号的傅里叶变换、AI 分类的向量/矩阵/概率),但学生在星图上看不到
  这条主线,数学的"通用性"和"跨项目复用价值"被稀释。
- **强化平台"真实项目为核心"定位**: 数学星系不孤立铺开,每个数学点都能回答两个问题——
  "哪个项目的哪一步用到它" (服务边) 和 "学它之前得先会什么" (前置链)。这与
  [[feedback_prereq_skill_via_agent_tutor]] "前置靠 agent 按需教" 的理念一致:
  星图先让学生看见数学的依赖结构,具体教学由 agent tutor 承接。
- **补全知识图谱的一大空白**: spec 041 已把 425 节点锚定 Wikidata,数学是其中缺的一整块。

## 目标 (Scope)

1. **现有 445 节点一律不动** —— subj / 坐标 / 连边 / QID 全部保持原样。数学是净新增。
2. **新总结一个 Mathematics 星系** (70-95 概念),覆盖小学→大学 4 个学段:
   - **来源**: 从 8 门课 179 个数学性原料概念提炼出数学"母概念"
     (如从"协方差矩阵""特征向量""黎曼几何分类"提炼出"矩阵""向量空间"),
     再向下补齐它们的基础前置,形成有前置梯度的完整 DAG。
   - **不是** 成体系的 K12-大学数学教材骨架 (那会产生大量与 8 课无关的悬空节点,
     偏离项目制定位)。范围严格由"8 课用到 + 其前置链"界定。
3. **走上游完整链路**: 在 `~/Dev/systemeduidea` 新建 `mathematics_concept_slice.json`
   作为第 9 个切片 (一门"虚拟课"),走现有 merge → assemble → anchor → emit 链路,
   重新生成前端 JSON。保持单一数据源,避免前端侧直接改 JSON 导致下次 emit 被覆盖。

### 非目标 (Out of scope)

- 不做数学概念的独立讲解页 / 课程内容 (星图只展示概念节点 + 依赖,不含教学)。
- 不改星图前端渲染逻辑 (`ConceptGalaxy.tsx`)——数学作为普通学科天然被现有渲染支持。
- 不重锚定现有 445 概念的 QID。

## 数学星系的概念骨架 (5 分支 × 4 学段)

从 179 个原料提炼,按数学内部结构组织成 5 个分支:

| 分支 | 小学 | 初中 | 高中 | 大学 | 服务哪些课 |
|---|---|---|---|---|---|
| 数与量 | 计数、比例、百分比、分数、数量级 | 单位换算、科学计数法 | 对数/指数尺度 | — | 全部课 (传感器读数、浓度) |
| 代数与函数 | 变量、简单方程 | 一次函数、斜率、线性关系 | 二次/指数函数、方程组 | 多项式拟合、插值 | stirling(P控制)、purpleair(校准) |
| 几何与空间 | 角度、面积、坐标 | 平面坐标系、勾股 | 向量、三角函数、旋转/平移 | 向量空间、点积、范数、投影、黎曼几何 | mars(运动学)、satellite(地理坐标)、eeg |
| 概率与统计 | 平均数、计数统计 | 中位数/众数、简单概率 | 方差/标准差、分布、直方图 | 协方差矩阵、回归、相关、贝叶斯、采样、混淆矩阵 | ant、eeg、purpleair、molecule |
| 微积分与变化率 | — | 变化率直觉 | 斜率即瞬时变化 | 导数、梯度、积分、卷积、傅里叶/拉普拉斯 | stirling(积分控制)、eeg/emg(信号)、AI(梯度下降) |

底层线性代数枢纽 (向量→矩阵→特征值→梯度) 被最多课共享,是星图上最亮的大节点。
(表格为方向示意,最终概念清单由提炼阶段确定。)

## 连边策略 (数学是横切工具,两类边)

1. **数学内部前置链 (`hard`)**: 如 `向量 → 矩阵 → 协方差矩阵`、`斜率 → 导数 → 梯度`。
   这是数学星系自己的 DAG 骨架,回答"学它之前得先会什么"。
2. **数学 → 现有概念的服务边 (`soft`)**: 如 `协方差矩阵 →(soft)→ 空间滤波器[现有AI概念]`、
   `导数 →(soft)→ 积分控制I[现有Control概念]`。回答"哪个项目的哪一步用到它"。
   - 服务边通过 `covers` 复用现有课的 module 锚点 (数学点挂到用到它的 `slug:M##`),
     所以前端选中某项目时,它服务的数学点会一起点亮。

## 提炼方式 (已定: 多 agent 并行 + 人工审校)

每个分支 (数与量 / 代数与函数 / 几何与空间 / 概率与统计 / 微积分与变化率) 派一个
sub-agent,基于 179 原料 + 8 课切片上下文,提炼该分支的:
概念 (name_zh/en/grade_band/type/description) + 内部前置链 + 服务边 (指向现有概念) +
Wikidata 搜索词。主 agent 审校去重、消解跨分支重叠、合并成单一 slice。
