# 分步课堂记录与按任务设计的输入

Status: implemented locally (2026-09-20), pending production deployment

问题：账号保存后，课程仍把下载放在主要路径；所有思考题套用大空白框，缺少例子与填写边界，孩子不知道从哪里开始。

目标：四个节点依据实际学习动作配置选择、条件句、前后对照和交付说明。一次展开一个任务，提供明确且不自动写入答案的例子；保留独立表达。自动保存和正式提交保持区分。下载、导入、历史成为次要操作，失败时直接提供备份。

兼容：沿用原课程和问题 ID、存储版本；原答案不解析、不覆盖。新表单的结构和人类可读回答一起保存，刷新、账号恢复、下载与旧格式都可用。没有填写的字段、示例、占位提示不计入完成。

验收：四节点各有具体示例和适合任务的字段；无默认代答；分步进度可回看；必需字段未完成不可提交；新旧记录恢复；正常状态下载收起、冲突可直接备份；手机布局及键盘操作验证。


## 验证与边界

新增 6 组真实浏览器检查：默认空白与例子不代填、缺项阻止完成、四节点结构、旧文字兼容、跨浏览器账号恢复、手机与键盘交互。原 8 组账号保存检查继续覆盖断网、重复提交、版本冲突与导入；7 组课程回归覆盖实验关联、配额异常及移动布局。证据见 artifacts/guided-response/、artifacts/learning-records/、artifacts/guided-course/。

变更组件 ESLint 通过。全量 TypeScript 仍报告既存 slide-demo 与课程生成接口参数错误，本轮新组件未新增类型错误。

本次覆盖驾驶规则课程四节点，并形成可选 response_prompts 配置和课程制作说明。开放式长反思仍允许自由文本；已有文字恢复为自由表达，不自动改写。自动化检查不能替代儿童试用，尚未声称已经降低实测完成时间。
