# 方案

采用结构化小步骤并保留自由表达。相比仅给大框加 placeholder，能减少组织答案的负担；相比把所有题都做成选择题，仍要求孩子说明理由。示例持续可见且与真实实验结果区分，不提供一键代填。

课程 JSON 增加可选 response_prompts，定义标题、引导、示例和字段（choice/short/text）。回答仍写入原 answers，结构字段存 client_context.guided_response；旧文字直接进入自由表达模式，避免猜测拆分。

共享回答组件负责展示和完成条件，课堂 notebook 负责两步切换、记录状态和提交。账号正常时导出收进折叠选项，网络/版本/存储问题显示恢复操作。课程侧栏以返回本节记录为主要动作，最终交付不再要求下载文件。

实际浏览器验证填写与恢复，复用前轮账号保存测试；增加表单缺项与示例不代填检查。仅提交本次改动，保留其他工作区内容。
