# 生命解码局本地试用

入口：[生命解码局](http://localhost:4000/library?view=lines&line=biomedicine)。本批为本地版本，未部署。首次由家长帮助登录；无需化学品、额外软件或器材。

| 项目 | 入口 | 建议观察 |
| --- | --- | --- |
| 01 转动我的第一个分子 | [开始](http://localhost:4000/explore/biomedicine/turn-a-molecule) | 孩子能否自己转动、标记原子、留下观察卡 |
| 01 给分子排个队 | [开始](http://localhost:4000/explore/biomedicine/sort-molecule-cards) | 是否理解排序依据；错误尝试是否帮助修订 |
| 02 做一台分子筛选器 · 4 节 | [开始](http://localhost:4000/explore/biomedicine/build-a-candidate-filter) | 能否读懂例子、独立改规则、解释一个 ID 的去向 |
| 02 给分子预测做一次体检 · 4 节 | [开始](http://localhost:4000/explore/biomedicine/check-a-prediction) | 是否能算一个绝对误差，同时看整体与单条案例 |
| 03 搭起我的分子发现工作台 · 6 节 | [开始](http://localhost:4000/explore/biomedicine/assemble-a-discovery-desk) | 能否接入自己的作品，解释接口故障、预算取舍与同版本复测 |
| 04 打开未知分子档案 · 5 节 | [开始](http://localhost:4000/explore/biomedicine/challenge-an-unseen-library) | 是否理解先冻结后揭晓、失败可交付、修订属于事后探索 |

建议先完整试 02 筛选器：阅读一个示例，完成三步任务，做理解自检，填写自己的简短观察。最后交付并展开报告，确认规则、两版对比和解释均在。随后修改草稿，旧报告应保持不变。

登录时：草稿自动保存，理解自检按次提交，最终作品另存固定快照；关闭后用同一账号可继续。未登录时仅当前浏览器，不能视为账号同步。理解自检可重试，不锁住作品，也不代表系统已经评定掌握。

请重点记录三个现象：孩子在哪一步需要家长提示、哪个词或例子仍难懂、交付后能否用自己的话解释一个决定。时间只是设计目标，当前的软件测试尚不能回答儿童实际学习效果。

课程源：`~/dev/systemeduidea/project_lines/biomedicine/`；引导源 `lesson-guides.json`，四个课程包在 `projects/<id>/course/`。生成封面维持已确认版本。
