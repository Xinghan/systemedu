# 058 生命解码局与五级项目路线

Status: local_ready (2026-09-21), not deployed

用户授权继续生成项目，并授权按真实复杂度增加层级。本批补齐生命解码局：两个短体验、两门方法课程、一门系统课、一门独立挑战；接到已有分子怪兽猎人。

## 学习责任

01 发现与操作；02 制作并比较一种方法；03 组合系统、诊断故障、协调约束；04 预先声明方案、面对未见数据、解释失败与修订；05 完整工程与研究。层级与原旗舰课程的工程深度分开，保持旧记录版本和账号范围。

## 验收

- 六个可开始入口，有各自生成的位图封面；短体验具有高质量分子 3D 与准确 SVG 回退。
- 非短体验均为多节点课程，含正文、真实参考资料、核实的视频及中文替代阅读、结构化记录、实践工具与最终作品。
- 分子结构及测量数据有来源、版本、单位和计算方法。训练、验证与挑战样本不泄漏；课堂挑战不声称具有防作弊能力。
- 最终作品包括实际配置、可复算结果、学生解释与提交快照。改变配置使旧证据失效；失败实验也可成为合格研究证据。
- 登录账号保存草稿与提交版本；匿名仅本机。跨项目读取自己的正式作品，或明确在本课重新制作。
- 项目库按 01–05 顺序展示所有项目，主题入口保持独立视图；不把尚未完成内容登记为可开始。
- 不新增医疗建议或湿实验；计算筛选不能证明药效。儿童用时与可用性仍须实测。

实施和验收已完成：六个入口、19 个课程节点、四份最终作品，五级库展示与账号保存。计算、完整浏览器流程、库回归和生产构建通过；详情与全仓既有类型问题见 verification.md。
