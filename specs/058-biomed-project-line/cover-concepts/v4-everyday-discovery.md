# 封面方向讨论：从身边素材到自己的发现

状态：概念样张，尚未替换网站正式封面。

## 设计目标

封面要传递与课程一致的承诺：孩子能观察什么、做什么、留下什么。真实质感不等于必须展示昂贵设备；亲近感也不靠玩具化科学对象。生命解码局当前主要通过浏览器观察结构、比较属性、建立筛选规则、核对预测并组合工作流程，封面主角应围绕这些可完成的活动和作品。

推荐采用“生活中的真实素材 + 微观科学可视化 + 个人作品痕迹”。以茶叶与咖啡因观察卡作为第一张概念样张：叶片建立与生活的联系，分子视窗表达科学内容，原子标记和观察卡表达孩子的贡献。观察卡是作品的视觉表达；课程不增加采叶、打印、提取物质或购买仪器的要求。

## 分项目设计

| 项目 | 封面主角 | 孩子贡献的可见线索 |
| --- | --- | --- |
| 转动我的第一个分子 | 真实茶叶、咖啡因微观视窗 | 一个自己标记的原子与观察卡 |
| 给分子排个队 | 三张分子属性卡 | 排序位置及一次调整 |
| 做一台分子筛选器 | 清楚的候选卡与规则片段 | 保留、排除的判断痕迹 |
| 给分子预测做一次体检 | 一张预测与实际结果的对比作品 | 被圈出的误差案例 |
| 搭起我的分子发现工作台 | 已有观察、筛选、预测作品组成的工作界面 | 可理解的数据连接与一次修订 |
| 打开未知分子档案 | 已写下的判断标准和新一组分子资料 | 初次结果与之后的反思 |

正式制作时，结果图和数据优先取实际课程的可核验示例，不能用生成的随机数值假装实测。封面样张不当作学生真实提交。

## 视觉基调

暖纸色、叶片绿与少量珊瑚色；自然光、细腻材质和清楚留白。分子保持科学可视化细节，不画成桌面玩具。允许纸张、铅笔、局部操作痕迹营造可参与感，避免泛化的电脑操作员照片、无关大型设备和过度布景。

器械特写加微观放大仍适合孩子实际使用、设计或制作该器械的课程；不能把它作为所有科学课程的默认模板。
