# 生命解码局封面修订

2026-09-21。用户要求有真实质感的科研机器，并通过适度放大展示分子。主角是研究设备和微观世界，画面不使用实验室电脑操作员作为主体。

## 本次范围

重做六个新增项目封面及生命解码局入口图，使用内置 image_gen 逐张生成。设备按高细节摄影质感表现，占据主要画幅；以边界清楚、有细引线的科学放大视窗连接样品与分子尺度。分子窗口标记“分子示意”，不画成现实空间里的悬浮物、放大镜或装饰摆件。

结构观察对应晶体衍射仪与分子结构；分子比较对应质谱进样设备；筛选对应自动移液与样品板；预测核对对应光谱测量；系统整合对应自动化发现工作单元；新数据挑战对应新批次自动进样。它们表达相关科研语境，不意味着课程中的计算规则就是仪器工作原理。

课程仍为已有数字课程。实验室封面用于表现相关科研语境，不表示学生必须使用画面中的实验仪器，也不充当实验测量、真实实验室实拍或学生作品证据。

## 验收

- 七张图逐张检查，拒绝分子实体摆件、放大镜、古董天平、虚构筛选门和悬浮全息画面。
- 核对仪器形态、机械连接、光照与比例，以及分子示意的连接；图像中心裁切后仍能辨别主题。
- 在桌面和移动端检查项目线、全部项目里的加载与裁切，不修改课程或学习数据。
- 图像和最终提示词同步保存到课程源仓库；记录生成来源，不称为真实实拍。

完整提示词与最终文件对应关系见 cover-prompts.json；本次选用版本标记为 machine-molecule-v3。
