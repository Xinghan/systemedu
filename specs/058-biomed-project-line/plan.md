# 实施方案

复用现有多节点课程壳、视频组件、结构化笔记、learning_records 持久化和正式提交机制；将太空专有路径改为可选项目线元数据，旧课程默认仍为太空。

新增独立的生物医药模型、分子渲染器和分阶段工作台，不依赖其他未提交的科学可视化文件。冻结公开 ESOL 数据、分组划分、RDKit 派生属性与结构坐标；计算在纯函数中可复算。课程与源项目线保留生成和来源说明。

项目类型继续使用 micro/guided/integration/flagship；独立 level 表达学习责任，避免给已有数据枚举增加不必要分支。03 火星车仍要求实物，现场远征归入 04；其他主题不强制拥有每一级。

按数据与契约、模型、交互、课程、库展示、测试顺序实施。验证科学数据及拆分、模型泄漏与版本失效、空/有效交付、账号恢复、桌面移动端及 WebGL 不可用场景。生成封面只用插图，不作为实验数据。

本批完成本地可评审版本并提交推送到独立分支；上线状态另行记录。

## 课程内容深化实施

用一份手工编写的节点引导数据同时生成正文示例、任务、差异化笔记提示及网页自检。复用现有 quiz 学习记录，不改数据库或作品格式。独立的只读成果组件展示正式提交快照；补齐筛选表的 logP 和误差方向边界。同步 systemeduidea 的课程、打包器和引导源文件。用临时账号验证全部项目、自检重试与恢复、固定作品报告、移动端，然后清理测试记录。
