# 实施方案

1. 修正 project-line、course_factory、project_factory 的分流规则：micro 走直接互动；guided/integration/flagship 走课程设计与节点内容，不以时长替代难度。
2. 增加课程设计契约，要求学习目标、真实前置、多个节点、材料计划、reference/video 使用任务、练习、交付和验收。校验器阻止单 HTML 被登记为已完成中等课程。
3. 为五条线现有中等/组装规划补具体多节点大纲；未生成的材料明确为计划。驾驶规则制作实际课程材料并核对原始资料。
4. 内容采用 tree/knowledge_tree.json 与 knodes/<id>/lesson.md、resources.json、assignment.md 的课程包结构；本地课程入口读取这些材料并呈现课程目录、正文、资料、视频和节点学习记录。避免改动已有未提交的完整课程播放器。
5. 沿用规则工作台作为节点实验，保存独立学习记录；不把播放视频、打开页面或通过模拟测试当作全部学习完成。核对可恢复、导出和存储异常。
6. 更新项目库的课程标签、节点数与累计时长，运行结构和浏览器回归，精确同步、提交推送两个仓库。
