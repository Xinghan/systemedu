# 实施方案

采用“主题入口 + 分层项目库”：与只加难度角标相比，这能提供明确的首个动作；与强制升级地图相比，它保留按兴趣选择及直接进入完整项目的自由。

视觉沿用暖纸色与珊瑚色，首屏采用远征手册式横幅，复用已有火星车插画，搭配轻量观测起点。类型选择形成清楚的水平结构，卡片用独立的作品、时间、挑战和准备信息降低判断成本。

1. 在 `src/lib/project-lines/catalog.ts` 集中维护已实现短项目、太空主题链接及明确的规划摘要。
2. 重构 `/library`，将静态短项目与内容服务课程合并为可筛选的视图数据。课程继续使用现有 API，draft 不提供课程跳转。
3. 新卡片保留领域徽章、封面兜底、故事弹窗和已加入状态；火星车明确关联太空探索。
4. 使用范围限定的 CSS Module；中英文文案单独组织，沿用全局语言状态。
5. 导航中的“实验室”统一为“项目库”，首页相关入口同步命名。
6. 验证实际 API、类型筛选、搜索、挑战筛选、排序、草稿与故障状态、故事、窄屏、两种语言及体验跳转；归档截图和检查结果。

内容来源：当前课程 API 和 systemeduidea 已确认的太空项目线。只开放已实现的观测台；不把规划节点伪装成可运行课程。
