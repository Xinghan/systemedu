# 项目库：主题项目线与分层入口

Status: deployed to production (2026-09-20); see docs/deployments/2026-09-20-rover-project-lines.md
**Created**: 2026-09-18

## 背景与目标

现有项目库以学科标签和完整课程卡片为主，首次进入的孩子很难判断从哪里开始。用户已授权重新设计主网站项目库，要求突出难度差异、3 分钟入口和“太空探索”这样的大领域项目线。

以项目库作为内容发现入口：首屏展示太空探索及其首个可玩项目，再以短体验、引导小项目、组装挑战、完整工程区分投入方式。挑战程度、时间、准备事项和作品分别显示。保留已有课程详情、开篇故事、已加入状态及项目申请。

## 用户路径

1. 新用户从主题卡片直接进入约 3 分钟的观测台，无需登录。
2. 想了解全貌的家长或孩子进入现有项目线，看到入口到火星车的关系。
3. 熟悉平台的用户通过类型、挑战程度、领域、搜索和排序定位完整项目。
4. 未制作的引导和组装项目只展示明确的规划提示，不能开始。

2026-09-19 调整：主导航只保留项目库；“全部项目 / 项目线”作为项目库内的两个视图。项目线地址为 `/library?view=lines`，旧 `/project-lines` 兼容跳转。视图可刷新、分享及通过浏览器前后退恢复，页内切换保留已有筛选。

## 验收

- `/library` 首屏具有醒目的太空探索入口和两个可用操作：开始短体验、查看项目线。
- 首个短项目出现在项目库；完整课程展示真实时长、原挑战评分与目标作品。
- 类型、领域、挑战程度、关键词、排序与筹备中开关可操作，具有空态和重置。
- 内容 API 故障时显示重试，首个静态短体验仍可进入。
- 默认优先展示可开始的项目；没有开放内容的层级明确说明筹备状态。
- 保留已有课程和故事入口；桌面、窄屏、英文、键盘均可用。

时长并非儿童试用结果；短体验不映射成旧课程 difficulty 1–5。无新增后端 API、数据库、生产发布或自动解锁。
