# 实施方案与制作 brief

复用首个项目的静态 HTML + 同源 iframe、本地 Three.js 和程序素材。共享模块负责存档、场景与受限模型；每个项目保留自己的操作界面，避免复制同一个玩法。使用深色任务舱与铜色火星地面，核心操作就近放在场景边缘，手机上下排列。

1. 着陆：从 60 m、向下 4 m/s 开始，点击开始后控制制动。固定步长积分重力与有限燃料推力，降低模拟播放速度给初学者反应时间。触地速度不超过 3 m/s 记为柔和着陆；超过阈值真实记录失败。轨迹、燃料与制动记录可回看和下载，失败同样是有效尝试。重力取约 3.7 m/s²（NASA Mars Fact Sheet）；推力、燃料、阈值和简化模型为教学设定，没有大气、姿态或变质量模型。
2. 驾驶：预置小型网格地形，方向按钮逐格驾驶，岩石阻挡并提示绕行；选岩层或沙丘目标，调整镜头方向，在接近并朝向目标后拍照。主视图呈现空间路径，取景窗呈现当前相机，保存取景窗实际画面、路线与输入。重新打开可查看作品、回放路线。
3. 规则：平台提供 clear / sand / rock / unknown 状态输入。孩子用四条条件选择动作；运行器实际移动虚拟车，前进遇岩石碰撞、快速进入软沙停滞，绕行走相邻通道，停车保留当前位置。先观察不合适的动作，再修改；两条不同布局都安全行驶到 unknown 并停车后保存。导出受限控制程序及逐步日志，导入只加载规则，不信任文件的完成声明。
4. 模型支持无需 DOM 的单元验证。3D 初始化失败时使用同一状态的 Canvas 示意；页面切到后台时停止推进，不补算孩子没看见的过程。
5. 本机存档包括版本、个人选择、模拟结果与平台模块说明；存储不可用时保留下载。每项 README 说明模型、素材来源、启动动作、成果格式和真实试用问题。
6. 扩充共享前端目录为已实现短项目和引导项目，项目线与列表同时消费；已有完整课程与筛选保持可用。新增浏览器验证，检查模型边界、保存与导入、路由、移动布局；同步内容仓库并分别提交推送。

重力参考：https://nssdc.gsfc.nasa.gov/planetary/factsheet/marsfact.html （2026-09-19 查阅）。除该近似常数外，所有地形、模型和教学参数均由本项目设计，不表示 NASA 飞行仿真。
