# 实施计划

1. 在 project-line 入口与 short-projects 引入“简化任务不简化成品质量”，新增可按需读取的视觉制作和验收参考；不膨胀成完整课程工厂。
2. 复用本地 Three.js 0.184.0，拆分设备、地形、SVG 仪表、渲染控制；所有资源在本地生成，不依赖外部请求。构建概念教学设备，参考真实工程结构，但不冒充特定型号复制品。
3. 程序化 PBR 材质、环境反射、柔和阴影、多层地表和远景；六轮悬挂、桅杆镜头、太阳翼、腿架、喷管和细部连接。相机提供跟随、全景、设备近看与可控旋转缩放。
4. 两个项目采用独立的任务控制界面：运行场景为主体，SVG 地图/下降仪表显示真实状态，驾驶取景与导航同时可见。轻量降级继续使用相同状态并明确标注。
5. 视觉状态独立于模型积分。拍照时强制对齐当前逻辑位置、镜头和记录；回放不计入新成果。保留原 schema、模型与已保存数据。
6. 运行既有模型和互动回归，补查视角、动画、导出画面、移动端、资源释放与性能；检查实际截图后迭代。同步两个仓库，精确提交并推送。
