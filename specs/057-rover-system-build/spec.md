# 03 级系统设计与实物探测车

Status: deployed to production (2026-09-20); see docs/deployments/2026-09-20-rover-project-lines.md

用户批准半开放系统挑战，并明确：03 探测车最终必须做出实物，数字原型仅为中间成果。02 是部件与单变量实验；03 要处理模块接口、多约束取舍、证据诊断、新情景迁移和制造实测。

组装课 2.0：八节点，从任务、接口、设计与运行、未知故障、新路线，到参数化打印、低压电路与程序、实测交付。提供可修改 CAD、STL、尺寸图、接线表、控制程序和材料规格。有限实物目标为双轮差速底盘、触碰停止；不宣称相机 AI 或真实火星能力。制造等待与成人协助单列。

数字方案有实际相互作用：轮径、结构、载荷与能量；增加电池也增加质量。连接选择改变运行。故障先显示现象，孩子测量、判断和修复。交付必须包含当前版本数字验证、制造修改、实测原始记录与实物照片；自动检查仅确认材料完整，提交仍待评阅，不宣称实物被平台验证通过。

远征课改为 2.0：读取 2.0 实物作品包，保留模拟规划，再完成真实地面任务记录与实物证据。1.0 课程与记录可从明确旧版入口回看，不自动换算为 2.0 实物交付。

本轮验证覆盖软件模型、保存恢复、跨项目消费、打印网格几何、固件逻辑和网页；没有打印机或实车，不能宣称完成制造试验。实际加工与电路仍需首台样机校验。

## 本轮验收

- 模型：耦合取舍、当前版本证据、两项诊断检查、旧日志伪造拒绝、数字不能代替实物、远征参数消费与任务变更失效通过。
- 制造文件：四个 STL 通过闭合、定向、尺寸与正体积检查；固件通过启动静止、常闭开关断线阻止启动、触碰停止、异常停止、占空比和单次时限模拟测试。
- 浏览器：13 节材料与旧版导航、数字五阶段、制造文件下载、源码与照片交付、现场远征、账号数据库恢复/隔离、手机布局与 WebGL 验证通过。仅隔离测试账号使用明确标记的合成素材，不声称实体试制成功。
- 全量 TypeScript 检查仍有原有 6 处无关错误（slide-demo 两处、course-content-view 四处）；本次文件无类型错误。新增文件定向 lint 通过。
- 待做：首台实物样机、儿童试用、生产部署。已提供参考包与成人分工，不把静态/模拟测试冒充实物验证。
